# 四层自检详细检查清单

> 本文件从 `SKILL.md` 拆分而来。主文件保留四层自检摘要 + 通过标准，详细检查项和修复指引在此。

---

## L1 硬性规则检查（自动扫描层）

这一层检查的是绝对不能违反的规则，类似代码的语法检查。任何一项不通过就必须修复，没有例外。

**L1-1 禁用词扫描**
全文搜索以下词汇，出现则必须替换：
- "说白了" → 换成"坦率的讲"、"其实就是"
- "意味着什么" / "这意味着" → 换成"那结果会怎样呢"、"所以呢"
- "本质上" → 换成"说到底"、"其实"
- "换句话说" → 换成"你想想看"、"也就是说"
- "不可否认" → 直接删掉，换成正面陈述
- "综上所述" / "总的来说" → 换成具体的回扣句
- "首先...其次...最后" → 用自然的转场词替代
- "值得注意的是" / "不难发现" → 删掉，直接说

**L1-2 禁用标点扫描**
全文搜索以下标点，出现则必须替换：
- 冒号"：" → 用逗号替代
- 破折号"——" → 用逗号或句号替代
- 双引号""或"" → 用「」替代，或直接不加引号

**L1-3 结构性套话扫描**
检查是否出现以下模式：
- "让我们来看看..." / "接下来让我们..."
- "在当今...的时代" / "随着...的发展"
- 连续使用bullet point罗列观点（超过3个就需要改成散文叙述）
- 大段加粗（超过2行的加粗几乎肯定是过度结构化）

**L1-4 工具名检查**
确认所有提到的AI工具/产品都使用了具体名称，没有出现"AI工具""某个模型""相关技术"等空泛表述。

**通过标准**：以上四项扫描零命中。量化指标：
- L1-1 禁用词扫描：0 命中（每出现1个禁用词即不通过）
- L1-2 禁用标点扫描：0 命中（冒号/破折号/双引号各0处）
- L1-3 结构性套话扫描：0 命中（套话模式0处、bullet point ≤3个/段、加粗 ≤2行/处）
- L1-4 空泛工具名：0 处（所有AI工具/产品均为具体名称）

**修复方式**：逐个替换，用推荐口语化词组中的表达替代。
**修复时间预算**：≤ 3 分钟/千字（L1 为机械替换，速度应最快）

## L2 风格一致性检查（模式匹配层）

这一层检查文章是否符合活人感写作模式，类似代码的单元测试。每一项都给出"是/否"判断。

以下检查项中的风格标准，以你的人设档案为基准。

**L2-1 开头检查**
- 是否从一个具体的、当下的事件/场景切入？（不是宏大叙事）
- 第一句话是否让读者产生"然后呢？"的冲动？
- 有没有使用任何教科书式开头？

**L2-2 节奏与结构检查**
- 是否有长短句交替？（连续3句以上句式长度相近 = 节奏呆板）
- 是否有一句话独立成段的"断裂"效果？（全文至少出现3次）
- 偏离主线的段落后面是否有"扣主线句"拉回来？
- 有没有用疑问句来制造节奏的刹车和转向？
- 是否避免了不必要的小标题？（除非是分条目的方法论文章，否则不应出现markdown标题或加粗小标题，靠口语化转场自然衔接）

**L2-3 口语化检查**
- 是否使用了推荐口语化词组？（全文至少出现8-10个不同的口语化表达）
- 有没有论述中的故意打破？（重复强调、中途打断、省略主语等）
- 有没有至少一处自嘲或承认不足？
- 标点是否用来表达情绪？（"。。。""？？？""= ="至少出现其中一种）

**L2-4 标点禁令二次确认**
- 全文是否完全没有冒号、破折号和双引号？（AI容易在修改过程中重新引入这些标点，需要二次确认）

**通过标准**：L2-1全部通过，L2-2至少3/4通过，L2-3至少3/4通过，L2-4通过。量化指标：
- L2-1 开头检查：3/3 全部通过（具体事件切入 + "然后呢"冲动 + 无教科书开头）
- L2-2 节奏与结构：≥3/4 通过，其中"长短句交替"和"扣主线句"为必过项
- L2-3 口语化：≥3/4 通过，其中"口语化词组 ≥8 个不同表达"和"情绪标点至少1处"为必过项
- L2-4 标点禁令二次确认：0 命中（冒号/破折号/双引号各0处，与 L1-2 交叉验证）

**修复方式**：逐段检查，对不符合的段落进行改写。重点关注那些"读起来像在写报告"的段落。
**修复时间预算**：≤ 8 分钟/千字（L2 需逐段判断，耗时中等）

## L2-5 短视频专项检查（口播适配层）

当脚本类型为短视频口播脚本时，追加以下专项检查：

**L2-5-1 口播停顿密度**
- 每100字是否包含 ≥2 处停顿标记（逗号自然停顿、句号、省略号"。。。"、独立短句断行均计为停顿）？
- 若密度不足：标注段落位置，建议增加口语化断句（拆分长句、插入语气停顿）

**L2-5-2 画面感指令密度**
- 每30秒口播内容是否包含 ≥1 处画面描述词（动作指示如"你看这个""镜头切到""注意这里"、场景提示如"想象一下""你眼前是"、视觉锚点如"那一瞬间"）？
- 若密度不足：标注"口播内容偏纯文本，缺少画面引导指令，建议在关键节点插入视觉提示"

**L2-5-3 时长估算**
- 按 150 字/分钟 估算口播总时长，与脚本标注的预期时长对比
- 偏差 > 20% → 标注"⚠️ 时长估算偏差 {X}%：估算 {Y} 秒 vs 预期 {Z} 秒。检查是否内容过密或过疏"
- 偏差 ≤ 20% → 通过

**L2-5-4 呼吸点分布**
- 检查情绪高点后是否有短暂放缓（句式变短、节奏放缓、插入停顿、"。。。"标记）
- 若情绪高点后连续 3 句以上无任何放缓标记 → 标注"情绪高点后缺少呼吸点，观众可能疲劳"
- 若情绪高点后均有放缓 → 通过

**通过标准**：L2-5-1 必须通过，L2-5-2 和 L2-5-3 至少一项通过，L2-5-4 通过。
**修复方式**：不通过的维度在脚本中标注具体位置和建议，返回给用户确认后修改。

## L3 内容质量检查（深度审查层）

这一层检查内容本身的深度和说服力，类似代码的集成测试。

**L3-1 观点支撑检查**
- 每个核心观点是否都有具体的人/场景/细节/数据支撑？
- 有没有空泛的观点只有论断没有例证？

**L3-2 知识输出方式检查**
- 知识点是否以"聊着聊着顺手掏出来"的方式呈现？
- 有没有出现"下面我来介绍""首先需要了解"这种教科书式科普？
- 引用（论文、书籍、历史）是否自然融入论述，像"聊着聊着想起来的"而不是"我特意去查的"？

**L3-3 文化升维检查**
- 有没有至少一处从具体事件连接到更大的文化/哲学/历史参照物？
- 这个连接是否自然？

**L3-4 对立面与同理心检查**
- 在讲核心观点时，是否有对对方立场的理解和承认？
- 有没有先站到读者的处境里，再给出自己的视角？

**L3-5 文章类型专项检查**
根据文章原型做针对性检查：
- 调查实验型 → 有没有"亲自下场"的叙事感？过程是否有层层递进的发现？
- 产品体验型 → 有没有真实的使用场景？有没有跟其他产品的自然对比？
- 现象解读型 → 是否有"观察→好奇→研究→升维"的推进？
- 工具分享型 → 有没有个人故事铺垫？效果展示是否让人"卧槽"？
- 方法论分享型 → 每节是否都落到了可执行行动？是否坦诚说明了学习成本和失败点？有没有谦逊铺垫？

**L3-6 逐一展示检查**
- 如果涉及多个产品/案例的比较，是不是用了逐一展示（每个带吐槽点评）而不是一次性罗列？

**通过标准**：L3-1和L3-2必须全部通过，L3-3至L3-6中至少通过相关项（根据文章类型，有些项目可能不适用则跳过）。量化指标：
- L3-1 观点支撑：每个核心观点 ≥1 个具体支撑（人/场景/细节/数据），空泛论断 = 0
- L3-2 知识输出方式：0 处教科书式科普，引用自然融入率 100%
- L3-3 文化升维：≥1 处自然连接到更大参照物（不适用则跳过）
- L3-4 对立面与同理心：核心观点处 ≥1 处对方立场理解（不适用则跳过）
- L3-5 文章类型专项：对应原型检查项全部通过
- L3-6 逐一展示：多案例比较时使用逐一展示而非罗列（不适用则跳过）

**修复方式**：需要重新审视不通过的段落，补充案例、改写知识输出方式、或调整文化升维的自然度。
**修复时间预算**：≤ 12 分钟/千字（L3 涉及内容深度调整，耗时较长）

## L4 活人感终审（最终人格层）

这是最重要也是最主观的一层。这一层不是逐项检查，而是以读者的视角通读全文，回答一个核心问题：

**有人设时**：**"读完这稿子，感觉像是 [{persona.身份}] 在说话，还是一个AI在输出信息？"**
**无人设时（persona_mode: generic）**：**"读完这篇文章，我感觉是一个真实的人在认真跟我聊一件打动Ta的事，还是一个AI在给我输出信息？"**

具体的感知维度：

**L4-1 温度感**
- 文中的情绪表达是体感记忆（"我当时就愣住了""鼻子一酸"）还是知识性描述（"我感到非常震撼"）？
- 如果有人物描写，这个人物是否让你"能感觉到他的体温"？

**L4-2 独特性**
- 这篇文章是否有"只有你才会写出来的角度"？
- 还是换一个AI博主也能写出差不多的东西？

**L4-3 姿态检查**
**有人设时**：文章的语气是否符合 [{persona.身份}] 的表达方式，而非导师教学或品牌营销？
**无人设时（persona_mode: generic）**：文章是否像一个真实的人在认真聊一件打动Ta的事，而不是"导师在教学生"或"品牌在做营销"？
- 有没有不自觉地滑入了说教或推销的姿态？

**L4-4 心流检查**
- 从头到尾读，有没有哪个地方你的注意力断掉了？需要回头理解逻辑？
- 如果有，那个地方就是需要修复的节奏问题。

**通过标准**：L4-1到L4-4整体感觉"这像是真人写的"。如果任何一项让你觉得"这段AI味太重了"，就需要返工。量化指标：
- L4-1 温度感：体感记忆表达 ≥3 处（"我当时就愣住了"类），知识性描述 = 0 处（"我感到非常震撼"类）
- L4-2 独特性：≥1 处"只有这个作者才会写出来的角度"，无同质化段落
- L4-3 姿态检查：0 处说教/推销姿态（"你应该""你必须"类祈使句 ≤2 处且仅出现在行动呼吁段）
- L4-4 心流检查：0 处注意力断点（从头到尾一口气读完无卡顿）

**修复方式**：这一层没有机械的修复方法。核心操作是：把"AI味重"的段落找出来，想象你本人会怎么说这段话，然后用更口语、更私人、更不完美的方式重写。
**修复时间预算**：≤ 15 分钟/千字（L4 为主观判断+重写，耗时最长，可能需要多轮迭代）
