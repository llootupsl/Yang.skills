# 假设-预测桥接协议

## 目的

连接"选题假设"和"盲预测"两个阶段，确保选题时的假设在预测阶段可被验证。

## 流程

### 选题阶段
```
假设: [如果选这个题 / 用这个钩子 / 在这个时间发]
      那么预计 [某指标] 会达到 [范围]
      因为 [选题的原理 / 对标数据 / rubric 高分推断]
```

### 预测阶段
验证选题假设是否在预测中被显式考虑：
- 预测中该维度得分是否与假设方向一致？
- 若不一致 → 标记「选题假设 vs 预测分歧」

### 复盘阶段
实际数据出来后验证：
- 假设是否正确？
- 预测是否比假设更准确？

## 桥接失败处理
连续 3 次假设-预测分歧 → 建议用户重新检查选题假设生成逻辑
