# 中文情感分析工具对比调研

> **调研问题**：当前情绪曲线引擎（`yang-emotion-curve`）需要更强的小说级情绪标注能力，哪些中文情感分析工具可以增强这个环节？
> **结论**：基于词典规则的细粒度情绪分类（7种情绪+正负面）为首选；基于深度学习的方案为补充（置信度打分）。

---

## 一、方案总览对比

| 维度 | 词典规则方案 | 深度学习方案 |
|------|---------|----------|
| **技术路线** | 基于词典规则（知网 + 情感本体库） | 基于BERT深度学习模型 |
| **情感维度** | 7种情绪（乐/好/怒/哀/惧/恶/惊）+ 正负面情感值 | 正/负面 0-1 置信度 |
| **可解释性** | 高（词典匹配结果可追溯） | 低（黑盒模型） |
| **推理速度** | 极快（纯规则匹配） | 较慢（需GPU推理） |
| **部署门槛** | 极低 | 中（需深度学习框架） |
| **中文适配** | 原生中文词典设计 | BERT支持中文 |
| **自定义能力** | 高（可扩充词典） | 低（需微调模型） |
| **资源消耗** | 几乎为零 | 需要GPU/较多内存 |
| **准确率** | 中等（规则覆盖有限） | 高（深度学习泛化） |

---

## 二、方案详细分析

### 2.1 词典规则方案 —— 首选推荐

**核心优势**：
- **7种情绪细粒度分类**："乐、好、怒、哀、惧、恶、惊" —— 这套情感分类可以直接映射到短视频脚本的情绪设计（起承转合的情绪编排）
- **双重词典融合**：知网情感词典 + 情感本体库，覆盖面广
- **可解释性强**：输出每个词的匹配结果，方便人工审核和迭代
- **自定义词典**：可添加领域专有情感词（如自媒体行业黑话）

**与 Yang.skills 工作流的集成**：

```
对标视频转录文本
      │
      ▼
ASR引擎 (语音识别 + 粗粒度情感)
      │
      ▼
词典规则引擎 (细粒度7情绪标注) ──→ 情绪标签 + 情绪强度
      │
      ▼
yang-emotion-curve 引擎 ──→ 对标视频情绪曲线
      │
      ▼
yang-seed 内容引擎 ──→ 模仿对标情绪节奏创作新脚本
```

**集成收益分析**：

| 收益维度 | 量化预估 |
|---------|---------|
| 情绪标注自动化 | 从人工逐段标注 → 自动标注，效率提升10倍以上 |
| 对标拆解深度 | 新增"情绪维度"，对标分析从"说了什么"升级为"怎么让人感觉" |
| 脚本优化 | 新脚本可基于对标情绪曲线优化起伏节奏 |

**集成难度**：极低

---

### 2.2 深度学习方案 —— 精度补充

**核心优势**：
- **BERT级精度**：基于预训练BERT模型，准确度超过词典规则方案
- **置信度输出**：0-1区间，可以量化每句话的情感强度

**最佳使用场景**：
- 作为词典规则方案的"二审"引擎：词典规则给出粗粒度7情绪 → 深度学习给出每条文本的正负面置信度打分
- 尤其适合需要精确量化的场景（如A/B测试两条脚本的情感效果对比）

**集成难度**：中
- 需要安装深度学习框架
- 推理需要GPU或较多CPU资源

## 三、推荐方案与技术路线

### 推荐优先级

| 优先级 | 方案 | 使用场景 | 理由 |
|--------|------|---------|------|
| **P0** | 词典规则方案 | 对标视频情绪拆解、脚本情绪标注 | 7种细粒度情绪 + 可解释 + 零门槛 |
| **P1** | 深度学习方案 | 脚本情感量化A/B测试、关键词级别情感打分 | 精度高但有资源门槛，作为补充引擎 |

### 双引擎配合架构

```
输入文本
    │
    ├──→ 词典规则引擎 ──→ 7情绪标签 + 正负值
    │                              → 适用：对标拆解、快速标注
    │
    └──→ 深度学习引擎 ──→ 正负面置信度(0-1)
                                   → 适用：A/B测试、精确对比
```
