# 视频质量评估工具调研

> **调研问题**：对标分析当前靠人工 rubric 评分，是否有工具支持多维度视频质量的自动评估？
> **结论**：通用多维度评估框架适合框架参考，可定制评估维度方案更贴近实际需求。两者均属 Phase 3 前沿增强。

---

## 一、当前痛点

| 痛点 | 说明 |
|------|------|
| **纯人工评分** | 对标视频的 rubric 矩阵（选题/结构/情绪/视觉等维度）全靠人工逐条打分 |
| **主观偏差** | 同一个视频，不同人打分差异可能达2-3分（10分制） |
| **效率瓶颈** | 一条对标视频完整拆解 + 评分需要30-60分钟 |
| **视觉维度缺失** | 当前 rubric 偏重"内容"维度（选题、结构、情绪），"视觉"维度（画面质量、剪辑节奏、色彩）几乎空白 |

---

## 二、方案对比

### 2.1 通用评估框架

**定位**：多维度视频质量评估框架

**评估维度**：

| 维度 | 说明 | 对标分析价值 |
|------|------|-------------|
| **视觉质量** | 分辨率、画面清晰度、光线 | 对标画面质量基准 |
| **文本-视频对齐** | 文案与画面的匹配度 | 对标信息传递效率 |
| **物理一致性** | 画面是否符合物理规律 | 对标可信度 |
| **审美评分** | 构图、色彩搭配、视觉风格 | 直接对标视觉层面 |

**优势**：
- 多维度量化，天然适合转化为 rubric 矩阵分数
- 可灵活定制

**局限**：
- 社区文档不够完善
- 中文视频适配度待验证

---

### 2.2 可定制评估方案 —— 更贴近实际需求

| 项目 | 详情 |
|------|------|
| **技术路线** | 基于多模态大模型的可定制视频评估框架 |
| **核心亮点** | 支持自定义评估维度，可直接映射到 rubric 矩阵 |

**核心差异化**：

| 能力 | 说明 |
|------|------|
| **自定义评估维度** | 不只是"画质好不好"，可以定义"情绪感染力""节奏紧凑度""信息密度"等业务维度 |
| **Rubric 映射** | 评估维度可以直接对应 Yang.skills 的 rubric 评分矩阵 |
| **中文适配** | 天然中文生态友好 |

**适用场景**：
- 对标视频批量自动评分（替代人工 rubric）
- 多对标账号的视觉风格对比
- 内容质量A/B测试（同一选题的两种表达方式，自动评分比较）

## 三、方案对比总结

| 维度 | 通用评估框架 | 可定制评估方案 |
|------|:---:|:---:|
| **通用性** | 高（多维度框架） | 中（需定制评估维度） |
| **中文适配** | 待验证 | 天然友好 |
| **自定义评估维度** | 有限 | 核心能力 |
| **社区活跃度** | 一般 | 可持续更新 |
| **集成难度** | 高（需理解框架） | 中高（需多模态推理资源） |
| **推荐阶段** | Phase 3 | Phase 3 |
| **推荐优先级** | P2 | P1（更贴近业务需求） |

## 四、集成方案设计

### 4.1 评估维度映射

```
Yang.skills Rubric 维度            可定制评估维度
─────────────────────────────────────────
选题（Topic）           →  话题吸引力评分
结构（Structure）       →  信息组织清晰度评分
钩子（Hook）            →  开头3秒抓人力度评分
情绪（Emotion）         →  情绪感染力评分
节奏（Pacing）          →  剪辑节奏紧凑度评分
视觉（Visual）          →  画面质量 + 审美风格评分
完播预估（Completion）  →  综合留存吸引力评分
```

### 4.2 工作流集成

```
对标视频
    │
    ▼
可定制评估方案 多维度自动评分 ──→ rubric 矩阵分数
    │
    ▼
yang-learn: 对标分析报告（含量化分数 + 评语）
    │
    ▼
yang-seed: 以高分视频为模板孵化新内容
```

## 五、集成难度与风险

| 维度 | 评估 |
|------|------|
| **技术门槛** | 高 —— 需要多模态大模型推理能力，GPU资源需求大 |
| **中文适配** | 可定制方案天然友好，通用框架待验证 |
| **维护成本** | 中 —— 持续更新有保障 |
| **降级路径** | 清晰 —— 不可用或不达标，降级为人工 rubric 评分 |
| **定位** | Phase 3 —— 属于前沿增强，优先级在下半年 |

## 六、预期收益

| 指标 | 当前（人工 rubric） | 升级后（自动评分） | 提升 |
|------|:---:|:---:|:---:|
| 评分效率 | 30-60分钟/条 | 分钟级/条 | 10-30倍 |
| 评分一致性 | 因人而异 | 100%一致 | 消除主观偏差 |
| 视觉维度评估 | 几乎空白 | 新增4+视觉维度 | 全面性飞跃 |
| 批量能力 | 每天3-5条 | 无上限 | 质的飞跃 |
