## 附录 B：多平台预测格式适配

当同一作品在多个平台发布时，预测文件需按平台差异适配预测维度和 bucket 刻度。

### 平台维度映射

| 维度 | 抖音 | 小红书 | B站 | 视频号 |
|------|------|--------|-----|--------|
| 钩子冲击力 (ER) | ✅ 核心 | ✅ 核心 | ✅ 核心 | ✅ 核心 |
| 信息增量 (HP) | ✅ 核心 | ✅ 核心（偏图文适配） | ✅ 核心（长内容加分） | ⚠️ 次要 |
| 情绪价值 (QL) | ✅ 核心 | ✅ 核心（情绪共鸣权重上浮） | ⚠️ 次要 | ✅ 核心 |
| 人设契合 (NA) | ⚠️ 次要 | ✅ 核心 | ✅ 核心 | ⚠️ 次要 |
| 传播力 (AB) | ✅ 核心 | ✅ 核心（收藏驱动） | ✅ 核心（投币驱动） | ✅ 核心（社交裂变） |
| 社会议题 (SR) | ✅ 核心 | ⚠️ 次要 | ✅ 核心 | ⚠️ 次要 |
| 议题分享冲动 (TS) | ✅ 核心 | ⚠️ 次要 | ⚠️ 次要 | ✅ 核心 |

### 平台 Bucket 刻度

| 平台 | `<5w` | `5-30w` | `30-100w` | `>100w` | `>150w` | 说明 |
|------|-------|---------|-----------|---------|---------|------|
| 抖音 | ✅ | ✅ | ✅ | ✅ | ✅ | 默认刻度 |
| 小红书 | `<1w` | `1-5w` | `5-20w` | `>20w` | `>50w` | 流量基数较小，刻度压缩 |
| B站 | `<3w` | `3-20w` | `20-80w` | `>80w` | `>150w` | 中长视频流量分布 |
| 视频号 | `<2w` | `2-15w` | `15-50w` | `>50w` | `>100w` | 社交裂变驱动 |

### 多平台预测格式

当作品同时发布多平台时，在预测段后追加平台适配段：

```markdown
## 平台适配预测

### 抖音（主平台）
（使用默认 bucket 和维度权重）

### 小红书
**适配维度权重**: ER×0.30 / QL×0.30 / HP×0.20 / AB×0.15 / NA×0.05
**Bucket 刻度**: `<1w` / `1-5w` / `5-20w` / `>20w` / `>50w`
**内心概率分布**:
- `<1w` → X%
- `1-5w` → X%
- **`5-20w` → X%**（中枢 ~Xw）
- `>20w` → X%
- `>50w` → X%

**平台特有因素**: [小红书收藏率 / 图文适配度 / 搜索流量预期]
```

> **规则**：主平台使用默认预测段；副平台使用"平台适配预测"段，仅列出与主平台不同的部分。维度权重和 bucket 刻度必须显式写出，不可省略。

## 附录 C：预测 v2 段格式规范（拍摄后改稿的二次预测）

拍摄完成后如对稿件做了重大修改（改稿率 >30%），需在原预测文件中追加 v2 预测段，而非创建新文件。

### v2 预测段格式

```markdown
## 预测 v2（拍摄后改稿）

> ⚠️ **本段同样 immutable**——写完不可改。

**v2 触发原因**: `<改稿率 >30% / 主题方向变更 / 结构重组 / 其他>`
**v2 预测时间**: `<YYYY-MM-DD>`
**v2 Script Hash**: `sha256:<12位>`（改稿后的新哈希）
**v2 Actual Script Length**: `<新字数>`

**v2 与 v1 的关键差异**:
- [改了什么：具体段落 / 论点 / 结构]
- [为什么改：拍摄反馈 / 新信息 / 逻辑修正]
- [预期影响：哪个维度分数变化 + 方向]

**v2 分数 (vN)**: `<dim1=X / dim2=X / ...>` → composite=**`<X.XX>`**

**v2 Bucket**: `<X-Yw>`

**v2 内心概率分布**:
- `<5w` → X%
- `5-30w` → X%
- **`<headline bucket>` → X%**（中枢 ~Xw）
- `>100w` → X%
- `>150w` → X%

**v2 一句话 reason**:
> [v2 核心驱动因素 + 与 v1 的关键差异 + 中枢预测]

**v2 推理因素**:

| 因素 | 方向 | 置信度 | 说明 | v1→v2 变化 |
|---|---|---|---|---|
| `<dim or feature>` | 强+ / 中+ / 弱? / 强- | 高 / 中 / 低 | [≤30字理由] | ↑ / ↓ / → / 新增 |

> 最后一列标注该因素相对 v1 的变化方向，方便复盘时追踪改稿的实际影响。
```

### v2 追加规则

1. **触发条件**：改稿率 >30%（字数差异 / 段落重组 / 核心论点变更任一满足）
2. **追加位置**：在原"预测"段之后、"推理因素"段之前插入
3. **v1 不可修改**：原预测段保持 immutable，v2 是追加而非覆盖
4. **复盘时**：复盘段需同时评估 v1 和 v2 的偏差，并分析改稿的实际效果
5. **Script Hash 不一致**：如 v2 Script Hash ≠ v1 Script Hash，复盘段自动标注 integrity warning
