# 复盘段模板

> **本模板由 `/yang-retro` 自动追加到对应 prediction 文件的 `## 复盘` 段**。
> 不是独立文件——只是 prediction 文件的下半段格式参考。
>
> 示例数据来自视频分析项目的「停止期待」复盘（[predictions/2026-04-24_ab61ed09_停止期待.md] 的复盘段）。
>
> 完整规范见 [shared-protocols/prediction-anatomy.md](../Yang.skills/shared-protocols/prediction-anatomy.md) 的"复盘段"部分。

---

## 复盘

**复盘时间**: `<YYYY-MM-DD>`（发布 T+`<N>`d）
**抓取时间**: `<YYYY-MM-DD HH:MM>`
**数据来源**: `manual paste` / `adapter:<platform>`

### 实绩数据

- 播放：**`<X>`w**（落在 \``<bucket>`\` 桶内 [偏高 / 偏低 / 中枢]，相对中枢 `<X>`w **`<+X% / -X%>`**）
- 点赞：`<X>`w（赞播比 `<X.XX%>`）
- 评论：`<N>`（评播比 `<X.XXX%>`）
- 收藏：`<N>`
- 分享：**`<X>`w**（分播比 **`<X.XX%>`**，[强 / 中 / 弱]）

> **示例**（停止期待 T+7d）：
> - 播放：**71.1w**（落在 `30-100w` 桶内偏高，相对中枢 50w **+42%**）
> - 点赞：2.4w（赞播比 3.38%）
> - 评论：899（评播比 0.126%，**为同期视频之首**）
> - 收藏：5251
> - 分享：**1.8w**（分播比 **2.53%**，强）

> **关键派生比率必须算出来**：赞播比、评播比、分播比——它们是单纯播放数无法暴露的信号。
> 比如视频分析项目发现"分播比"是 TS（议题分享冲动）维度的最强外部代理：求职 0.96% vs 停止期待 2.53%——同 composite 但分播比差 2.6 倍。

### Top 评论关键词

> 把粘进来的 N 条评论分 3-5 类（高赞模因 / 概念引用 / 离题噪声 / 转发暴露暗示 / @朋友传播 等），
> 每类列代表性评论 + 赞数 + 比例。

- **「[关键模因 / 句式]」**: [赞数] 独占 / 高频出现 N 次变体（[简短描述模式]）
- **「[次级模因]」**: [赞数] [次级模式描述]
- **戒断 / 共鸣 / 戏仿 类**: [赞数] [代表性评论]
- **拓展引用**: [其他衍生模式]
- **@朋友传播 / 自嘲共谋**: [评论区是否在做这件事]

> **示例**：
> - **「她不一样」/「他不一样」模因爆发**：2266 赞独占榜首，且全文出现至少 12 次（193、5、5、5、3、4、4、2、2、2、2、1...重复变体），观众**主动套用句式自嘲**——这是关键级模因
> - **「Joker / 小丑 / 舔狗」二级模因**：412 赞「薛定谔的Joker/Crush叠加态」、74 赞「我自己想转圈圈」
> - **戒断方法被认真转译**：27 赞「1.少想 2.别相信美好 3.重构滤镜」——观众主动 RTF
> - **@朋友传播**：大量 @ 链——评论区是社交场，观众把视频当作"骂朋友 / 自嘲共谋"工具

### 哪些预测被验证 ✅ / 推翻 ❌

**被验证 ✅**:
- [关键校准假设是否成立] [带具体数字的对比]
- [推理因素表里哪些被验证]
- [反事实场景里哪个 bucket 被命中]

**被推翻 ❌**:
- [中枢偏差超 ±25% 的话明确写]
- [反事实里"如果 X 意味着 Y"的 Y 是否真的发生]
- [推理因素表里"高置信度"被推翻的项 → rubric bug 信号]

> **示例**：
> **被验证 ✅**:
> - 关键校准假设**完全成立**：本篇 71.1w / 谁问你了 11.7w = **6.07x**，远超我押的 1.5-2x
> - ER=5 主导情感传播力 → **H1 强证据**
> - HP=5 验证：分播比 2.53%，金句"间歇性希望"被高频引用
>
> **被推翻 ❌**:
> - 中枢 50w 被超出 +42%：低估了"她不一样"模因的二创病毒级
> - 反事实推理里"必须搭配强社会议题才能破 30w"**完全错误**——SR=2 也轻松破 70w
> - 我对 SR 的押注（"H2 SR 应上调"）**反向被推翻**：SR 在情感向场景**几乎不贡献**

> **关键纪律**：每条验证 / 推翻必须引用具体数据（"分播比 2.53%"），不许写"基本符合"这种含糊措辞。

### 需要写进 rubric_notes.md 的新观察

1. **[一句话规律标题]**：[具体证据，引用具体数据点]
2. **[第二条规律]**：[同上]
3. **[候选维度命名建议]**：[如观察到 rubric 没捕获的维度，提议候选维度名 + 评分定义草案]

> **示例**：
> 1. **ER 在情感向场景的真实权重应 ≥ ×2.0**：与谁问你了 6x 流量比是 v2 rubric 最强的反事实证据
> 2. **议题分享冲动 (TS) 是隐藏维度**：joker / "她不一样" / 滤镜重构提供了**安全的自嘲身份**，转发不暴露处境，TS=5 的样本
> 3. **HP × ER 共振效应**：ER=5 + HP=5 + 可挪用模因句 = 病毒级；缺一不可
> 4. **"二创句式" 维度候选 (Memetic Shareability, MS)**：观众能不能用作者的句式造句？停止期待 = Y（她不一样无穷变体），谁问你了 = N（无需求信息供给只能引用）

> 每条观察必须可追溯到具体数据点（不写"情感很重要"——写"ER5/SR2 vs ER3/SR4 同 composite 下流量差 6x"）。
> 这些观察会被 `/yang-retro` 自动写到 `rubric_notes.md` 的"观察记录"段。

### Bump 触发评估

- 偏差方向：[high / low / on-target]
- 累计同向偏差：[N 次（包含本次）]
- 是否触发 bump 提议：[是 / 否]

> 如累计同向偏差 ≥3，`/yang-retro` 会在末尾输出"建议跑 /yang-bump"提示。
> 实际 bump 通过 `/yang-bump` 完成，本段只是触发器记录。

## 附录 B：复盘深度格式差异（T+3d / T+7d / T+30d）

不同复盘窗口提供不同深度的分析。T+3d 为快速初判，T+7d 为标准复盘，T+30d 为长周期验证。

### T+3d（快速初判）

**适用场景**：发布后 3 天内的初步数据反馈，流量趋势已可见但未完全释放。

```markdown
## 复盘（T+3d 初判）

**复盘时间**: `<YYYY-MM-DD>`（发布 T+3d）
**抓取时间**: `<YYYY-MM-DD HH:MM>`

### 实绩数据（初判）
- 播放：**`<X>`w**（趋势：[上升 / 趋稳 / 下降]，相对中枢 `<+X% / -X%>`）
- 点赞：`<X>`w（赞播比 `<X.XX%>`）
- 分享：**`<X>`w**（分播比 `<X.XX%>`，[强 / 中 / 弱]）

### 初步判断
- **流量走向**：[爆发中 / 稳步增长 / 已见顶 / 不及预期]
- **中枢偏差方向**：[偏高 / 偏低 / 符合预期]
- **是否需要 T+7d 完整复盘**：[是 / 否（偏差 <15% 且趋势明确）]

> T+3d 不要求完整评论分析和 rubric 观察，只做方向性判断。
> 如果 T+3d 偏差已 >40%，建议立即做一次快速 rubric 诊断。
```

### T+7d（标准复盘）

**适用场景**：发布后 7 天，流量基本释放完毕，数据趋于稳定。这是默认复盘深度。

```markdown
## 复盘（T+7d 标准）

（使用模板主体的完整格式——实绩数据 + Top 评论 + 验证/推翻 + 新观察 + Bump 评估）
```

> T+7d 是标准复盘窗口，所有字段均需填写。模板主体即 T+7d 格式。

### T+30d（长周期验证）

**适用场景**：发布后 30 天，用于验证长尾效应和 rubric 的长期校准。

```markdown
## 复盘（T+30d 长周期）

**复盘时间**: `<YYYY-MM-DD>`（发布 T+30d）
**抓取时间**: `<YYYY-MM-DD HH:MM>`

### 长周期数据
- 播放：**`<X>`w**（T+7d → T+30d 增量：`<+Xw>`，增幅 `<+X%>`）
- 点赞：`<X>`w（赞播比 `<X.XX%>`，vs T+7d `<X.XX%>`）
- 分享：**`<X>`w**（分播比 `<X.XX%>`，vs T+7d `<X.XX%>`）

### 长尾效应评估
- **是否有二波传播**：[是 / 否]（触发原因：[热搜 / KOL 转发 / 算法推荐 / 其他]）
- **评论生态演变**：[评论类型分布是否变化 / 是否出现新模因 / 是否出现争议升级]
- **T+7d 判断是否需要修正**：[是（说明修正点）/ 否]

### Rubric 长期校准信号
- **T+7d 被推翻的项，T+30d 是否被修正回来**：[具体项 + 数据]
- **长尾流量与 composite 的相关性**：[比 T+7d 更强 / 更弱 / 不变]
- **是否需要追加 rubric 观察**：[新增观察 / T+7d 观察已足够]

> T+30d 重点关注 T+7d 判断的修正和长尾效应。不需要重复 T+7d 已确认的验证/推翻项，只写变化。
```

### 复盘深度选择规则

| 条件 | 推荐深度 | 说明 |
|------|---------|------|
| 所有预测 | T+7d | 默认标准复盘 |
| T+7d 偏差 >40% | +T+3d 快速诊断 | 下次预测前先做 T+3d 初判 |
| T+7d 后仍在爆发 | +T+30d | 流量未稳定，需长周期验证 |
| 累计同向偏差 ≥3 | +T+30d | rubric 系统性偏差需长周期确认 |
| 多平台发布 | 每个平台独立 T+7d | 平台间数据不混用 |

## 附录 C：偏差分析标准化输出格式

### 偏差计算规则

```
偏差率 = (实际值 - 预测中枢) / 预测中枢 × 100%

偏差方向判定：
  偏差率 > +25%  → high（实际高于预测）
  偏差率 < -25%  → low（实际低于预测）
  -25% ≤ 偏差率 ≤ +25%  → on-target
```

### 标准化偏差输出格式

```markdown
### 偏差分析

**整体偏差**:
- 播放量偏差：**`<+X% / -X%>`**（实际 `<Xw>` vs 预测中枢 `<Xw>`）
- 偏差方向：`<high / low / on-target>`
- 落入 bucket：`<实际落入的 bucket>`（预测 bucket：`<预测 bucket>`）

**维度级偏差归因**:

| 维度 | 预测分数 | 复盘校准分数 | 偏差 | 归因说明 |
|------|---------|------------|------|---------|
| `<dim>` | `<X>` | `<Y>` | `<±Z>` | [该维度对流量偏差的贡献解释] |

> 复盘校准分数 = 基于实际数据回溯打分，与预测分数对比，量化每个维度的预测偏差。
> 归因说明必须引用具体数据（如"分播比 2.53% 证明 AB 被低估"），不可写"可能有影响"。

**关键偏差信号**:

| 信号类型 | 判定条件 | 本次是否触发 | 说明 |
|---------|---------|------------|------|
| 中枢偏差 > ±40% | 偏差率超阈值 | [是/否] | [说明] |
| Bucket 跨档 | 实际落入非预测 bucket | [是/否] | [说明] |
| 高置信度因素被推翻 | 推理因素表中"高置信度"项被实绩否定 | [是/否] | [说明] |
| 派生比率异常 | 赞播比/评播比/分播比与同类样本偏差 >2σ | [是/否] | [说明] |
| 维度分数系统性偏离 | ≥2 个维度复盘校准分数与预测偏差 >1 分 | [是/否] | [说明] |

**累计偏差追踪**:

| 序号 | 日期 | 作品 | 偏差方向 | 偏差率 | 累计同向次数 |
|------|------|------|---------|--------|------------|
| N | `<date>` | `<title>` | `<high/low>` | `<±X%>` | `<N>` |
```

### 偏差分析纪律

1. **量化优先**：每条偏差必须带具体数字，禁止"基本符合""差距不大"等模糊措辞
2. **归因到维度**：整体偏差必须分解到 rubric 维度级别，不可只写整体
3. **区分噪声与信号**：偏差率 ±15% 以内视为噪声范围，不作为 rubric 修正依据
4. **累计才有意义**：单次偏差不触发 bump，累计同向 ≥3 次才提议 rubric 修正
5. **反例同样重要**：on-target 的预测也要记录，它验证了 rubric 的有效区间
