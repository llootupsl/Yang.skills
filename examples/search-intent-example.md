# 搜索意图选题示例（Channel E）

> 本文档展示一个完整的搜索意图选题流程示例，从用户输入到最终输出。
> 所有数据均为虚构，仅供流程参考。

---

## 输入

```
帮我找一些搜索量高但竞争低的选题
```

---

## 过程

### Step 1: 触发 Channel E

系统识别关键词"搜索量高但竞争低"，判定为搜索意图驱动型选题请求，激活 Channel E（搜索意图选题）。

```
🔍 识别选题模式：搜索意图驱动 → Channel E 优先 + Channel A 辅助
```

### Step 2: 种子词提取

从 `rubric_notes.md` 提取用户垂直领域的核心关键词：

```
📋 种子词提取（来源: rubric_notes.md）

垂直领域: AI工具测评
核心关键词:
  1. "AI工具"       （主种子词，搜索意图信号最密集）
  2. "AI写作"       （细分赛道，长尾机会多）
  3. "免费AI"       （价格敏感型需求，问题型搜索多）
  4. "AI效率"       （场景型需求，内容空白概率高）
  5. "AI替代"       （焦虑型需求，情绪驱动力强）
```

### Step 3: 六种信号拉取

调用 `adapters/search-intent/search_intent.py` 逐源拉取：

```
📡 搜索意图信号拉取 · 种子词: AI工具

[intent:baidu-suggest]  拉取 18 条  ✅
[intent:baidu-related]  拉取 12 条  ✅
[intent:google-suggest] 拉取 15 条  ✅
[intent:zhihu-question] 拉取  8 条  ✅
[intent:bing-suggest]   拉取 10 条  ✅
[intent:longtail]       拉取 25 条  ✅
[intent:content-gap]    拉取  3 条  ✅

信号分布:
  搜索建议: 43条 | 相关搜索: 12条 | 问题型需求: 8条 | 长尾词: 25条 | 趋势查询: 0条 | 内容空白: 3条

去重后总计: 72 条
成功源: 7/7
```

### Step 4: 相关性筛选

对 72 条信号做相关性筛选（与垂直领域"AI工具测评"的相关性评分）：

```
🎯 相关性筛选

筛选标准: 相关性评分 ≥ 0.3

  ✅ 保留: 34 条（相关性 ≥ 0.3）
  ❌ 淘汰: 38 条（相关性 < 0.3）
     - "AI是什么"（0.12，过于宽泛）
     - "AI人工智能发展"（0.18，非测评方向）
     - "AI绘画教程入门"（0.25，偏离工具测评）
     ...
```

### Step 5: 分级

对 34 条筛选后的信号按分级标准归类：

```
📊 分级结果

🅰 高优先（内容空白检测命中 / 多源验证升级）: 3 条
🅱 中优先（搜索建议+问题型 / 单源强信号）: 12 条
🅲 低优先（长尾词 / 弱信号备选）: 19 条
```

## 验证门

本示例的输出可通过以下方式验证：

| 检查项 | 验证方法 | 预期结果 |
|--------|---------|---------|
| Channel E 触发 | 检查是否识别为搜索意图驱动型选题 | 输出包含"Channel E"标识 |
| 种子词提取 | 检查种子词是否从 rubric_notes.md 提取 | 3-5 个核心关键词，非用户手动输入 |
| 六种信号拉取 | 检查是否调用 search_intent.py 拉取6种信号 | 至少4种信号类型有返回结果 |
| 相关性筛选 | 检查低相关性信号是否被过滤 | 相关性 < 0.3 的信号未出现在最终输出 |
| 分级标准 | 检查内容空白检测命中的选题是否为 🅰 | content_gap 类型自动标记高优先 |
| 验证数据 | 检查每个选题是否有 _signal_type 和验证数据 | 每条选题含信号类型 + 搜索量估算/关注数 |
| 搜索量估算 | 检查搜索量是否有锚定依据（排名/关注数） | 搜索量标注来源（百度建议第X位/知乎X关注） |
| 内容空白评分 | 检查内容空白选题是否有评分 | 0-1 范围，≥ 0.6 为高空白 |
| candidates.md 更新 | 检查选题是否写入候选池 | candidates.md 含 Channel E 来源的选题 |
| 多源验证升级 | 检查多通道重叠时是否升级 | Channel E + Channel C 重叠 → 升级为 🅰 |
