# 活人感量化评分示例（Humanness Score）

> 本文档展示一个完整的活人感量化评分流程示例，包含润色前评分→润色→润色后再评分的 Before/After 对照。
> 所有数据均为虚构，仅供流程参考。

---

## 输入

一段 AI 味重的脚本：

```
在当今社会中，人工智能已经成为了推动社会进步的重要力量。据统计，全球有超过数亿用户在使用AI工具，这一数字还在不断增长。

首先，AI工具极大地提升了我们的工作效率。无论是写作、设计还是编程，AI都能显著地减少我们的工作时间，让我们能够更加专注于创造性的任务。

其次，AI工具正在改变我们的学习方式。令人震惊的是，一些AI辅导工具能够根据学生的学习进度，个性化地推荐学习内容，从而极大地提高学习效率。

最后，AI工具也带来了一些令人担忧的问题。不可否认的是，随着AI的普及，一些传统岗位可能会被替代，这无疑是一个令人深思的问题。

综上所述，AI工具是一把双刃剑，我们需要理性地看待它，既要充分利用其优势，也要警惕其潜在的风险。
```

---

## 过程

### Step 1: 润色前评分（Before）

```
🧪 Humanness Score · Before

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

| 维度       | 缩写     | 得分 | 权重 | 加权 | 典型AI特征                     |
|-----------|----------|------|------|------|-------------------------------|
| 开头自然度 | H-OPEN   |  15  | 20%  |  3.0 | "在当今社会中"宏大叙事开场      |
| 论证流畅度 | H-FLOW   |  25  | 15%  |  3.8 | "首先…其次…最后…"三段式         |
| 修饰具体度 | H-SPEC   |  40  | 20%  |  8.0 | "极大地""显著地""不断增长"      |
| 结构多样性 | H-STRUCT |  30  | 15%  |  4.5 | 全文排比，每段结构相同           |
| 情绪真实度 | H-EMOT   |  20  | 15%  |  3.0 | "令人震惊""令人担忧""令人深思"  |
| 人设一致度 | H-PERSONA|  10  | 15%  |  1.5 | 无个人痕迹，上帝视角             |

总分: 23.8 → 24 🔴 AI味重 → 必须润色

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🔴 等级判定: AI味重（0-30分）
   建议: 必须润色，执行全量 L1-L4
```

### Step 2: 润色执行

```
🔧 润色执行 · 强度: 全量 L1-L4

L1 禁用词扫描:
  ✗ "在当今社会中" → 删除，直接场景切入
  ✗ "极大地" → 替换为具体数字
  ✗ "显著地" → 替换为具体描述
  ✗ "令人震惊的是" → 替换为真实感受
  ✗ "不可否认的是" → 删除让步句式
  ✗ "令人担忧" → 替换为私人感受
  ✗ "令人深思" → 替换为个人判断
  ✗ "综上所述" → 删除，自然收束
  L1 扫描结果: 8 处命中，全部修复

L2 风格一致性:
  ✗ 冒号使用 → 替换为逗号或断句
  ✗ 双引号过度使用 → 减少至必要处
  L2 检查结果: 2 处命中，全部修复

L3 内容质量:
  ✗ "数亿用户" → 缺乏具体来源，替换为可验证数据
  ✗ "双刃剑" → 陈词滥调，替换为个人判断
  L3 检查结果: 2 处命中，全部修复

L4 活人感终审:
  ✗ 全文无人称 → 注入"我"视角
  ✗ 无具体场景 → 加入个人经历锚点
  ✗ 无口癖/情绪表达 → 加入人设档案中的表达方式
  L4 检查结果: 3 处命中，全部修复
```

### Step 3: 润色后脚本

```
上周我用AI写了一篇稿子，3分钟出稿。然后又花了2小时改它。

说实话，我一开始是拒绝用AI的。觉得写出来的东西没灵魂。但当我发现用它改简历能多拿3倍面试的时候，我改主意了。

我现在写东西的流程是这样的：先让AI出个初稿，然后我自己改。改什么？改那些"极大地""显著地"——这些词一看就是机器写的。我换成具体的数字，比如"3天涨了200粉"。

学习这块我也试过。我表弟高考，用AI刷题，说比自己看书效率高。我不知道是不是真的，但他成绩确实从年级200名到了80名。

不过我也被坑过。我有个做设计的朋友，上个月被裁了。他老板说，AI能干的活不需要那么多人。这话听着刺耳，但可能是实话。

AI不是什么双刃剑。它就是个工具。用好了省时间，用差了省工作。
```

## 验证门

本示例的输出可通过以下方式验证：

| 检查项 | 验证方法 | 预期结果 |
|--------|---------|---------|
| 6维度完整性 | 检查 Before/After 评分是否包含全部6维度 | H-OPEN/H-FLOW/H-SPEC/H-STRUCT/H-EMOT/H-PERSONA 均有评分 |
| 评分范围 | 检查每维度评分是否在 0-100 范围内 | 所有分数 ≥ 0 且 ≤ 100 |
| 加权计算 | 检查加权分 = 维度分 × 权重 | 每维度加权分与维度分和权重一致 |
| 总分计算 | 检查总分 = Σ(加权分) | 总分等于6维度加权分之和 |
| 等级判定 | 检查等级与总分范围匹配 | 🔴0-30 / 🟠31-50 / 🟡51-70 / 🟢71-85 / 🔵86-100 |
| Before/After 对照 | 检查是否输出量化变化 | 含总分变化 + 每维度变化 + 具体改进说明 |
| 润色强度判定 | 检查润色强度与 Humanness Score 匹配 | 总分 < 30 → 全量 L1-L4 |
| L1 扫描完整性 | 检查禁用词/套话是否全部命中 | "在当今社会中""极大地""令人震惊"等全部扫描出 |
| L4 终审 | 检查是否注入人称/场景/口癖 | 润色后脚本含"我"视角 + 具体场景 + 情绪表达 |
| 改进说明 | 检查每维度变化是否有具体 Before→After 对照 | 每维度含原文特征 → 润色后特征的说明 |
