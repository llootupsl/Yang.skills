# Migration: v1.3 → v1.4

## WHAT

rubric 文件拆分 + blind channel 完整性强化：

- `rubric_notes.md` 拆分为：
  - `rubric_notes.md`：公式 + 通用维度定义（blind 白名单可见）
  - `rubric-memo.md`：升级 Memo 含证据 + 派生证据（blind 硬禁读）
- `state` 字段不变，仅 `schema_version` bump 标识老用户须跑迁移

## WHY

yang-score-blind sub-agent 的 channel B 隔离协议：blind sub-agent 若读到 rubric_notes.md 里的实绩（播放数、点赞数），会污染盲评的独立性。

## HOW

```python
state["schema_version"] = "v1.4"
# 文件层面：手动将 rubric_notes.md 中的升级 Memo 段（含 ## 升级 Memo、含实绩数据）提取到 rubric-memo.md
```

## Manual fallback

1. 打开 `rubric_notes.md`
2. 找到 `## 升级 Memo` 段及后续所有含实绩数据的 memo 条目
3. 剪切到新文件 `rubric-memo.md`
4. 在 `rubric_notes.md` 原位置留引用：`> 升级 Memo 已移至 rubric-memo.md`
5. 改 `.yang-state.json` 的 `schema_version` 为 `"1.4"`

**不跑 migrate 的后果**：blind sub-agent 仍会读到 rubric_notes.md 里的实绩，sub-agent 会自报 `non_blind_warning` 并降所有 confidence 到 medium——可用但不再是"真盲"。**BREAKING for blind channel integrity**。
