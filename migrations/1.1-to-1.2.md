# Migration: v1.1 → v1.2

## WHAT

`shoots[]` 数组项 schema 扩展，新增 5 个字段记录"拍后改稿是否触发 v2 预测重判"：

| 新增字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `scripts_path` | string / null | `null` | 拍摄稿文件路径 |
| `script_consistency` | string | `"consistent"` | "consistent" / "minor_changes" / "major_rewrite" |
| `script_diff_pct` | float / null | `null` | 与原始 prediction 的文本差异百分比 |
| `v2_prediction_written` | bool | `false` | 是否已触发 v2 预测重判 |
| `script_hash_at_shoot` | string / null | `null` | 拍摄时稿子内容的 hash |

## WHY

yang-shoot 检测到拍摄稿与原 scripts 有重大偏离时自动调用 yang-predict 写 `## 预测 v2` 段。yang-retro 需要知道读 v1 还是 v2。

## HOW

```python
state["schema_version"] = "v1.2"
# shoots 中的老条目补默认值
for shoot in state.get("shoots", []):
    shoot.setdefault("scripts_path", None)
    shoot.setdefault("script_consistency", "consistent")
    shoot.setdefault("script_diff_pct", None)
    shoot.setdefault("v2_prediction_written", False)
    shoot.setdefault("script_hash_at_shoot", None)
```

## Manual fallback

老 state 缺少这些字段时，所有 skill 用 `state.get(field, default)` 兜底。**不强制跑迁移**，但迁移后字段对齐 schema 文档。
