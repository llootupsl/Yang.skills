# Migration: v1.2 → v1.3

## WHAT

新增 2 个字段跟踪 blind scoring 的 contamination 状态：

| 新增字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `last_prediction_self_scored` | bool | `false` | 上一次 `/yang-predict` 是否走了 `--skip-blind` flag 或 Phase 2.5 用户选 b |
| `last_self_scored_at` | ISO 8601 / null | `null` | `last_prediction_self_scored` 触发时的时间戳 |

## WHY

把 contamination 跟踪从"靠 git history"升级为"靠 state 字段"。yang-status / SessionStart hook 据此 nag："上次预测没走 blind sub-agent，已 N 天"。

## HOW

```python
state["schema_version"] = "v1.3"
state.setdefault("last_prediction_self_scored", False)
state.setdefault("last_self_scored_at", None)
```

## Manual fallback

老 state 缺这两字段 → 兜底 `false` / `null`，**MINOR 兼容**。无需强制迁移。
