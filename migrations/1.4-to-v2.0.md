# Migration: v1.4 → v2.0

## WHAT

MAJOR schema 升级——新增 6 个字段 + schema_version 大版跃迁：

### 新增字段

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `persona_exists` | bool | `false` | 是否已建立创作人设档案 |
| `persona_version` | string / null | `null` | 人设档案版本号 |
| `persona_name` | string / null | `null` | 人设名称 / 用户身份 |
| `persona_history` | array | `[]` | 人设变更历史记录 |
| `competitor_count` | int | `0` | 竞品数量 |
| `calibration_records` | array | `[]` | 校准记录列表（每次 retro 的维度分 + 实绩对） |

### schema_version
`"1.4"` → `"v2.0"`

## WHY

1. 新增活人感润色引擎（yang-polish）和创作人设档案（yang-persona），需扩展 state schema
2. 竞品系统集成，需 competitor 相关字段
3. calibration_records 为 Bayesian 校准和自动 bump 提供结构化数据源

## HOW

```python
import os, json

state_path = os.path.join(os.getcwd(), ".yang-state.json")

with open(state_path) as f:
    state = json.load(f)

state["schema_version"] = "v2.0"
state.setdefault("persona_exists", False)
state.setdefault("persona_version", None)
state.setdefault("persona_name", None)
state.setdefault("persona_history", [])
state.setdefault("competitor_count", 0)
state.setdefault("calibration_records", [])

with open(state_path + ".tmp", "w") as f:
    json.dump(state, f, indent=2, ensure_ascii=False)
os.replace(state_path + ".tmp", state_path)
```

## Manual fallback

1. 编辑 `.yang-state.json`，改 `schema_version` 为 `"v2.0"`
2. 添加字段：
   ```json
   "persona_exists": false,
   "persona_version": null,
   "persona_name": null,
   "persona_history": [],
   "competitor_count": 0,
   "calibration_records": []
   ```
