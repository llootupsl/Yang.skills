# v5.1 → v6.0 迁移指南

## 概述

v6.0 是一次 MAJOR 升级，新增搜索意图研究、活人感量化评分、渐进式加载机制和双架构支持。

## 变更清单

### 1. 新增搜索意图适配器

- **路径**: `adapters/search-intent/`
- **文件**: `search_intent.py`
- **功能**: 6种搜索意图信号（搜索建议/相关搜索/问题型需求/长尾关键词/趋势查询/内容空白检测）
- **依赖**: `pip install requests`（零API Key）
- **迁移动作**: 无需手动操作，文件随 Skill 包分发

### 2. 新增活人感量化评分协议

- **路径**: `shared-protocols/humanness-score.md`
- **功能**: 6维度0-100分评分（H-OPEN/H-FLOW/H-SPEC/H-STRUCT/H-EMOT/H-PERSONA）
- **与 yang-score 映射**: Humanness Score < 50 → QL 降1分；各维度 < 30 → 对应 yang-score 维度降1分
- **迁移动作**: 无需手动操作，yang-polish 和 yang-score 自动关联

### 3. 新增统一适配器接口

- **路径**: `adapters/adapter_base.py` + `adapters/registry.py`
- **功能**: 统一的适配器注册、发现和调用接口
- **迁移动作**: 无需手动操作，新文件随 Skill 包分发

### 4. 新增渐进式加载机制

- **配置**: SKILL.md frontmatter 中 `loading-strategy: progressive`
- **行为**: 首次加载只读紧凑核心规则段（~300 tokens），按需加载子skill
- **迁移动作**: 无需手动操作，Agent 自动遵循加载策略

### 5. yang-seed 从四通道升级为五通道

- **新增**: Channel E（搜索意图选题）
- **种子词来源**: rubric_notes.md 提取 + 用户输入兜底
- **迁移动作**: 无需手动操作，yang-seed 自动启用 Channel E

### 6. Humanness Score 与 yang-score 的映射关系

| Humanness Score 维度 | yang-score 维度 | 映射关系 |
|---------------------|----------------|---------|
| H-OPEN（开头自然度） | HP（钩子力） | H-OPEN<30 → HP降1分 |
| H-FLOW（论证流畅度） | QL（文案力） | H-FLOW<30 → QL降1分 |
| H-SPEC（修饰具体度） | QL（文案力） | H-SPEC<30 → QL降1分 |
| H-STRUCT（结构多样性） | SR（节奏力） | H-STRUCT<30 → SR降1分 |
| H-EMOT（情绪真实度） | ER（情绪力） | H-EMOT<30 → ER降1分 |
| H-PERSONA（人设一致度） | AB（人设力） | H-PERSONA<30 → AB降1分 |

**综合规则**: Humanness Score 总分 < 50 → QL 额外降1分（叠加维度降分）

## State Schema 变更

`schema_version` 从 `"v2.1"` 升级到 `"v2.2"`。

新增字段（均使用 `.get()` 兜底，向后兼容）：

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `search_intent_enabled` | bool | true | 搜索意图适配器是否启用 |
| `humanness_score_enabled` | bool | true | Humanness Score 评分是否启用 |
| `loading_strategy` | string | "progressive" | 加载策略 |

## 迁移步骤

1. **确认当前版本**: 检查 `.yang-state.json` 中 `schema_version` 为 `"v2.1"`
2. **备份**: `cp .yang-state.json .yang-state.json.bak.v2.1-v2.2.$(date +%Y%m%dT%H%M%S)`
3. **更新 schema_version**: 将 `.yang-state.json` 中 `schema_version` 改为 `"v2.2"`
4. **添加新字段**: 在 `.yang-state.json` 中添加 `search_intent_enabled: true`、`humanness_score_enabled: true`、`loading_strategy: "progressive"`
5. **验证**: 运行 `/yang-status` 确认系统正常

## 回滚方案

- 恢复备份: `cp .yang-state.json.bak.v2.1-v2.2.* .yang-state.json`
- 回滚窗口: 迁移后 24 小时内可安全回滚
- 回滚数据损失: 无（新字段使用默认值兜底）

## 风险评估

**综合评级**: 🟢 低风险

- 无字段删除
- 无语义变更
- 新增字段均有默认值
- 搜索意图适配器为可选功能，失败不影响核心闭环
