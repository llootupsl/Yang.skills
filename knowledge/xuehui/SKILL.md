# 短视频内容创作与运营体系知识库

> **核心框架**：粉丝经济原理 → 商业定位 → 内容定位
> 三位一体的打法体系，从底层原理到商业设计到内容执行的一贯逻辑。
>
> **体系索引**：流量结构 → 选题方法 → 钩子系统 → 骨架系统 → 情绪系统 → 叙事系统 → 运营系统

## 一、核心理念与三大体系总览

### 1.1 体系架构

完整的短视频创作与运营体系分为三层递进结构：

```
                                                    ┌─────────────────────────┐
                                                    │       内容定位体系         │
                                                    │  三有原则 / 四大脚本类型    │
                                                    │  情绪刺点 / 多维高频更新    │
                                                    └────────────▲────────────┘
                                                                 │
                              ┌──────────────────────────────────┤
                              │                                  │
                   ┌──────────┴──────────┐                       │
                   │     商业定位体系      │                       │
                   │ 变现方式 / 有/无产品   │                       │
                   │ 商业定位决定拍什么     │                       │
                   └──────────▲──────────┘                       │
                              │                                  │
                   ┌──────────┴──────────┐                       │
                   │    粉丝经济原理      │                       │
                   │ 产品满足需求          │                       │
                   │ 人物制造偏好          │                       │
                   └─────────────────────┘                       │
```

**三位一体的核心逻辑**：不是孤立的三门课，而是从底层原理到商业设计再到内容执行的一贯逻辑。先理解为什么（原理），再决定怎么赚钱（商业），最后确定拍什么（内容）。

### 1.2 三种经济形态对比

做短视频之前，必须首先认清自身所处的经济形态。市场上存在三种主流的经济形态：

| 形态 | 投入 | 风险 | 特点 | 推荐度 |
|------|------|------|------|--------|
| **粉丝经济** | 经济投入低，行动成本高（需耐心+时间） | 低 | 基于人的信任和偏好，用户为人买单 | ★★★★★ |
| **品牌经济** | 经济投入高 | 中 | 基于品牌认知和忠诚 | ★★★☆☆ |
| **流量经济** | 经济投入高（投流） | 高 | 基于流量本身做低转化变现，来得快去得快 | ★☆☆☆☆ |

**核心判断**：粉丝经济经济投入最低、风险最小。它的难度不在金钱，而在行动成本——需要耐心和时间持续产出内容。品牌经济需要大量资金投入建设品牌认知。流量经济高度依赖投流费用，一旦停止投流则流量归零，风险极高。

## 二、粉丝经济原理

### 2.1 核心公式

**产品满足需求，人物制造偏好**

- **产品**解决的是"我需要"（理性决策）
- **人物**制造的是"我想要你这个人"（偏好/感性决策）
- 粉丝经济的本质：用户不是因为产品而买单，而是因为你这个人而买你的产品

### 2.2 核心案例：农民卖樱桃

一位山东烟台的农民大哥在网上卖樱桃。消费者在楼下超市也能买到樱桃，价格可能还更便宜，但消费者选择在网上购买。原因在于：大叔通过短视频展示了自己的故事和形象——一个朴实的农民、在田间地头辛苦劳作、樱桃从树上摘下来直接发货。消费者看到这些画面后产生了情感共鸣，在"帮助一个辛苦的农民"和"在超市随便买一盒"之间，情感驱动选择了前者。

**案例启示**：当产品相同时，消费者为人物买单。人物制造了偏好，偏好超越了产品本身的功能价值。

### 2.3 行业延伸：非标准化产品行业中人的决定性作用

在以下行业中，人几乎等于一切，因为产品本身就是人：

| 行业 | 人的作用 |
|------|----------|
| **理发** | 消费者因为信任某个理发师而一直找他，换了发型师就不放心 |
| **婚纱摄影** | 消费者看到摄影师拍照的过程，对其产生信任和兴趣 |
| **教育** | 家长因为信任某个老师而选择让他辅导孩子 |
| **装修** | 业主看到工长认真负责的工作过程，产生信任 |
| **医疗美容** | 消费者看到医生的专业操作过程，建立信任 |

**结论**：在这些非标准化产品行业，做好个人IP比做好产品介绍重要一百倍。展示过程、展示专业度、展示为客户的付出，远比罗列产品参数有效。

### 2.4 粉丝经济的行动逻辑

1. **先让人认识你**：通过内容让用户看到你是一个怎样的人
2. **再让人信任你**：通过持续输出价值（知识/过程/观点/故事），建立信任关系
3. **最后让人为你买单**：信任累积到一定程度，变现自然发生

## 三、商业定位体系

### 3.1 核心原则

**做短视频，第一步永远先做商业定位。**

商业定位决定账号拍什么内容。有产品的人应明确如何通过内容定位把产品卖出去；没产品的人要先选好产品。许多创作者做短视频时容易陷入误区——先想自己的特点、爱好、擅长什么，而不是先想商业定位。结果是账号火了但无法变现。

### 3.2 三种变现方式详解

| 方式 | 适合人群 | 操作逻辑 | 推荐度 |
|------|----------|----------|--------|
| **卖货和引流** | 普通人 | 挂小黄车卖货，视频或直播展示产品；引流为实体店吸引顾客，300粉丝即可开始变现 | ★★★★★ |
| **广告** | 大V | 不推荐。广告主更愿意自己做号，预算持续减少，接广告需要几百万粉丝基数 | ★☆☆☆☆ |
| **打赏** | 极少数人 | 金字塔尖少数人能赚钱（万人直播间），底层主播收入极低。不推荐普通人尝试 | ★☆☆☆☆ |

### 3.3 有产品的情况

有产品的人执行路径：
1. 明确自身产品是什么
2. 思考目标人群是谁
3. 通过内容定位设计——拍什么内容能让目标人群对自己的产品产生兴趣
4. 四类脚本并行（观点/过程/知识/故事），兼顾流量和成交

### 3.4 没产品的情况

没产品的人最容易走弯路——幻想先积累粉丝，粉丝多了再变现。实际应该：

**先选一个产品，再做内容。**

带货分为三个层级：

| 层级 | 成功率 | 适合人群 | 说明 |
|------|--------|----------|------|
| **单品类** | 高 | 新手/普通人 | 只带一个品类/一个产品，精准度高 |
| **赛道类** | 中 | 有IP基础的创作者 | 带一个赛道内的多种产品 |
| **全品类** | 低 | 大明星/1000万粉以上大网红 | 什么都带，精准度极低 |

**运营思路**：
1. 选一个商品
2. 围绕这个商品多拍视频（不是发纯广告，而是用四种脚本类型包装）
3. 300粉丝就开始变现
4. 做好单品后做出IP
5. 有IP后扩赛道（例如：卖地瓜的IP成功后，夏天扩到卖地瓜苗、大鹅等农产品）

**推荐的高利润率品类**：尿不湿、挖耳勺、削皮器、油污净等——这些日常消费品利润率高、复购率高、展示效果好。

### 3.5 单品→IP→扩赛道路径

经典案例：
- **卖地瓜案例**：通过拍地瓜相关视频（晒收获过程、教怎么挑地瓜、讲地瓜的故事），形成小IP后，夏天不卖地瓜时卖地瓜苗、大鹅等农产品，从单品成功扩到赛道
- **卖蒜苔案例**：通过大量发布关于蒜苔的视频，打造出IP后，开始卖松花蛋、大馒头等农产品
- **卖流心披萨案例**：一个4000粉丝的账号，一场带货能达几十万，正常一天能带两万块钱货

### 3.6 资产与负债思维

| 状态 | 属性 | 说明 |
|------|------|------|
| 有产品无流量 | **负债** | 库存积压、租金照付、无销售渠道 |
| 有粉丝/私域群 | **资产** | 粉丝不会蒸发，能持续提供价值 |
| 有实体店无线上流量 | **负债** | 疫情等特殊时期少了流量环就不赚钱 |

**关键认知**：抖音粉丝不会蒸发，一旦积累就是永久资产，能持续提供变现价值。

## 四、内容定位体系

### 4.1 内容定位的核心原则

做短视频不能把它当成淘宝货架——光展示产品没人看。应该像**钓鱼**一样，用用户喜欢的内容作为鱼饵，输出既能结合自身行业又能保证质量的内容。

内容定位三大核心原则：

1. **多维**：一个账号应出多个主题，不能只出一个主题。多主题提供更多的成交理由。例如：少儿篮球培训机构可以拍「教练指导孩子动作」+「过往成功履历」+「家长真实反馈」等多个主题维度。

2. **原生感**：让人看到的就是真实的自己，不装。原生感意味着内容让观众感知到"这是真实发生的"，而不是精心编排的表演。原生感越强，越能顺理成章地变现。

3. **高频**：想让人记住自己，不能指望一个视频。要多出现、多被刷到。消费者的购买决策往往是经过多次触达后才做出的——第一次看到产生印象，第二次看到产生兴趣，第三次看到才可能下单。

### 4.2 运营漏斗模型：三种形态

```
第一种（最差）：
大量流量 → 无商业定位 → 100万粉丝也不赚钱

第二种（中间）：
有流量 → 内容方向/个人IP/商业定位有问题 → 无法变现

第三种（最佳）：
个人IP足 → 粉丝少但变现能力强
```

**变现关键**：所有的定位是为了最大化变现服务。应先考虑变现，跑通变现后再考虑放大流量。例如晒过程脚本最能最大化变现，就应先重点学习晒过程脚本的写法，跑通变现后再提高流量。

### 4.3 三有原则

**有用处、有兴趣、有共鸣** —— 内容是否值得被传播的三重判断标准。

| 维度 | 含义 | 典型点赞动机 |
|------|------|-------------|
| **有用处** | 内容对用户有实际价值 | "学了有用""收藏了""学到了" |
| **有兴趣** | 内容让用户觉得有意思/解压 | "好解压""真有趣""太上头了" |
| **有共鸣** | 内容让用户产生情感认同 | "这就是我！""太真实了""说得太对了" |

**应用标准**：每条内容至少满足其一，三者兼具 = 爆款体质。

三有原则的具体应用示例：
- **有用处**：教知识类视频（如何瘦脸、如何收纳、如何选品）
- **有兴趣**：修驴蹄子、掏耳朵、解压视频
- **有共鸣**：关于中国父母与孩子关系的讨论、职场人的困境、宝妈的时间焦虑

## 五、素材库搭建体系

### 5.1 素材库的核心概念

专业编导和内容创作者的灵感并非凭空而来。大部分创作灵感来自见过的优秀作品的影子。普通人要持续输出内容，必须搭建素材库——就像乐高的零件盒子，里面装着各种内容创意零件，创作时从中提取组合。

### 5.2 五大素材文件夹

| 文件夹 | 内容 | 来源与方法 |
|--------|------|------------|
| **1. 选题** | 拆解别人的好选题，积累选题库 | 行业词+关键词 → 百度/抖音话题项搜索/巨量算数关联分析 |
| **2. 脚本结构** | 拆解别人的结构框架 | 对标账号拆解 |
| **3. 开篇结尾** | 好的开头和金句结尾直接收录 | 刷视频记录 + 小红书 + 微信公众号改编 |
| **4. 呈现方式** | 拍摄形式/BGM/转场/画面风格 | 跨领域借鉴：同平台跨领域 / 跨平台同领域 / 跨平台跨领域 |
| **5. 音乐** | 情绪音乐分类存放 | 十二种主流情绪的120首经典BGM + 70首赛道流量BGM |

### 5.3 选题搜索三步法

**第一步：百度搜索**
使用公式「行业词 + 关键词」搜索。关键词维度包括：时间、地点、人群、行业细分、年纪、场景。
- 示例：做服装行业，行业词=牛仔裤，关键词=胖子 → 输入百度找到「大家都在搜」，看是否有合适的选题 → 如果有，继续点开该词条下的「大家都在搜」→ 层层深挖找到适合自己的选题。

**第二步：抖音话题搜索**
抖音综合搜索 → 向右找到「话题」点击 → 找到最热的话题点击 → 拆解拍得最好的人的视频结构和选题。

**第三步：巨量算数关联分析**
输入赛道关键词 → 点击「关联分析」→ 向下找到雷达图 → 找到关联关键词 → 随意组合关键词找出新话题 → 把组合话题输入搜索框搜索 → 选择想拍的视频拆解 → 把适合的选题装入素材库。

### 5.4 蹭热点的正确方法

结合账号定位和人群定位，在金热榜、微博热搜、抖音热榜获取热点。**不结合定位的蹭热点 = 无效流量**。蹭热点的前提是该热点是你目标用户群体关心的话题。

### 5.5 金句收集

金句是视频的最后一句话或某段落的结尾，短而有力量，能让观众瞬间上头有情绪。好的金句能大幅提升视频的质量。

收集来源：
- **知乎**：搜索「鼓舞人心的句子」「安慰人的句子」等，对应自己的赛道改编
- **对标账号**：刷视频时记录好的结尾金句
- **小红书/微信公众号**：好的文案结尾直接改写适配

金句按情绪分类存放：潇洒、金钱、警告、励志、爱情、亲情、友情。

### 5.6 对标账号与呈现方式

**找对标账号的核心原则**：
- 不要找表现不好的账号对标（学不到东西）
- 不要找头部账号的呈现方式雷同（你无法复制头部的影响力）
- **差异化策划**：同平台跨领域、跨平台同领域、跨平台跨领域
- **呈现方式借鉴原则**：同领域找选题，跨领域找呈现方式

## 六、爆款元素体系（八大元素）

### 6.1 散弹枪原则

**话题被越多用户感兴趣，流量就会越大。**

多发多测，不赌一条。流量是概率游戏，用大量内容覆盖更多可能爆的话题。小透明的生活没人感兴趣，想要在短视频平台获取流量做出爆款，需要好的选题。

### 6.2 八大爆款元素

**成本、人群、奇葩、反差、最差、头牌、怀旧、荷尔蒙**

| 元素 | 含义 | 应用示例 |
|------|------|----------|
| **成本** | 金钱/时间/人力的极致约束 | "100元吃遍一座城""1块钱在上海过一天""5000块钱服装创业" |
| **人群** | 锚定特定人群标签 | "158cm120斤微胖女生穿搭""95后裸辞摆摊卖土豆泥""宝妈必看""天生喝凉水都长胖的" |
| **奇葩** | 少见、奇怪或反常识 | 奢侈品盘点、奇葩商品测评、"一天只吃黑色的食物" |
| **反差** | 预期与实际之间的巨大落差 | 土味穿搭博主秒变时尚、乞丐秒变型男、"让外卖小哥管理一天公司" |
| **最差** | 极限低点的挑战/展示 | "大牌口红里的丑东西""全网最难吃的……" |
| **头牌** | 借势大牌/明星/标杆 | "#明星同款""#李佳琦推荐""尹正同款蒸菜减脂餐""劳斯莱斯级……" |
| **怀旧** | 勾起过去的回忆 | "90后童年零食""校门口的路边摊""复刻90年代校门口路边摊""复刻十年前……" |
| **荷尔蒙** | 颜值/身材/性吸引力 | 帅哥/美女相关视觉内容 |

**使用原则**：一条视频至少蕴含一个元素，元素越多越容易爆。在选题阶段就用这八个元素检视自己的选题是否有吸引力。

### 6.3 八大元素实战应用——将普通选题爆款化

以五大常见赛道为例，展示如何给普通选题加入爆款元素：

**① 吃饭赛道**
- 成本：1000块钱吃一顿外卖 / 一分钱不花吃到撑
- 奇葩：一天只吃黑色的食物
- 怀旧：复刻90年代校门口路边摊
- 头牌：尹正同款蒸菜减脂餐

**② 服装赛道**
- 成本：50块钱搭一身潮女服装 / 100块钱打造一身甜妹装 / 一件T恤搭配一周不重样
- 人群：158cm微胖女生 / 小个子女生穿搭

**③ 创业赛道**
- 成本：5000块钱服装创业
- 人群：95后裸辞摆摊卖土豆泥
- 反差：让外卖小哥管理一天公司

**④ 减肥赛道**
- 人群：天生喝凉水都长胖的、大肚子、大基数小基数、居家的
- 成本：一个星期花200块钱减掉十斤 / 一个星期不节食不运动能不能减掉十斤

### 6.4 主题IP

> 来源：12天实操班Chapter.3 / 第5课

从一个受欢迎的选题可以发展出一个系列的主题IP——类似电视剧和综艺的季播模式：
- "测评50位明星的减肥法"
- "100块钱吃遍全国早市"
- "每天复刻一个校门口的路边摊"

主题IP能形成持续期待感，让观众追更。

#### 6.4.1 主题IP常见内容类型8类

| 序号 | 内容类型 | 对应三有原则 | 典型示例 |
|------|----------|-------------|----------|
| 1 | **教程类** | 有用处 | — |
| 2 | **推荐类** | 有用处 | — |
| 3 | **美好类** | 有兴趣 | 萌宠、颜值、风景 |
| 4 | **炫技类** | 有兴趣 | 日记Vlog |
| 5 | **恶搞类** | 有兴趣 | 爱情攻略 |
| 6 | **情感类** | 有共鸣 | 经典语录 |
| 7 | **励志类** | 有共鸣 | 奋斗、理想 |
| 8 | **吐槽类** | 有共鸣 | 工作、生活 |

#### 6.4.2 主题IP方法4种

> 原则：简单易懂 + 时间 + 三有原则 + 风格独特

| 序号 | 方法 |
|------|------|
| 1 | **名字 + 垂直词汇** |
| 2 | **人群 + 垂直词汇** |
| 3 | **地域 + 垂直词汇** |
| 4 | **场景 + 垂直词汇** |

### 6.5 人群垂直 vs 赛道垂直

做账号应该是**人群垂直**而非赛道垂直。观众的兴趣标签是多元的，不会只关注一个赛道的内容。如果一个账号的选题过于杂乱，观众难以判断账号定位，影响涨粉和变现——也不太会在这样的账号上消费。

### 6.6 内容配比

> 来源：12天实操班Chapter.5 / 第5课 / 薛辉课程

| 比例 | 内容类型 | 作用 |
|------|----------|------|
| **90%** | 赛道内容（主线） | 让观众知道账号主营价值，核心变现内容 |
| **10%** | 人群内容（辅线） | 丰富多元内容，延伸人群价值，让观众更喜欢 |

**核心原则**：以赛道内容为主、人群内容为辅。自己核心变现的内容要占90%，其他类选题只能占10%。让观众知道账号的主线和能提供的专项价值，同时丰富内容使观众更喜欢。

## 七、创作方法论

### 7.1 情绪波点理论

**创作的来源不是"灵机一动"，而是生活中引起情绪波动的事件（情绪波点）。**

- 一个作品可以没头没尾，但**必须要有情绪**。两条简单却有情绪的视频能获得高赞，而技术好但没有情绪的视频则不火。
- 打开「观察情绪」的功能开关，情绪波点无处不在。生活中每一个引起你情绪波动的事件——儿子弄坏口红、发现怀孕、被老板骂、看到感人的新闻——都是创作素材。
- 很多博主看似每天都有新内容，实际上每个视频背后都有一个情绪波点支撑。

**三种创作转化路径**（基于情绪波点）：

| 情绪波点 → | 转化方式 | 产出脚本类型 |
|-------------|----------|-------------|
| 回忆 | 回忆过往相关经历 | 故事型脚本 |
| 行动 | 采取行动、记录过程 | 过程型脚本 |
| 分析 | 理性分析事件背后的道理 | 知识型/观点型脚本 |

**创作过程**：有了情绪波点 → 通过回忆/行动/分析，将一个点拉成一条线 → 创作成完整的视频。

### 7.2 创作被打断的两大原因

1. **说自己不行**：缺乏自信，认为自己没有能力创作
2. **顾忌太多**：担心创作的方向不对、担心行动是否有必要、担心别人怎么看

很多人在创作时会因为顾忌而拖延甚至不行动。应对方法：做生活中的勇敢者，不要被局限，先行动再优化。有行动才会有记录，有记录才会有作品。

### 7.3 作品自检清单（7个核心问题）

每创作一条内容前，用以下7个问题自检：

| 序号 | 检查维度 | 核心问题 |
|------|----------|----------|
| 1 | 信息有效 | 内容让用户觉得有用？有趣？有共鸣吗？ |
| 2 | 信息关联 | 内容与精准粉丝关联度高吗？ |
| 3 | 内容趣味 | 内容是用户觉得不枯燥的吗？ |
| 4 | 行动成本 | 内容是用户很容易就能学会的吗？ |
| 5 | 发生频次 | 内容是用户频繁发生的难题吗？ |
| 6 | 内容持续 | 内容是可持续延伸的吗？ |
| 7 | 内容价值 | 内容是能够落地解决问题的吗？ |

## 八、文案写作体系

### 8.1 文案在脚本创作中的定位

文案在脚本创作中重要性并非第一——创作不依赖文案。很多人不会写文案是因为不知道文案到底是什么。

### 8.2 文案写作核心方法论

**核心心法：把"写文案"变成"说画面"。**

**好文案 = 一个特写镜头 = 画面感 + 力量感**

### 8.3 画面感

好的文案能给人带来画面感。

**方法一：描述（把不具体的事物描述成具象的画面）**
- 差文案：空洞无物，让人听不懂
- 好文案：用具体的描述来表达，不说空洞的话
- **写作铁律**：多用动词、名词、量词，少用成语和描述形状的形容词。说村东头老太太都能听懂的话。

**方法二：类比（把一件不具体的事物类比成具象的事情）**
- 练习示例：
  - "苹果电脑很薄" → 类比为"薄到可以夹在一本书里不被发现"
  - "小宝宝的皮肤很嫩" → 类比为"嫩得像刚剥壳的煮鸡蛋"

#### 8.3.1 文案训练题

> 来源：第7课

通过以下训练题练习用描述或类比的方法写出有画面感和力量感的文案：

| 训练题 | 训练目标 | 参考答案 |
|--------|----------|----------|
| "苹果电脑很薄" | 类比法 | 薄到可以夹在一本书里不被发现 |
| "小宝宝的皮肤很嫩" | 类比法 | 嫩得像刚剥壳的煮鸡蛋 |
| 表达"帅" | 描述法/类比法 | 用具体的画面描述帅的感觉 |
| 表达"纠结" | 描述法/类比法 | 用具体的画面描述纠结的感受 |
| 表达"忐忑" | 描述法/类比法 | 用具体的画面描述忐忑的状态 |

**训练要点**：不要再写空洞无物的文案，要写出能让人听懂、有情绪的文案。好的文案就是一个特写镜头，特写镜头由画面感和力量感带来。

### 8.4 特写镜头

好的文案就是一个特写镜头。标准示范：
> "副驾车门打开，一双修长白皙的双腿，踩着高跟鞋，踏在老旧的石板路上，哒哒哒作响"

这就是一个完整的特写镜头——有画面、有声音、有质感。达到千万粉丝口播视频的水平。

### 8.5 力量感

好文案不仅有画面感，还有力量感。力量感通过两种方式实现：

**① 方言词汇（天然的高情绪表达力）**
- 东北话的情绪天然高昂，很多方言词汇能表达高情绪且无法被普通话替代
- 方言词汇自带的地域感和亲近感不可替代

**② 强弱对比**
通过四个维度的对比制造力量感：
- **对比数量**："我赚了十万" vs "我一天就赚了十万"
- **对比时间**："我失业了，在餐厅里吃饭的时候真羡慕那些端盘子的服务员"
- **对比经历**：曾经的辉煌 vs 现在的落魄
- **对比身份**：老板 vs 员工、富人 vs 穷人

### 8.6 情绪冲突的四种文案角度

在文案中制造情绪冲突，可以从以下四个心理学维度切入：

| 维度 | 心理学原理 | 文案公式 | 示例 |
|------|------------|----------|------|
| **利用追求心理** | 人会为变得更好而行动 |「来/做___，变/拥有___」 |「来健身房，变成更好的自己」「敷面膜，永远保持20岁」 |
| **利用规避心理** | 人会为避免损失而行动 |「来/做___，摆脱___」 |「来健身房，摆脱肥胖困扰」「敷面膜，避免皮肤干燥」 |
| **利用恐惧心理** | 人会因害怕后果而行动 |「不来/不做___，慢慢变成___」 |「不来健身房，慢慢变成胖子」「不护肤，皮肤干燥鱼尾纹」 |
| **利用失去心理** | 人会因害怕失去而行动 |「不来/不做___，失去___」 |「不来健身房，失去变美的机会」「不护肤，与水嫩肌肤告别」 |

**实战句式模板**：
- 追求型：「有/会___，___轻松搞定」「想让___，必须___」
- 规避型：「有/会___，摆脱___困扰」「想让___不失望，必须___」
- 恐惧型：「没有/不会___，慢慢变成___」「不懂___，将没有一个___」
- 失去型：「没有/不会___，你将失去___」「不懂___，将失去___」

### 8.7 四个维度让标题更有吸引力

| 维度 | 示例标题 |
|------|----------|
| **简单易行** | 「玩手机躺着也能减肥」「6个小办法，甩掉高原红」 |
| **解决难题** | 「厨房收纳7件神器」「新手必备化妆全流程」 |
| **信息盘点** | 「12种女生干练穿搭方法」「适合婚礼的50首歌曲」 |
| **场景触发** | 「订婚这些流程你知道吗？」「国庆旅游好物清单」 |

## 九、四大脚本类型体系

> 来源：12天实操班Chapter.3 / 第3课

**观点、过程、知识和故事四类脚本都应拍摄，才能让观众对个人IP有全面的了解。四类脚本兼顾流量和成交，因为它们背后都是成交理由。**

### 9.1 塑造人物IP内容输出的6大方向

> 来源：12天实操班Chapter.3

以人物为中心输出作品，有6大方向：

| 方向 | 具体内容 |
|------|----------|
| **讲故事** | 客户故事、从业故事、人生经历 |
| **说产品** | 接待过程、沟通过程、卖货过程、服务特色、人物特色 |
| **晒过程** | 接待过程、沟通过程、卖货过程、顾客趣闻 |
| **教知识** | 行业内幕、购买建议、使用技巧 |
| **拍段子** | 热点段子、沙雕模仿 |
| **递温度** | 父母温暖、同事友谊、情侣关心 |

### 9.2 6大方向与7种内容类型的关系

> 来源：12天实操班Chapter.7-9 / 行业内容配比矩阵

**6大方向**是"以人物为中心"塑造IP的输出方向，侧重于人设打造；**7种内容类型**是行业内容配比矩阵中的分类（说产品、教知识、晒过程、讲故事、谈特色、尬段子、标题党），侧重于内容形式。

两者对应关系：
- 6大方向中的"讲故事"对应7种类型中的"讲故事"
- 6大方向中的"说产品"对应7种类型中的"说产品"和"谈特色"
- 6大方向中的"晒过程"对应7种类型中的"晒过程"
- 6大方向中的"教知识"对应7种类型中的"教知识"
- 6大方向中的"拍段子"对应7种类型中的"尬段子"和"标题党"
- 6大方向中的"递温度"是独立的人设塑造方向，可融入其他类型中呈现

**四大脚本类型**（观点、过程、知识、故事）是核心脚本结构，6大方向和7种类型都是在四大脚本基础上的延伸和应用。

## 十、观点型脚本

### 10.1 核心定位

**有观点才有真粉丝，观点是情绪领袖。**

有观点的人物IP能吸引真粉丝——只靠热闹或知识吸引的粉丝可能是假粉丝（他们只喜欢你给的东西，而不是你这个人）。观点型脚本的标题自带情绪，能引发观众的情绪和讨论。

### 10.2 选题公式

**观点性选题 = 写作对象 × 人物关系 × 情绪**

| 维度 | 含义 | 示例 |
|------|------|------|
| **写作对象** | 你在说哪一类人？ | 宝妈、未婚女性、离异女性、都市白领…… |
| **人物关系** | 与谁的关系（站在哪边/对谁说话）？ | 家庭关系（婆婆/老公/孩子）、工作关系（老板/同事）、社会关系（闺蜜/前男友）…… |
| **情绪** | 看完产生什么情绪？ | 伤害、纠结、委屈、过错、不甘、遗憾…… |

**组合示例**：
- 单亲妈妈 + 家庭关系（孩子）+ 遗憾 =「没给孩子一个完整的家，以后他会不会怪我？」
- 恋爱中的女生 + 亲密关系（男友）+ 纠结 =「发现男朋友玩聊天软件，该不该原谅他？」
- 单亲妈妈 + 社会关系（用人单位）+ 伤害 =「用人单位知道我是单亲妈妈，就拒绝录用我」

### 10.3 行业型选题公式

**行业 × 产品/从业者身份 ×（被误解 / 被批判 / 被支持 / 被建议）**

示例：
- 房产中介 + 公寓 + 被误解：「做房产中介五年，今天必须为公寓说句公道话」
- 家居行业 + 沙发 + 被建议：「卖沙发十年，建议你别买这几种沙发」

### 10.4 六种论据类型

| 论据类型 | 核心逻辑 | 适用场景 |
|----------|----------|----------|
| **权衡利弊** | 不这么做会失去什么，这么做会得到什么 | 大龄女孩不结婚的利与弊 |
| **无奈之举** | 该做的都做了，但没办法 | 年轻人面对高房价、结婚成本的无奈 |
| **不同视角** | 从不同人的角度看问题 | 女人花男人钱的不同视角 |
| **倒打一耙** | 不讲事实，只图舒心（回怼，我乐意） | 女人为不干活找借口 |
| **维度升级** | 从更高的维度看问题（历史线/未来/生意维度） | 年轻人不要理财而要投资自己 |
| **人身攻击** | 慎用！除非批判不公，否则易树负面人设 | — |

### 10.5 力量感法则

**否定句 > 肯定句 > 疑问句**

- "千万不要买公寓"（否定句，最有力）
- "旅游还是中国好"（肯定句，中等力量）
- "该不该买房呢"（疑问句，力量最弱）

**应用**：开篇第一句话尽可能用否定句或肯定句，避免用疑问句。

### 10.6 核心

观点型脚本的核心不是"告诉一个正确的观点"，而是让观众产生**「对！我就是这样想的！」**的共鸣冲动。

## 十一、晒过程（过程型脚本）

### 11.1 核心定位

**最利于成交的脚本类型——能展示实力，秀出过程，让用户眼见为实。**

几乎是所有内容平台的终点：拍500个过程比教500个知识更容易。知识类视频可以通过改变呈现方式（如利用特定角色说出知识）增加可信度，使其变成"轻过程"。一个好内容的定义核心：**能否制造情绪曲线**——一个视频可以没头没尾，但必须要有情绪。

### 11.2 四大内容方向

| 方向 | 描述 | 适用行业 |
|------|------|----------|
| **制作过程** | 展示原料→过程→成品，让用户产生信任和溢价空间 | 食品、手工艺、修手机、装修、卖辣椒酱、火锅底料、珠宝串…… |
| **测评产品** | 横向（同类不同品牌比较）/ 纵向（单产品多维度验证），看上去在测评实际在带货——替顾客当质检员 | 充电宝、纸尿裤、手机…… |
| **任务挑战** | 没有困难制造困难，目标明确、困难可衡量 | 1000元在上海玩四天、一分半吃完一根香肠奖励1000元、一个星期花200减掉十斤 |
| **改造对比** | 正向改造 / 反向改造 / 升级过程 | 发型、穿搭、妆容、厨房、直播间…… |

### 11.3 埋钩子：让用户从头看到尾的技巧

在视频开头设置钩子，吸引用户从视频开头看到结尾，增加停留时长，从而提高流量。钩子类型包括：免费充电宝、饮料、熟人、明星、抽奖等。

### 11.4 建立期待感的十个技巧

| 技巧 | 说明 | 应用示例 |
|------|------|----------|
| **送温暖** | 给陌生人惊喜/帮助 | 给环卫工人送早餐 |
| **金钱** | 涉及金钱的刺激 | 猜对价格就送给你 |
| **怀旧** | 勾起过去的记忆 | 复刻小时候的味道 |
| **对抗** | 设置对立/竞争 | PK谁能吃完 |
| **惊喜** | 制造意外惊喜 | 偷偷给妈妈买她舍不得买的 |
| **意外** | 出乎意料的情节 | 以为翻车了结果没有 |
| **盲盒** | 未知结果的期待 | 随机抽一家店吃到撑 |
| **验证** | 验证某种说法 | 测试网红产品是不是真的好用 |
| **解密/揭秘** | 揭晓未知/内幕 | 揭秘行业内幕 |
| **整蛊** | 恶作剧/玩笑 | 假装忘记对方生日然后给惊喜 |
| **荷尔蒙** | 颜值/身材吸引力 | 帅哥美女相关视觉内容 |

### 11.5 困难制造维度

- **金钱维度**：花小钱办大事（100元过一天）/ 花大钱办小事（挑战花1万做最丑的造型）
- **时间维度**：短时间多数量缺人手（一小时做100个 cupcake）

### 11.6 趣味玩法：「单钩钓」

核心：**强化过程，弱化结果。**

三种事件体验类型：
| 类型 | 描述 | 示例 |
|------|------|------|
| **新奇体验** | 体验普通人平时没见过的 | 盲人出行体验、老板体验员工的一天 |
| **奇葩规则** | 设定荒谬的规则 | 挑战运动洗脸——不管师傅怎么洗都怪他没吃饭 |
| **角色扮演** | 切换身份视角 | 内行人假装外行人的体验 |

### 11.7 创作顺序

确定方向 → 罗列关键步骤 → 加入钩子 → 丰富过程 → 多看他人作品提升创作能力

## 十二、教知识（知识型脚本）

### 12.1 核心定位

教知识易转粉、涨精准流量、塑造良好人设。

**教知识的本质是信息差**——在短视频平台上，只要有信息差就可以教知识。信息差来自素材库。通过搭建素材库并输出知识，既能在平台上获得流量，也能使自己快速成长。

### 12.2 五大选题维度

| 维度 | 含义 | 典型内容 |
|------|------|----------|
| **追求更好** | 帮别人变得更好 | 穿搭教程、化妆技巧、学习方法 |
| **解决难题** | 帮别人解决具体问题 | 瘦脸方法、收纳技巧、吵架话术 |
| **避免踩坑** | 帮别人提前避开陷阱 | 装修避坑、买车避坑、求职避坑 |
| **降低成本** | 帮别人省金钱/省时间/省力 | 平替推荐、省钱攻略、效率工具 |
| **丰富谈资** | 帮别人获得吹牛/聊天的资本 | 冷知识、行业内幕、谈资类内容 |

**筛选逻辑**：日常难题 + 放大危机，二选一。
- **日常难题**：用画面感描述场景难题
- **放大危机**：用恐惧心理写放大危机
- 实在不行 → 去同行评论区找高赞问题（评论区的高赞问题就是最好的选题来源）

### 12.3 获得感三要素——教知识能火的核心

教知识能火的核心是给观众带来**获得感**。获得感有三个维度：

| 维度 | 含义 | 通用句式 |
|------|------|----------|
| **信息多** | 一口气给大量信息 | "16种营销模式""史上最全……""100首营销音乐""盘点排名" |
| **效果快** | 快速见效 | "一秒搞定……""三分钟学会……""几秒钟学会弹钢琴""1秒钟学会单词" |
| **料够猛** | 谈资类/内幕类内容 | "只有内行人才知道的……""99%的人不知道……""行业内幕揭秘" |

### 12.4 四大教知识脚本子类型

#### ① 解题型

**结构**：场景难题 + 放大危机 → 给出低成本解决办法

**要点**：
- 场景难题：把生活中的糗事用画面感描述出来，描写小细节
- 危机：利用人的恐惧心理，吓唬观众
- 解决办法：低成本、简单易行

**示例**：「瘦脸」——场景：拍照永远要找角度、P图P半天；危机：再不瘦脸以后婚纱照都没法拍；办法：三个零成本瘦脸动作，每天两分钟。

#### ② 推荐型

**结构**：开篇（3选1）→ 推荐内容 → 给出理由

**要点**：
- 推荐至少3个
- 获得感强的排前面
- 理由30~40字，要简短有力
- 可以多给知识或推荐内容
- 门槛低、行动成本低的排在前面

**开篇三选一方式**：
1. 美好愿景：「想要厨房永远干净整洁？」
2. 圈定人群：「所有小腿粗的女生看过来」
3. 引发好奇：「只有内行人才知道的6个……」

#### ③ 揭秘型

**结构**：直接提出揭秘事件 → 讲述事件内情

**要点**：
- 揭秘的事件必须与大众生活息息相关（如装修内幕、话费慢充灰色产业、食品安全等）
- 勇敢暴露缺点，让观众感受到真诚

#### ④ 案例型

**结构**：提出案例并描述 → 提取案例中的知识点 → 告诉用户怎么做

**要点**：
- 案例要有热度——热点案例、成功案例、失败案例、名人案例、影视桥段
- 创作思路①：先有案例，结合行业输出知识
- 创作思路②：先有知识，结合知识找案例支撑

### 12.5 教知识脚本常见四大错误

> 来源：12天实操班Chapter.7-9 / 第11课

| 错误 | 表现 | 正确做法 |
|------|------|----------|
| **用词专业** | 说行业术语、学术词汇 | 说接地气的话，村头老太太都听得懂 |
| **反馈过长** | 「让孩子多读书三年后有见识」 | 改为「三天后有效果」 |
| **排列不好** | 获得感弱的内容排前面 | 获得感强的放前面，门槛低行动成本低的放前面 |
| **对象模糊** | 开篇不说清楚写给谁 | 开篇明确写作对象（如"所有孩子写作文困难的家长"） |

### 12.5.1 教知识不火的原因

> 来源：第11课

1. **讲原理不如给方法**：直接给答案比讲原理更有流量。例如讲减肥的视频，给方法的点赞多。
2. **不符合小宝宝法则**：教知识要寓教于乐，把观众当成小宝宝哄开心，不要讲太多原理。拍剪要好，表现力要提高。

### 12.6 小宝宝法则

教知识要**寓教于乐**——把观众当成小宝宝哄开心，不要讲太多原理。直接给答案比讲原理更获流量。拍剪要好，表现力要提高。

## 十三、讲故事（故事型脚本）

### 13.1 核心定位

讲故事的作用：突破信任防线——让用户了解更多，突破粉丝信任防线，促进成交和提高溢价。

三种故事类型：
- **行业营销型**：为自己的事业做信任背书（如帮助村子脱贫致富，目的是招商引资）
- **日常生活型**：单纯立人设，吸引有相同经历或能感受其经历的用户（如夫妻备孕故事）
- **信任突破型**：让用户了解更多，促进成交

### 13.2 三种故事脚本结构

### ① 小有成就（需粉丝基础）

让别人羡慕——不止金钱，任何一个小成就都可以。

**四段论结构**：
1. **已达成的成就**（上来直接说成就是怎么达成的）
2. **过程中的困境**（阻碍、困难）
3. **过程中的转机**（转折点）
4. **目标带来的感悟**（总结经验/感悟）

**影响故事好看与否的关键**：中间的困境与转机。
- 困境和转机需是**经典桥段**：盲目自信、家门不幸、天灾人祸、恶霸欺压、过河拆桥、抓住商机且产生正向影响、至亲寄托（信念感）、意外之喜（无心插柳）、因祸得福（狗血）、破釜沉舟（自我改变+努力）
- **情绪递进规则**：刚开始简单 → 后面逐步变难。前面就很难后面就乏味了。

### ② 成功案例（0粉可做）

与小有成就结构相似，区别在于：
- 写的是「帮助他人成功」
- 包含「我帮助别人的部分」+「他人自己努力的部分」

示例：帮一个卖水饺的店铺卖爆单——展示自己如何策划、对方如何配合、最终取得什么成果。

### ③ 苦难经历（立人设专用）

通过讲述自己的苦难经历（如特殊病症、艰难经历等），将自己不堪的经历暴露出来，洗白人设，使人物形象更加鲜活，拉近与用户的距离。

**脚本三步结构**：

**第一步：找出自己的缺陷**
- 来源：自身特殊缺点、苦难经历（尿床、胎记、整容、性别不同、特殊癖好、生活习惯、家庭关系、亲密关系、社会关系……）
- 关键：为缺陷包装一个合理的解释

**第二步：缺陷产生原因 + 缺陷带来的痛苦**
- **猎奇型**（缺陷足够小众）：少写原因，多写困苦——尤其多写别人的嘲笑和欺负
- **共鸣型**（缺陷足够常见）：多写原因——通过和别人的对比来突出原因，让大家感知到

**第三步：释怀的感悟**
- **猎奇型**感悟方向：用自己的痛苦经历鼓励别人——「你们已经过得比我好了」
- **共鸣型**感悟方向：释怀当初的苦难，见不得别人再经历——「不想再看到任何人经历我曾经历的事」
- 注意：释怀不代表放弃

### 13.3 苦难经历的经典桥段加持

给苦难经历加上经典桥段，目的是让别人觉得更惨，体现剧情的激励性：
- **他人嘲笑**：被同学、同事、陌生人的嘲笑
- **连累他人**：因为自己连累了家人或朋友
- **阻碍成就**：缺陷阻碍了自己实现某个重要目标
- **至亲误解**：最亲近的人不理解自己
- **自我牺牲**：为他人牺牲却得不到理解

### 13.4 苦难经历的核心铁律

> 来源：第13课

**讲苦难时不许哭，要笑着讲。**

**拍摄技巧**：讲苦难时不许哭，要笑着讲。因为抖音的导向是记录美好生活，用户更愿意看到经历苦难仍心向阳光的博主，而不是在镜头前自怨自艾。

平台的导向是记录美好生活。用户更愿意看到经历苦难仍心向阳光的博主，而不是在镜头前自怨自艾。结尾必须落在**释怀和鼓励**上。纯立人设，不直接带来变现——但因为人设立住了，后续的变现会顺理成章。

### 13.5 故事创作总流程

1. 思考自己的小有成就
2. 给成就加一个阻碍（身体情况、经济条件、社会环境、他人阻挠、原生家庭……）
3. 录音说出故事素材
4. 语音转文字，打印出来
5. 识别其中的经典桥段
6. 排列组合，将经典桥段展开创作

**注意事项**：
- 避免写人物自传式的故事背景（流水账没人看）
- 写文案要增加画面感
- 多注意文案的写作技巧

> 来源：第14课

2. **人物本身身份或特质极为特殊的视频**：无法复制的人物特质
3. **对口型变装等无商业属性的视频**：无商业变现价值

**拆片训练建议**：从简单的视频开始拆解，逐渐过渡到复杂的脚本，以提升网感和积累爆款视频结构。带着拆片思维看爆款视频能看出门道，进入专业创作者行业。

## 十五、表现力训练体系

### 15.1 面对镜头的紧张

**紧张的原因**：对生活事物的不熟悉、害怕别人的评价和眼光。

**紧张的表现**：肢体僵硬、表情不自然、声音小、语速慢、读词抒情、说话没重点没情绪。

**克服方法**：
1. **多拍（镜头脱敏）**：拍得越多越自然，最终达到忘记镜头存在的状态
2. **把镜头当熟人**：把镜头当做家人/朋友/闺蜜来聊天，而不是表演
3. **演绎真实的自己**：演绎自己生活中的样子，让观众感觉不到在演——镜头感就是能自然真实地出现在镜头内

### 15.2 入戏的必备条件

**① 内心视象**：在心里想象一个画面或场景——因为发生了某件事，所以要说出相应的文案/知识/观点/故事。先有「发生了什么」，才能自然说出相应的话。

**② 交流对象**：明确自己在跟谁说话。不同的人（闺蜜/老板/妈妈/陌生人）对应不同的情绪和反应。不同场景遇到不同的事情，用不同的情绪。

**总结**：因为什么/发生了什么要说这个话 + 你要跟谁去说。

### 15.3 表现力的核心

**真看、真听、真感受**

让观众感觉到视频内容是真实发生的，不是在演小品或装。最高级的表现力就是让观众完全感受不到表演痕迹。

### 15.4 还有什么可以影响说话的状态

**场景**——把口播变成晒过程，现场去拍、现场去感受。当你在真实的场景中说相关的话，情绪和表现力都会自然流露。

## 十六、声音训练体系

### 16.1 为什么觉得自己说话声音难听

> 来源：如何让声音更好听课程大纲 / 声音训练项目

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 音色不好听 | 发声的位置不对 | 练习正确发声位置 |
| 嗓子容易干、疼 | 不会使用气息 | 气息训练 |
| 声音没力量 | 不会用丹田发声 | 丹田发声练习 |
| 听起来不舒服 | 断句不正确、整句话容易被打断 | 节奏训练 |
| 普通话不标准 | 平翘舌不分 | 着重练习拼音 |
| 个别辅音发音不标准 | l/n不分等，容易使别人听不清内容 | 着重练习对应拼音 |
| 观众听起来没感觉 | 没有情感、不带情绪 | 练习台词、朗诵，带着情绪说话（开心、悲伤、恐惧、得意、吃惊等） |
| 不容易创造代入感 | 没有面部表情带动语言情感 | 对着镜子做表情练习 |

### 16.2 塑造好声音的10项基本功练习

| 序号 | 练习项目 | 练习方法 |
|------|----------|----------|
| 1 | **提打挺松** | 1分钟（可以咬住筷子辅助） |
| 2 | **气泡音** | 5组，每次把气用完，尽量持久 |
| 3 | **打嘟噜** | 3组，每组8秒以上合格 |
| 4 | **快慢呼吸** | 快吸慢呼、慢吸慢呼、慢吸快呼，各3组 |
| 5 | **撅咧唇** | 20次 |
| 6 | **绕唇** | 顺时针、逆时针各20圈 |
| 7 | **饶舌** | 顺时针、逆时针各20圈 |
| 8 | **舌打两腮** | 60下 |
| 9 | **弹舌** | 40下 |
| 10 | **丹田发声** | "耶呀嘿嚯"10组 |

### 16.3 对象感训练——视频对话的灵魂

**什么叫对象感**：想象你在跟身边的一个朋友讲话的语言状态。有了对象感，观众会有代入感、真实感，更容易吸引观看。

**对象感的三个技巧**：
1. **轻重起伏**：句子中的轻重音和高低起伏可以穿插变化，不要太平
2. **快慢相间**：重点处放慢，过渡处加快
3. **运用气息**：气息支撑发声，声音更稳定有力

**辅助技巧**：
- **加入表情**：视觉上感染观众，加深印象
- **运用手势**：增加说话气势和强调重点

**对象感练习示例**：
- "嘿！你知道，改变自己最重要的是什么吗？"
- "学会这三招，视频更清晰！"
- "如何掌握文案技巧？悄悄告诉你"

注意：句子中的轻重音和高低起伏要穿插变化。

### 16.4 情感表达——带着情绪说话

> 来源：如何让声音更好听课程大纲

观众听起来没感觉的原因是没有情感、不带情绪。解决方案是**带着情绪去说话**。

**五种核心情绪表达**：
- 开心
- 悲伤
- 恐惧
- 得意
- 吃惊

**练习方法**：
- 练习台词、朗诵，带着情绪说话
- 对着镜子做表情练习，用面部表情带动语言情感
- 加入表情视觉上感染观众，加深观众印象
- 运用手势增加说话气势和强调重点

**核心原则**：没有面部表情带动不了语言情感，不容易创造代入感。通过表情和情绪的配合，让观众有代入感、真实感，更容易吸引观看。

## 十七、口播置景体系

### 17.1 核心认知

**场景是打开流量突破口的一把刀。**场景的改变可以带来流量的突破。同样的内容在不同场景下表达，效果完全不同——置景不同，情绪不同，流量也不同。

### 17.2 三种场景类型

| 场景类型 | 特点 | 建议 |
|----------|------|------|
| **素背景**（大白墙/纯色窗帘/书架） | 刺眼、有距离感，不适合普通创作者（表现力和颜值不如大博主，难以吸引用户） | 避免 |
| **包装性背景** | 突出专业人设、增加可信度，但容易让用户产生距离感，不太符合平台接地气的特点 | 需搭配接地气内容 |
| **生活背景** | 拉近距离，让用户身临其境，降低预期 | 强烈推荐 |

### 17.3 推荐的生活化场景

公园、车里、卫生间、海边、马路、被窝、天台、羊圈、商场、江边、餐馆、洗浴中心——任何真实的生活场景都可以。

### 17.4 置景原则

1. **根据讲的内容选择对应场景**——场景不同，情绪不同
2. **多切换场景**——短视频中高播放量的博主都会刻意切换场景来吸引注意力
3. **置景要有原生感**——根据不同话题选择合适的场景，让观众感受真实和自然

### 17.5 拍摄小技巧

- 摄像头高度与视线尽可能一致
- 避免使用白色背景墙
- 可使用射灯或落地台灯增加画面色彩的鲜艳度和视觉的舒适度

## 十八、拍摄及呈现体系

### 18.1 四种常见呈现形式

| 形式 | 人设强度 | 变现效果 | 流量 | 拍摄成本 | 适合人群 |
|------|----------|----------|------|----------|----------|
| **图文** | 几乎为零 | 差 | 一般 | 极低 | — |
| **情景剧** | 演出来的 | 靠直播打赏+广告 | 大 | 巨高 | 团队 |
| **口播** | 强 | 好 | 相对小 | 低 | 个人/新手 |
| **vlog** | 强 | 相对不错 | 介于中间 | 中 | 有记录习惯者 |

### 18.2 口播的四种拍摄视角

| 视角 | 特点 | 适用场景 |
|------|------|----------|
| **自拍视角** | 一人一支架，成本低但过于普通 | 常规口播 |
| **偷拍视角** | 有窥私欲、即时性、真实感 | 面试系列、记录真实状态 |
| **采访视角** | 相对偷懒，采访路人/客户/学员，需提前设置问题 | 街头采访、客户见证 |
| **聊天视角** | 降低预期，更有代入感——拍摄人代表观众提问，问题是观众关心的 | 问答式内容 |

**结论**：任何口播视频都可以换个视角再拍一次，获得不同的效果。

### 18.3 vlog 拍摄要求

- **真人出镜、真人说话**（或本人后期配音）
- **赋予主题**：不能是流水账（如"九零后在北京北漂的一天"——有明确主题），而是罗列关键步骤正常拍

### 18.4 景别

| 景别 | 取景范围 | 功能 | 口诀 |
|------|----------|------|------|
| **远景** | 环境宽广的画面 | 交代人物处在什么环境之中 | 远取其势 |
| **全景** | 人物全部出现在画面里 | 交代环境和人物关系，人物入场/剧情逆转 | 远取其势 |
| **中景** | 画面卡在膝盖以上 | 用动作表达情绪，用在时间和位置变化时 | 过渡 |
| **近景** | 画面在人物胸部以上 | 突出人物性格和状态，用表情表达情绪，口播中最常用 | 近取其神 |
| **特写** | 局部/某一部位 | 展示细节/产品/心里活动，非表情传递情绪 | 近取其神 |

**实拍建议**：
- 少用远景，多用近景
- 相邻景别不切换，跳两级不切换
- 隔景别切换是对的
- 不卡关节

### 18.5 构图

三种基本构图：
- **中心构图**：主体在画面正中间
- **三分法构图**：把人物的脸或身体放在参考线和交叉点上——多用在采访、聊天视频中。人物面向哪边，哪边空间要大一点。
- **前景式构图**：增加画面层次感

**避坑（7种常见错误）**：
面壁思过、顶天立地、脑袋悬浮术、断手断脚、移花接木、东倒西歪、喧宾夺主

### 18.6 运镜

> 来源：12天实操班Chapter.4 / 第17课

| 运镜方式 | 操作 | 功能 |
|----------|------|------|
| **推/拉** | 推：人物不动镜头往前走（远→近）；拉：从特写逐步拉远（近→远） | 突出画面主体、视觉聚焦／交代场景、有壮观感。镜头开头／镜头结尾 |
| **横移** | 边走边拍，人和镜头同方向同速度 | 表现人物与环境关系，让用户产生身临其境感（空间转移的衔接画面） |
| **横/纵摇** | 横摇：左右拍；纵摇：从下向上拍 | 横摇交代环境、模仿人眼；纵摇展现全貌、从低到高（用于建筑／大场景） |
| **跟随** | 跟随拍摄对象保持同等距离移动 | 拍摄人物表情动作变化，更有记录感（第一人称既视感） |
| **升降** | 全景别，传达出拍摄画面的高度 | 展现主体全貌时 |
| **环绕** | 人在中心不动，围绕中心转一圈 | 介绍整体环境，突出主体、渲染情绪、画面更有张力（巡视物品／人／环境时） |
| **蚂蚁** | 特写，低角度拍摄 | 呈现更强烈的空间感 |

一个镜头可出现多个景别和构图，通过运镜突出画面主体、交代环境、展现全貌。

### 18.7 写实镜头与写意镜头

| 镜头类型 | 功能 | 定义 | 示例 |
|----------|------|------|------|
| **写实镜头** | 表达事件 | 文案是什么就拍什么，直接拍摄对应画面 | "我想你了"直接说出来或拍相关场景 |
| **写意镜头** | 表达情绪 | 用委婉/象征方式表达，是作者心灵中画面的投射 | "今晚的月色真美""张万森下雪了"——表达遗憾、遗忘、失落、孤独 |

**练习场景**：
- "发了一千块钱奖金给自己奖励" → 写意镜头：空荡房间一个人举杯
- "一个人在家偷偷喝了一瓶啤酒" → 写意镜头：阳台上的空酒瓶和夕阳
- "一个人走在路上看见一个氢气球飞走了" → 写意镜头：仰拍气球越飞越远

### 18.8 画面质感与打光

**最佳光源**：自然光（太阳光），只要不逆光拍摄基本没问题。

**六种打光方式**：

| 打光方式 | 特点 | 应用场景 |
|----------|------|----------|
| **正面光** | 面部均匀明亮 | 基础补光 |
| **45°光** | 皮肤好、显瘦，从侧面打光 | 人物主光，最常用 |
| **顶光** | 有压迫感，光源在人物正上方 | 特殊氛围 |
| **侧光** | 让人物更有个性，只有一侧有光 | 个性表达 |
| **底光** | 恐怖片打光，从下往上 | 恐怖/悬疑 |
| **背光** | 氛围感、神圣感，从背后打光 | 氛围营造 |

**拍摄设备建议**：
- **手机**：建议苹果手机，苹果12以上足够使用
- **拍摄前记得擦镜头！**
- **用原相机录**（不美颜），剪映后期美颜处理——美颜相机容易导致不清晰
- **灯**：神牛灯（外拍使用）；39元手机夹灯（光线不足时夹在手机上补光）
- **麦克风**：290元一拖二款（罗德平替，收音效果好，操作简单）
- **支架**：长支架使用场景更多

## 十九、剪辑核心体系

### 19.1 软件与导出标准

- **软件**：剪映（需熟悉工具栏18个功能）
- **导出标准**：1080p、30帧、码率适合、HDR勾上

### 19.2 剪映工具栏核心功能速查

| 功能 | 说明 |
|------|------|
| **分割** | 切割素材 |
| **移动素材** | 调整顺序 |
| **变速** | 调整播放速度 |
| **音量** | 调整音量大小 |
| **动画** | 入场动画（素材开始时的效果）/ 出场动画（素材结束时的效果） |
| **音频分离** | 将素材声音单独建立轨道，可删除原画面换新画面，保留原声音 |
| **编辑** | 镜像（左右翻转）/ 旋转（90°旋转）/ 裁剪（改变画面大小） |

| **调节** | 精细调整画面参数 |
| **蒙版** | 类似在视频上盖一张纸并抠出形状——可选择不同形状，拉伸/虚化/改变圆角 |
| **不透明度** | 数值越大画面越实，数值越小画面越透明 |
| **复制** | 复制素材 |
| **倒放** | 素材倒放（如"三天前""一个小时前"） |
| **定格** | 将选中画面静止显示（相当于截图并持续3秒） |
| **画中画** | 将图片/视频叠加在画面上（如减肥对比图、装修前后图） |
| **文本** | 添加字幕 |
| **贴纸** | 装饰画面 |
| **特效** | 画面特效 |
| **关键帧** | 改变大小/位置/饱和度/透明度/音量——距离越远变化越慢，距离越近变化越快 |

### 19.3 视频剪辑五步骤

**第一步：减掉气口**
- 目的：提升画面节奏感和完播率
- 操作：调节音量降噪 → 识别字幕 → 减掉气口（没有字幕的地方默认为气口，分割后剪掉）
- 注意：气口不要留太长，别剪多或留气口过多

**第二步：添加文本字幕**
- 字体：不要用系统字
- 字数：一行尽量不超过8个字，不要出现两行
- 排版：注意字幕摆放位置和颜色，避免错别字
- 重点字：可换色和添加动画突出
- 分段技巧：把一段长的字幕分割成几段（如"我一学生"把"生"切割，后面的字删除）
- 重点变色操作：双击文字 → 长按选中要变的字 → 点击"编辑样式"

**第三步：关键帧**
- 功能：改变物体大小、位置、饱和度、透明度、音量
- 最常用：改变位置和大小
- 操作：起点添加关键帧 → 在较远/较近处再添加关键帧 → 进行缩放/移动
- 规律：距离越远，变化越慢；距离越近，变化越快（情绪更激烈）

**第四步：画中画**
- 操作：点击画中画 → 导入提前选好的视频/图片 → 调节画中画长度大小
- 配合：点击贴纸搜索手机框 → 调整贴纸长度与画中画匹配
- 常见用途：减肥前后对比、装修前后对比

**第五步：蒙版**
- 操作：选择蒙版 → 移到要蒙的位置 → 左上图标往外拉可把方形角变圆 → 下边图标可虚化边框 → 其余两个调节大小高矮

### 19.4 封面制作

**封面的三大作用**：涨粉 + 设置悬念 + 形成个人IP。

**常见问题**：
- 太乱（元素太多）
- 过于统一且文字太多
- 没有封面

**建议**：参考喜欢的博主或大V的封面制作方式。

### 19.5 辅助软件

- **醒图**：修图
- **Wink**：视频美容（比剪映美颜更自然）

### 19.6 音乐推荐

> 来源：第19课

**① 十二种主流情绪对应120首经典音乐**

按十二种主流情绪分类存放的经典BGM库，涵盖各种情绪场景。情绪分类参考：潇洒、金钱、警告、励志、爱情、亲情、友情等（详见5.7音乐包参考清单）。

**② 70首赛道流量BGM**

根据赛道分类的自带流量BGM，不同赛道有不同的流量音乐，选择适合自己赛道的BGM可以增加流量。

**音乐使用技巧**：
- 热歌榜音乐可增加完播率
- 叙事型内容用背景音乐
- 音乐声音比例需调节
- 垂直词语、#相关领域话题#、@抖音小助手等配合使用

## 二十、账号搭建与CIS识别体系

### 20.0 账号体系四步法

> 来源：12天实操班Chapter.3

账号搭建遵循四步递进流程：

| 步骤 | 内容 | 说明 |
|------|------|------|
| **Step 1** | 明确商业定位 | 变现方式（卖货/引流/广告/直播） |
| **Step 2** | 明确内容定位 | 主题IP + 人物IP（受众面广、更易变现） |
| **Step 3** | 账号鲜活人设 | 通过6大方向输出塑造鲜活人设 |
| **Step 4** | 建立识别系统 | 超级符号（MI理念 + BI行为 + VI视觉） |

完整链路：商业定位 → 内容定位 → 账户搭建（头像/昵称/简介/头图）→ 超级符号 → 涨粉/持续/变现

### 20.1 CIS企业形象识别系统（适配个人IP）

### 21.1 标签机制

| 标签类型 | 作用 | 优先级 |
|----------|------|--------|
| **用户标签** | 基于点赞/收藏/评论/转发/关注/滑走行为给用户打标签 | — |
| **账号标签** | 无作品标签时的备用推流依据 | 不重要 |
| **作品标签** | 帮助平台精准识别视频内容，推给精准人群 | 最重要 |

**话题设置**：领域话题 → 行业话题 → 内容话题 → 自建话题。推荐使用：1个行业话题 + 2个内容话题。

### 21.2 推流机制（赛马机制）

同赛道视频竞争流量，数据好的获得更多流量。

- **初始流量**：200~500
- **考核指标**：完播、点赞、转发、评论、转粉、收藏
- **完播率是最核心指标**
- **规则**：同时长比完播率 → 不同时长比完播时长 → 完播时长越长流量越大

### 21.3 铁粉机制

- 对有粉丝的账号 → 可能导致掉粉和难破圈
- 对新号 → 有利低粉变现（铁粉先看到，容易产生购买行为）
- **破圈方法**：多维高频更新

### 21.4 小黄车推流

考核：橱窗点击率 + 商品转化率（后台根据这两个数据决定是否给流量）

### 21.5 图文推流

考核：完播率 + 互动 + **手动画图率** + **展开完读率**。需注意图的好看性 + 文案钩子。

### 21.6 账号权重诊断

| 等级 | 播放量区间 | 特征与对策 |
|------|-----------|------------|
| **僵尸号** | <100 | 持续一周<100，基本等于废号，建议注销重开 |
| **最低权重号** | 100~200 | 只会被推荐到最低流量池，可模仿热门段子提高互动和播放量；21天没突破会降为僵尸号 |
| **中途降权号** | >1000后突然降低 | 可能发了硬广或搬运他人作品被识别后降权（关进小黑屋），等待释放 |
| **待推荐账号** | 1000~3000 | 持续发布高质量/垂直领域优质作品，有可能被推荐到更大流量池 |
| **待上热门号** | >10000 | 每次基本都有1万播放量，配合蹭热点/官方话题/最火音乐可加速上热门 |

### 21.7 降权限流常见原因

1. 破坏社会团结、宣扬民族歧视
2. 封建迷信、风水、塔罗、星座占卜
3. 涉及他人隐私、个人信息或资料
4. 搬运他人作品、抄袭
5. 吸烟、暴力、恐怖、色情、赌博等
6. 留外部联系方式（威信、薇、围脖、扣q等）
7. 视频中出现微信、微博、淘宝等水印
8. 长时间出现商品logo/手机号/二维码（超3秒）
9. 视频内含有其他水印（视频平台/剪辑软件）
10. 视频清晰度太低、画质较差
11. 内容明显是营销广告
12. 直播中明显引流、卖货、推销行为
13. 直播中口播广告、联系方式
14. 纯图片轮播（带商品更严重）
15. 无口播拆箱物品或好物推荐

### 21.8 审核流程

机器检测 →（有问题）人工检测 → 查画面/文案/音乐/关键帧 → 违规则删除/封号 → 可申诉

### 21.9 限流申诉

账号检测 → 抖加检测 → 联系人工客服（态度卑微、明确诉求、照读句式成功率高）

## 二十二、DOU+投放与数据分析

### 22.1 三种投放目的与策略

| 目的 | 投放方式 | 时长 | 策略 |
|------|----------|------|------|
| **点赞评论** | 刚发视频时投 | 2小时 | 让数据更好看，吸引更多人观看；效果好→追加24h；目的是面子+吸引观看 |
| **粉丝量** | 自定义投放 | 24小时（越长越好） | 看成本。有赛道的粉丝更值钱。是否继续投看数据反馈。 |
| **商品推广** | 系统智能+自动出价 | — | 看成本收益。购买率低→检查差评/换品。 |

### 22.2 DOU+操作路径

- **个人账号**：三点 → 上热门 → 选择无营销的视频投放
- **企业号**：更多功能上热门 → 账号经营/获取客户/商品推广
- **蓝V**：三点 → 本地推 → 门店浏览/团购购买/粉丝增长等

### 22.3 核心数据指标

**转化漏斗**：
- 播放 → **互动率**（点赞/评论/转发）→ 互动
- 互动 → **关注率** → 涨粉
- 涨粉 → **咨询率** → 营销咨询
- 咨询 → **跳失率** → 导流/电商

**运营核心数据**：
- 营业额 = 导流量 × 转化率 × ARPU值（平均单用户付费价值）

### 22.4 AB test 方法论

用AB test持续优化转化效率：
- 不同的素材投放对比
- 同样的素材选不同的定向对比
- 同样的咨询导流不同的课程顾问对比
- 同样的课程顾问推荐不同的商品对比

找到最优组合后**稳定追投**。

### 22.5 资产与负债思维

- 有产品无流量 = **负债**
- 有粉丝/私域群 = **资产**
- 实体店 = 产品 + 流量 + 交付的综合体（少了流量环就不赚钱）
- 抖音粉丝不会蒸发，能永远提供价值

## 二十三、电商变现体系

### 23.1 人货场关系

**流量小 → 货带人 / 流量大 → 人带货**

三难：好人难找、好货难选、好场难搭。

### 23.2 视频电商 vs 直播电商

**短视频购物人群特征**：目标群体精准、场景情绪化、因促销活动和刚需化下单、有多次触达。
**直播购物人群特征**：产品多元化、需主播有IP、清仓处理、场景多样化、信任下单。

### 23.3 选品方法

**无产品时**：
1. 看做得好的同行都卖什么
2. 去精选联盟看爆品榜
3. 查看商品橱窗：爆款热卖榜、搜索热度榜、搜索趋势榜
4. **看榜时间**：早上8点、中午12点、下午6点（不同时段的数据有参考价值）
5. 选品注意：佣金、店铺评分、商品详情页、产品是否匹配自己的人群画像

**有产品时**：入驻抖店，按流程操作。

### 23.4 4P法则（带货版）

| P | 含义 | 目的 | 短视频中的应用 |
|---|------|------|---------------|
| **目标群体** (People) | 圈定精准人群 | 引起受众注意 | 如美白牙贴→牙黄/牙渍/嚼槟榔/抽烟的人 |
| **场景冲突** (Problem) | 制造场景引发情绪 | 引发用户情绪 | 如美白牙贴→约会/面试等重要场合，冲突要适中不能太大也不能太小 |
| **产品亮点** (Product) | 突出产品差异化 | 引出解决办法 | 如美白牙贴一贴一撕，方便快捷、能让牙齿变亮变美 |
| **促销活动** (Promotion) | 促成成交的行动理由 | 引导行动 | 如"加一元送马勺"让消费者感觉占便宜 |

### 23.4.1 三维三问——Get到营销创意

> 来源：12天实操班Chapter.7-9

通过"三维三问"获取营销创意：

| 维度 | 核心问题 |
|------|----------|
| **消费群体** | 谁来消费？目标人群是谁？ |
| **消费场景** | 在什么场景下消费？ |
| **消费成本** | 消费成本是多少？ |

通过回答这三个问题，可以快速Get到营销创意，为产品带货提供内容方向。

### 23.5 开通橱窗

## 二十四、直播间搭建体系

### 24.1 大宝宝法则

与短视频「小宝宝法则」（哄开心）不同，直播要满足用户的**新鲜感**：
- **场景新鲜感**：变换不同场景
- **玩法新鲜感**：变换不同玩法
- **人的新鲜感**：变换不同互动形式

大宝宝法则的核心：**让你产生情绪，买单。**

### 24.2 四种直播间玩法

#### ① 获得感强

适用于能展示的教知识或不能展示的交互知识。

**三种形式**：
1. **一个主题**：开播前设定主题，单个知识循环讲或多知识选择性讲
2. **连麦解答**：单领域能力经验丰富可进行连麦解答
3. **聊天室沟通**：需要玩法和技巧，成熟后可将人拉到麦序上挨个解决问题

#### ② 展示牛（可视化）

眼睛看见的才有安全感——展示的效果能直接看得见。

**玩法**：
- **测试型**：测产品质量、承重、高温低温……
- **展示型**：展示产品能解决的问题
- **实操型**：演示产品使用方法

**场景**：户外和街边、家里、真人不出镜。

#### ③ 制作性强

相对不好展示效果的产品 → 把操作过程可视化。

- 适合产品：调料包、食谱、锅、小吃、手工品、小吃教程、工具等。
- **形式**：
  - 晒过程（让粉丝看着过瘾，感觉自己也能做）
  - 制作型（展现技术和变现程度）
  - 加戏型（将产品可视化，如砸牛肉干）
- **场景**：户外（如鲨鱼小姐姐、葱油饼）、手工（工匠级别，如铝锅制作）、真人不露脸（如教烙饼）

#### ④ 正常带货（四种讲法）

| 讲法 | 内容 | 示例 |
|------|------|------|
| **讲产地** | 生产场地+产地产品优势 | 阳澄湖大闸蟹、舟山带鱼、西湖龙井…… |
| **讲体验** | 口感/触感/观感/使用感受/使用效果/使用过程 | 苹果口感、衣服面料、杯子保温效果…… |
| **讲头牌** | 借明星/产地/网红/品牌做对比和背书 | 欧莱雅同款、关晓彤同款减脂餐…… |
| **讲价格** | 与实体/其他直播间/同类比价，同时突出产品价值 | 茶叶一块钱低价引流，促进后续复购 |

### 24.3 直播话术体系

**互动话术**：
- **硬互动**：点名关注/点赞（需给观众一个行动理由）
- **软互动**：提问引导参与、问是否学会、问哪里不懂、问想学哪个

**产品话术结构**：
卖点描述 → 场景使用 → 附加价值 → 价格比较

示例（棉服）：
1. 卖点：保暖效果，防风防水防油
2. 场景：冬天出门、骑电动车
3. 附加价值：某某直播间同款
4. 价格：比实体店便宜多少

**促单话术**：
营造稀缺（限制产品数量、说明已售数量）→ 打开氛围 → 公屏扣数 → 引导放单

### 24.4 直播间场景与灯光

- **场景**：货架、仓库、室内（坐播/无人播/站播）
- **蓝橙光**：适合女性，色温偏暖，小清新轻松愉快
- **赛博朋克光**：科技感，适合测评/桌面摆件/数码产品/健身减脂，让人有力量

### 24.5 贴纸分区

A区（主题/专场）→ B区（福袋）→ C区（小内容）→ D区（动区，动态贴纸）→ E区（临时区）

### 24.6 直播禁忌

**三禁止**：虚假宣传、没有资质、利益诱导
**四常见**：私下引流、平台禁用词

### 24.7 直播间搭建预算三档

> 来源：第24课

不同价位的直播间搭建预算不同，分为三档：

| 档次 | 推荐设备 | 适合人群 |
|------|----------|----------|
| **入门版** | 爱图仕的灯、麦拉达的麦克风、美颜灯、手机散热器等 | 新手/预算有限 |
| **基础版** | 在入门版基础上增加台式机、显卡、采集卡等 | 有一定基础的创作者 |
| **终极版** | 在基础版基础上进一步提升电脑配置、相机和镜头等 | 专业直播团队 |

**搭建建议**：做直播需要真诚，不断练习，从看山是山到看山不是山，再到看山依然是山，理解短视频和直播的底层逻辑，按照逻辑去做，日拱一卒，最终会取得想要的结果。

## 二十六、起号方法全流程

4. **内容执行**：四大脚本（观点/过程/知识/故事）交替发布，兼顾流量和成交
5. **300粉丝就变现**：不发纯广告，用脚本类型包装产品内容
6. **跑通变现后再放大流量**：先用晒过程最大化变现，再逐步提升流量
7. **资产思维**：每一条视频、每一个粉丝都是永久资产，持续积累
