# 讲故事脚本与脚本模型进阶

> 本文件涵盖讲故事（故事型脚本）的完整方法论，以及脚本模型与模板的进阶技巧，包括拆片技巧体系。

---

## 十三、讲故事（故事型脚本）

### 13.1 核心定位

讲故事的作用：突破信任防线——让用户了解更多，突破粉丝信任防线，促进成交和提高溢价。

三种故事类型：
- **行业营销型**：为自己的事业做信任背书（如帮助村子脱贫致富，目的是招商引资）
- **日常生活型**：单纯立人设，吸引有相同经历或能感受其经历的用户（如夫妻备孕故事）
- **信任突破型**：让用户了解更多，促进成交

### 13.2 三种故事脚本结构

### ① 小有成就（需粉丝基础）

让别人羡慕——不止金钱，任何一个小成就都可以。

**四段论结构**：
1. **已达成的成就**（上来直接说成就是怎么达成的）
2. **过程中的困境**（阻碍、困难）
3. **过程中的转机**（转折点）
4. **目标带来的感悟**（总结经验/感悟）

**影响故事好看与否的关键**：中间的困境与转机。
- 困境和转机需是**经典桥段**：盲目自信、家门不幸、天灾人祸、恶霸欺压、过河拆桥、抓住商机且产生正向影响、至亲寄托（信念感）、意外之喜（无心插柳）、因祸得福（狗血）、破釜沉舟（自我改变+努力）
- **情绪递进规则**：刚开始简单 → 后面逐步变难。前面就很难后面就乏味了。

### ② 成功案例（0粉可做）

与小有成就结构相似，区别在于：
- 写的是「帮助他人成功」
- 包含「我帮助别人的部分」+「他人自己努力的部分」

示例：帮一个卖水饺的店铺卖爆单——展示自己如何策划、对方如何配合、最终取得什么成果。

### ③ 苦难经历（立人设专用）

通过讲述自己的苦难经历（如特殊病症、艰难经历等），将自己不堪的经历暴露出来，洗白人设，使人物形象更加鲜活，拉近与用户的距离。

**脚本三步结构**：

**第一步：找出自己的缺陷**
- 来源：自身特殊缺点、苦难经历（尿床、胎记、整容、性别不同、特殊癖好、生活习惯、家庭关系、亲密关系、社会关系……）
- 关键：为缺陷包装一个合理的解释

**第二步：缺陷产生原因 + 缺陷带来的痛苦**
- **猎奇型**（缺陷足够小众）：少写原因，多写困苦——尤其多写别人的嘲笑和欺负
- **共鸣型**（缺陷足够常见）：多写原因——通过和别人的对比来突出原因，让大家感知到

**第三步：释怀的感悟**
- **猎奇型**感悟方向：用自己的痛苦经历鼓励别人——「你们已经过得比我好了」
- **共鸣型**感悟方向：释怀当初的苦难，见不得别人再经历——「不想再看到任何人经历我曾经历的事」
- 注意：释怀不代表放弃

### 13.3 苦难经历的经典桥段加持

给苦难经历加上经典桥段，目的是让别人觉得更惨，体现剧情的激励性：
- **他人嘲笑**：被同学、同事、陌生人的嘲笑
- **连累他人**：因为自己连累了家人或朋友
- **阻碍成就**：缺陷阻碍了自己实现某个重要目标
- **至亲误解**：最亲近的人不理解自己
- **自我牺牲**：为他人牺牲却得不到理解

### 13.4 苦难经历的核心铁律

> 来源：第13课

**讲苦难时不许哭，要笑着讲。**

**拍摄技巧**：讲苦难时不许哭，要笑着讲。因为抖音的导向是记录美好生活，用户更愿意看到经历苦难仍心向阳光的博主，而不是在镜头前自怨自艾。

平台的导向是记录美好生活。用户更愿意看到经历苦难仍心向阳光的博主，而不是在镜头前自怨自艾。结尾必须落在**释怀和鼓励**上。纯立人设，不直接带来变现——但因为人设立住了，后续的变现会顺理成章。

### 13.5 故事创作总流程

1. 思考自己的小有成就
2. 给成就加一个阻碍（身体情况、经济条件、社会环境、他人阻挠、原生家庭……）
3. 录音说出故事素材
4. 语音转文字，打印出来
5. 识别其中的经典桥段
6. 排列组合，将经典桥段展开创作

**注意事项**：
- 避免写人物自传式的故事背景（流水账没人看）
- 写文案要增加画面感
- 多注意文案的写作技巧

## 十四、脚本模型与模板（进阶）

### 14.1 「标题党」脚本模型

适合人群：实体店主、创业老板、生活艰辛、逆风翻盘型人设。

**结构公式**：画面展现 → 内容项 → 结构 → 音乐

| 内容项 | 可选结构 | 适配音乐 |
|--------|----------|----------|
| 工作状态 / 负债 | 伤感 | 治愈 |
| 苦闷情绪 / 婆媳亲情 | 对比 | — |
| 美好生活 / 温暖 | 递进 | — |
| 艰苦生活 / 励志 | — | — |

### 14.2 讲故事创意的3F原则

| 原则 | 含义 |
|------|------|
| **Far** | 憧憬/理想/情怀——给观众一个向往的未来 |
| **Formerly** | 怀旧情感——唤起过去的记忆 |
| **Feelings** | 亲情/爱情/友情/同情——激发情感共鸣 |

**脚本结构**：人物背景 → 故事冲突（艰辛/困难）→ 美好走向（完美解决）→ 软性引导（想看此案例的……/想了解更多的……）

### 14.3 谈特色脚本模型

适用于需要突出产品/服务特色的场景。

**结构**：使用前 → 晒物品（价格/有趣/科技/颜值）→ 使用过程 → 使用后（尽量变魔法）

通过「使用前 vs 使用后」的对比来放大产品特色。

### 14.4 情绪冲突文案四角度实战句式

| 角度 | 肯定句式（去做） | 否定句式（不去做） |
|------|-----------------|-------------------|
| **追求心理** |「来___，变成___」「有___，___轻松搞定」 | — |
| **规避心理** |「来___，摆脱___困扰」 | — |
| **恐惧心理** | — |「不来___，慢慢变成___」「不懂___，将没有一个___」 |
| **失去心理** | — |「不来___，失去___」「不懂___，将失去___」 |

**具体示例**（以健身房为例）：
- 追求：「来健身房，变成更好的自己」
- 规避：「来健身房，摆脱肥胖困扰」
- 恐惧：「不来健身房，慢慢变成胖子」
- 失去：「不来健身房，与曼妙身材永远告别」

#### 14.5.3 拆片表格两部分

> 来源：第14课 / 视频总结-拆爆款

拆片表格分为两大部分：

**① 账号策划部分**：
- 内容类型
- 主题IP策划
- 爆款元素
- 人设（6类：崇拜者、教导者、分享者、陪伴者、衬托者、搞笑者）

通过观察账号封面、浏览视频和查看合集等方式，可以识别博主的内容类型、主题IP策划和爆款元素。

**② 单条内容部分**：
- 选题类型
- 写作对象
- 脚本结构

#### 14.5.4 四大脚本结构拆解

> 来源：第14课

| 脚本类型 | 脚本结构拆解 |
|----------|-------------|
| **教知识** | 新奇事件开篇 → 解释事件加美好预期 → 科普原理加美好预期 → 人群加对应方法加训练好处 → 评论区给福利 |
| **说观点** | 共同敌人加错误行为 → 列举事件 → 行为带来的负面结果 → 理想状态 → 结尾再骂一句 |
| **讲故事** | 心愿与现实有巨大差距 → 透露现实状况的线索 → 揭秘现实的窘迫 → 偶然时机有了与现实不符的心愿 → 心愿被拒绝产生负面情绪 → 心愿有更大惊喜的转折 → 心愿转机但自己放弃 → 事件带来感悟 → 多年后心愿再次出现发现已得到更重要的东西 |
| **晒过程** | 交代任务设置目标 → 透露难度 → 发现目标 → 遇到阻碍 → 成功调情 → 拍片成果 |

#### 14.5.5 不值得拆解的视频

> 来源：第14课

以下三类视频不值得花精力拆解：
1. **营销型视频**：纯营销内容，无创作逻辑可学
2. **人物本身身份或特质极为特殊的视频**：无法复制的人物特质
3. **对口型变装等无商业属性的视频**：无商业变现价值

**拆片训练建议**：从简单的视频开始拆解，逐渐过渡到复杂的脚本，以提升网感和积累爆款视频结构。带着拆片思维看爆款视频能看出门道，进入专业创作者行业。
