# 晒过程与教知识脚本

> 本文件涵盖晒过程（过程型脚本）和教知识（知识型脚本）两大脚本类型的完整方法论，是内容创作的核心实战指南。

---

## 十一、晒过程（过程型脚本）

### 11.1 核心定位

**最利于成交的脚本类型——能展示实力，秀出过程，让用户眼见为实。**

几乎是所有内容平台的终点：拍500个过程比教500个知识更容易。知识类视频可以通过改变呈现方式（如利用特定角色说出知识）增加可信度，使其变成"轻过程"。一个好内容的定义核心：**能否制造情绪曲线**——一个视频可以没头没尾，但必须要有情绪。

### 11.2 四大内容方向

| 方向 | 描述 | 适用行业 |
|------|------|----------|
| **制作过程** | 展示原料→过程→成品，让用户产生信任和溢价空间 | 食品、手工艺、修手机、装修、卖辣椒酱、火锅底料、珠宝串…… |
| **测评产品** | 横向（同类不同品牌比较）/ 纵向（单产品多维度验证），看上去在测评实际在带货——替顾客当质检员 | 充电宝、纸尿裤、手机…… |
| **任务挑战** | 没有困难制造困难，目标明确、困难可衡量 | 1000元在上海玩四天、一分半吃完一根香肠奖励1000元、一个星期花200减掉十斤 |
| **改造对比** | 正向改造 / 反向改造 / 升级过程 | 发型、穿搭、妆容、厨房、直播间…… |

### 11.3 埋钩子：让用户从头看到尾的技巧

在视频开头设置钩子，吸引用户从视频开头看到结尾，增加停留时长，从而提高流量。钩子类型包括：免费充电宝、饮料、熟人、明星、抽奖等。

### 11.4 建立期待感的十个技巧

| 技巧 | 说明 | 应用示例 |
|------|------|----------|
| **送温暖** | 给陌生人惊喜/帮助 | 给环卫工人送早餐 |
| **金钱** | 涉及金钱的刺激 | 猜对价格就送给你 |
| **怀旧** | 勾起过去的记忆 | 复刻小时候的味道 |
| **对抗** | 设置对立/竞争 | PK谁能吃完 |
| **惊喜** | 制造意外惊喜 | 偷偷给妈妈买她舍不得买的 |
| **意外** | 出乎意料的情节 | 以为翻车了结果没有 |
| **盲盒** | 未知结果的期待 | 随机抽一家店吃到撑 |
| **验证** | 验证某种说法 | 测试网红产品是不是真的好用 |
| **解密/揭秘** | 揭晓未知/内幕 | 揭秘行业内幕 |
| **整蛊** | 恶作剧/玩笑 | 假装忘记对方生日然后给惊喜 |
| **荷尔蒙** | 颜值/身材吸引力 | 帅哥美女相关视觉内容 |

### 11.5 困难制造维度

- **金钱维度**：花小钱办大事（100元过一天）/ 花大钱办小事（挑战花1万做最丑的造型）
- **时间维度**：短时间多数量缺人手（一小时做100个 cupcake）

### 11.6 趣味玩法：「单钩钓」

核心：**强化过程，弱化结果。**

三种事件体验类型：
| 类型 | 描述 | 示例 |
|------|------|------|
| **新奇体验** | 体验普通人平时没见过的 | 盲人出行体验、老板体验员工的一天 |
| **奇葩规则** | 设定荒谬的规则 | 挑战运动洗脸——不管师傅怎么洗都怪他没吃饭 |
| **角色扮演** | 切换身份视角 | 内行人假装外行人的体验 |

### 11.7 创作顺序

确定方向 → 罗列关键步骤 → 加入钩子 → 丰富过程 → 多看他人作品提升创作能力

### 11.8 晒过程脚本「火车节模型」

```
关键步骤1 ──→ 关键步骤2 ──→ 关键步骤3 ──→ 关键步骤4 ──→ 关键步骤5
   │              │              │              │              │
  转场           转场           转场           转场           转场
   │              │              │              │              │
 起因           经过           经过           经过           结果
   │              │              │              │              │
确认场景点    提炼步骤点    抛出难题点    展现专业点    结果展示
（预描场景、  （置身事外、  （描述经过、  （手法技巧、  （成果呈现）
 联想画面）    聚焦环节）    提炼核心）    过程成品）
```

## 十二、教知识（知识型脚本）

### 12.1 核心定位

教知识易转粉、涨精准流量、塑造良好人设。

**教知识的本质是信息差**——在短视频平台上，只要有信息差就可以教知识。信息差来自素材库。通过搭建素材库并输出知识，既能在平台上获得流量，也能使自己快速成长。

### 12.2 五大选题维度

| 维度 | 含义 | 典型内容 |
|------|------|----------|
| **追求更好** | 帮别人变得更好 | 穿搭教程、化妆技巧、学习方法 |
| **解决难题** | 帮别人解决具体问题 | 瘦脸方法、收纳技巧、吵架话术 |
| **避免踩坑** | 帮别人提前避开陷阱 | 装修避坑、买车避坑、求职避坑 |
| **降低成本** | 帮别人省金钱/省时间/省力 | 平替推荐、省钱攻略、效率工具 |
| **丰富谈资** | 帮别人获得吹牛/聊天的资本 | 冷知识、行业内幕、谈资类内容 |

**筛选逻辑**：日常难题 + 放大危机，二选一。
- **日常难题**：用画面感描述场景难题
- **放大危机**：用恐惧心理写放大危机
- 实在不行 → 去同行评论区找高赞问题（评论区的高赞问题就是最好的选题来源）

### 12.3 获得感三要素——教知识能火的核心

教知识能火的核心是给观众带来**获得感**。获得感有三个维度：

| 维度 | 含义 | 通用句式 |
|------|------|----------|
| **信息多** | 一口气给大量信息 | "16种营销模式""史上最全……""100首营销音乐""盘点排名" |
| **效果快** | 快速见效 | "一秒搞定……""三分钟学会……""几秒钟学会弹钢琴""1秒钟学会单词" |
| **料够猛** | 谈资类/内幕类内容 | "只有内行人才知道的……""99%的人不知道……""行业内幕揭秘" |

### 12.4 四大教知识脚本子类型

#### ① 解题型

**结构**：场景难题 + 放大危机 → 给出低成本解决办法

**要点**：
- 场景难题：把生活中的糗事用画面感描述出来，描写小细节
- 危机：利用人的恐惧心理，吓唬观众
- 解决办法：低成本、简单易行

**示例**：「瘦脸」——场景：拍照永远要找角度、P图P半天；危机：再不瘦脸以后婚纱照都没法拍；办法：三个零成本瘦脸动作，每天两分钟。

#### ② 推荐型

**结构**：开篇（3选1）→ 推荐内容 → 给出理由

**要点**：
- 推荐至少3个
- 获得感强的排前面
- 理由30~40字，要简短有力
- 可以多给知识或推荐内容
- 门槛低、行动成本低的排在前面

**开篇三选一方式**：
1. 美好愿景：「想要厨房永远干净整洁？」
2. 圈定人群：「所有小腿粗的女生看过来」
3. 引发好奇：「只有内行人才知道的6个……」

#### ③ 揭秘型

**结构**：直接提出揭秘事件 → 讲述事件内情

**要点**：
- 揭秘的事件必须与大众生活息息相关（如装修内幕、话费慢充灰色产业、食品安全等）
- 勇敢暴露缺点，让观众感受到真诚

#### ④ 案例型

**结构**：提出案例并描述 → 提取案例中的知识点 → 告诉用户怎么做

**要点**：
- 案例要有热度——热点案例、成功案例、失败案例、名人案例、影视桥段
- 创作思路①：先有案例，结合行业输出知识
- 创作思路②：先有知识，结合知识找案例支撑

### 12.5 教知识脚本常见四大错误

> 来源：12天实操班Chapter.7-9 / 第11课

| 错误 | 表现 | 正确做法 |
|------|------|----------|
| **用词专业** | 说行业术语、学术词汇 | 说接地气的话，村头老太太都听得懂 |
| **反馈过长** | 「让孩子多读书三年后有见识」 | 改为「三天后有效果」 |
| **排列不好** | 获得感弱的内容排前面 | 获得感强的放前面，门槛低行动成本低的放前面 |
| **对象模糊** | 开篇不说清楚写给谁 | 开篇明确写作对象（如"所有孩子写作文困难的家长"） |

### 12.5.1 教知识不火的原因

> 来源：第11课

1. **讲原理不如给方法**：直接给答案比讲原理更有流量。例如讲减肥的视频，给方法的点赞多。
2. **不符合小宝宝法则**：教知识要寓教于乐，把观众当成小宝宝哄开心，不要讲太多原理。拍剪要好，表现力要提高。

### 12.6 小宝宝法则

教知识要**寓教于乐**——把观众当成小宝宝哄开心，不要讲太多原理。直接给答案比讲原理更获流量。拍剪要好，表现力要提高。
