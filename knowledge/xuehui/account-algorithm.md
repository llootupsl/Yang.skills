# 账号搭建与平台算法机制

> 本文件涵盖账号搭建与CIS企业形象识别体系（含超级符号、人设6类）和平台算法机制（含标签机制、推流机制、违规行业清单），是账号运营的底层规则体系。

---

## 二十、账号搭建与CIS识别体系

### 20.0 账号体系四步法

> 来源：12天实操班Chapter.3

账号搭建遵循四步递进流程：

| 步骤 | 内容 | 说明 |
|------|------|------|
| **Step 1** | 明确商业定位 | 变现方式（卖货/引流/广告/直播） |
| **Step 2** | 明确内容定位 | 主题IP + 人物IP（受众面广、更易变现） |
| **Step 3** | 账号鲜活人设 | 通过6大方向输出塑造鲜活人设 |
| **Step 4** | 建立识别系统 | 超级符号（MI理念 + BI行为 + VI视觉） |

完整链路：商业定位 → 内容定位 → 账户搭建（头像/昵称/简介/头图）→ 超级符号 → 涨粉/持续/变现

### 20.1 CIS企业形象识别系统（适配个人IP）

CIS系统是帮助账号建立统一、专业的品牌形象的核心工具，分为三个层面：

| 层面 | 含义 | 内容 |
|------|------|------|
| **MI（理念识别）** | 账号的核心价值观和理念 | 广告语/slogan、账号定位宣言 |
| **BI（行为识别）** | 账号的独特行为模式 | 经典一句话、经典动作、经典风格、经典声音 |
| **VI（视觉识别）** | 账号的视觉呈现系统 | 头像、头图、简介、昵称、服装、造型、固定视觉元素 |

#### 20.1.1 账户搭建头图尺寸

> 来源：12天实操班Chapter.3

| 参数 | 数值 |
|------|------|
| **头图尺寸** | 1125*633像素 |
| **分辨率** | 72 |
| **核心内容尺寸** | 900*400像素 |

### 20.1.2 人设6类

> 来源：第14课（短视频爆款拆片技巧）

在拆片练习中，通过账号策划部分识别人设类型，人设分为6类：

| 序号 | 人设类型 | 说明 |
|------|----------|------|
| 1 | **崇拜者** | 让用户崇拜、仰望的人设 |
| 2 | **教导者** | 教导用户知识/技能的人设 |
| 3 | **分享者** | 分享经验/好物的人设 |
| 4 | **陪伴者** | 陪伴用户成长的人设 |
| 5 | **衬托者** | 作为衬托/配角的人设 |
| 6 | **搞笑者** | 制造欢乐/搞笑的人设 |

### 20.2 超级符号体系

超级符号是让用户一眼认出你的"视觉+行为"标签体系：

**① 视觉符号**
| 类型 | 示例 |
|------|------|
| **服装/造型** | 厨师服、旗袍、国风汉服、帽子+不露脸+文字排版 |
| **配件** | 黑色口罩、特定颜色围巾 |
| **固定视觉** | 定格画面+固定音乐+特效文案、固定开场图片 |
| **卡通形象** | 猫头套、卡通猪头、卡通牛头、漫画形象（鱼/人物）、简笔画 |

**② 行为符号**
| 类型 | 示例 |
|------|------|
| **经典一句话** | "大家好，我是___"（自我介绍）、"OMG！买它！"（行业经典话术）、"爱你呦！"（情绪）、"早啊！你们起床了没？"（问候） |
| **经典动作** | 敲木鱼、擦灶台+求赞 |
| **经典风格** | 咆哮风格、暴躁风格全程喊着教知识 |
| **经典声音** | 慵懒磁性的声音、港台腔、方言 |

**③ 组合型超级符号**
| 组合方式 | 示例 |
|------|------|
| **造型 + 一句话** | 容嬷嬷造型 + "你看我扎不扎你就完了" |
| **视觉 + 行为** | 经典造型 + "按时吃饭" |
| **固定开场 + 一句话** | 正面跟随走路 + "我是金牌秘书___" |

**④ 广告语/slogan（MI层）**
- "爱设计超过爱男人"
- "好酒莫贪杯，微醺胜买醉"

### 20.3 账号头像/昵称/简介7个关键点

| 维度 | 要求 |
|------|------|
| **行业关键词** | 昵称必须直接体现行业 |
| **人物出镜** | 头像是真人，增加信任感 |
| **内容价值** | 简介直接传达你能给用户什么价值 |
| **行动成本** | 让用户一眼知道关注你能得到什么 |
| **涨粉阶段** | 用赞粉比评估阶段，调整策略 |
| **商业化** | 简介预留变现路径 |
| **敏感词汇** | 避免敏感词被限流 |

### 20.4 策划内容定位公式

**什么身份 + 什么场景 + 什么动作/道具 + 用怎样的机位 + 带着什么态度**

变量库：
- **身份**：大叔、宝妈、留学生、宠物、老师、财务、潮人、厨子……
- **场景**：书桌、阳台、办公室、外国、楼梯间、大街上、饭馆、走廊……
- **动作/道具**：古装、动物头套、说唱、方言、沙雕、严肃、鸡汤……
- **机位**：特写、直男视角、仰天45°、采访视角、居中构图、偏左构图……
- **态度**：搞笑、土味、严肃、暴躁、悄悄的、分饰两角……

### 20.5 账号运营策划表框架

完整的账号策划应包含：

| 模块 | 内容 |
|------|------|
| **商业定位** | 有产品承接（少即是多）/ 无产品承接 |
| **内容定位** | 主题IP + 人物IP |
| **账号体系** | 超级符号（MI理念 + BI行为 + VI视觉） |
| **账户搭建** | 头像 + 头图 + 简介 + 昵称 |
| **脚本策划** | 讲故事 / 晒过程 / 教知识 / 谈特色 / 尬段子 |
| **呈现形式** | 真人口述 / 视频+配音 / PPT / 情景剧 |
| **素材体系** | 平台 + 账号 |
| **内容配比** | 赛道主线 + 人群辅线 |

## 二十一、平台算法机制

### 21.0 名词解析

> 来源：12天实操班Chapter.1

#### 21.0.1 计费方式

| 词汇 | 含义 |
|------|------|
| **CPM** | 按千次曝光计费 |
| **CPC** | 按单次点击计费 |
| **CPS** | 按佣金分成计费 |
| **CPT/CPD** | 按天数计费 |
| **CPA** | 按某个指定行动计费 |

#### 21.0.2 运营效果词汇

| 词汇 | 含义 |
|------|------|
| **KPI** | 关键绩效指标：指客户对我们合作希望达到的数据指标 |
| **ROI** | 投资回报率：就是客户的投资收益比 |
| **客咨成本** | 指客户咨询行为所付出的单笔成本 |
| **导流成本** | 指用户点击落地页或跳转页面的单笔成本 |
| **加粉成本** | 指用户成为粉丝所付成本 |
| **转化成本** | 指用户付费行为单笔所需成本 |

#### 21.0.3 内容运营词汇

| 词汇 | 含义 |
|------|------|
| **素材** | 未加工过的原始内容，一般都是先建立素材库后才开始批量生产内容的 |
| **选题** | 指选择输出内容的题目，选题的好坏起了决定性作用 |
| **Ctr** | 指点击率，有多少用户看到题目后点击了您的内容 |
| **拆片** | 指看到优质作品时，模仿的手法，将视频以视角、对话、场景等维度进行拆片 |
| **规范** | 平台对于不允许出现的内容的审核边界 |
| **AB test** | 指不改变主体内容只改变单一元素 |

#### 21.0.4 用户运营词汇

| 词汇 | 含义 |
|------|------|
| **用户画像** | 指用户的属性例如：地域，性别，年龄等标签 |
| **转化率** | 指后端销售转化率 |
| **UV** | 即Unique Visitor，独立访客量。是指访问您网站的一台电脑客户端为一个访客 |
| **PV** | 即Page View，即页面浏览量或点击量，PV反映的是浏览某网站的页面数，所以每刷新一次也算一次 |
| **DAU** | 即Daily Active User日活跃用户数量，当天登陆用户总和 |
| **MAU** | 即Monthly Active Users月活跃用户数量，当月登陆用户总和 |

#### 21.0.5 活动运营词汇

| 词汇 | 含义 |
|------|------|
| **Brief** | 需求，指发起某个活动的活动目的等需求信息 |
| **Campaign** | 指一次活动的项目策划方案，较完整大型方案的统称 |
| **Budget** | 活动预算 |
| **MAP图** | 指时间推进表，此次活动每日进程计划表 |
| **Arup值** | 指平均单用户的付费价值 |

### 21.1 标签机制

| 标签类型 | 作用 | 优先级 |
|----------|------|--------|
| **用户标签** | 基于点赞/收藏/评论/转发/关注/滑走行为给用户打标签 | — |
| **账号标签** | 无作品标签时的备用推流依据 | 不重要 |
| **作品标签** | 帮助平台精准识别视频内容，推给精准人群 | 最重要 |

**话题设置**：领域话题 → 行业话题 → 内容话题 → 自建话题。推荐使用：1个行业话题 + 2个内容话题。

### 21.2 推流机制（赛马机制）

同赛道视频竞争流量，数据好的获得更多流量。

- **初始流量**：200~500
- **考核指标**：完播、点赞、转发、评论、转粉、收藏
- **完播率是最核心指标**
- **规则**：同时长比完播率 → 不同时长比完播时长 → 完播时长越长流量越大

### 21.3 铁粉机制

- 对有粉丝的账号 → 可能导致掉粉和难破圈
- 对新号 → 有利低粉变现（铁粉先看到，容易产生购买行为）
- **破圈方法**：多维高频更新

### 21.4 小黄车推流

考核：橱窗点击率 + 商品转化率（后台根据这两个数据决定是否给流量）

### 21.5 图文推流

考核：完播率 + 互动 + **手动画图率** + **展开完读率**。需注意图的好看性 + 文案钩子。

### 21.6 账号权重诊断

| 等级 | 播放量区间 | 特征与对策 |
|------|-----------|------------|
| **僵尸号** | <100 | 持续一周<100，基本等于废号，建议注销重开 |
| **最低权重号** | 100~200 | 只会被推荐到最低流量池，可模仿热门段子提高互动和播放量；21天没突破会降为僵尸号 |
| **中途降权号** | >1000后突然降低 | 可能发了硬广或搬运他人作品被识别后降权（关进小黑屋），等待释放 |
| **待推荐账号** | 1000~3000 | 持续发布高质量/垂直领域优质作品，有可能被推荐到更大流量池 |
| **待上热门号** | >10000 | 每次基本都有1万播放量，配合蹭热点/官方话题/最火音乐可加速上热门 |

### 21.7 降权限流常见原因

1. 破坏社会团结、宣扬民族歧视
2. 封建迷信、风水、塔罗、星座占卜
3. 涉及他人隐私、个人信息或资料
4. 搬运他人作品、抄袭
5. 吸烟、暴力、恐怖、色情、赌博等
6. 留外部联系方式（威信、薇、围脖、扣q等）
7. 视频中出现微信、微博、淘宝等水印
8. 长时间出现商品logo/手机号/二维码（超3秒）
9. 视频内含有其他水印（视频平台/剪辑软件）
10. 视频清晰度太低、画质较差
11. 内容明显是营销广告
12. 直播中明显引流、卖货、推销行为
13. 直播中口播广告、联系方式
14. 纯图片轮播（带商品更严重）
15. 无口播拆箱物品或好物推荐

### 21.8 审核流程

机器检测 →（有问题）人工检测 → 查画面/文案/音乐/关键帧 → 违规则删除/封号 → 可申诉

### 21.9 限流申诉

账号检测 → 抖加检测 → 联系人工客服（态度卑微、明确诉求、照读句式成功率高）

### 21.10 违规行业14类清单

> 来源：12天实操班Chapter.2

以下行业禁止在平台投放/运营：

| 序号 | 违规行业 |
|------|----------|
| 1 | 彩票资讯或书籍相关 |
| 2 | 成人用品、计生用品 |
| 3 | 酒类 |
| 4 | 视频、直播、拍摄工具类 |
| 5 | 头条产品竞品 |
| 6 | 医疗机构、医疗平台 |
| 7 | 药品 |
| 8 | 保健品 |
| 9 | 医疗器械 |
| 10 | 棋牌捕鱼游戏 |
| 11 | 成人视角男权女奴等游戏 |
| 12 | 不接受信用卡代办平台或者代理公司业务 |
| 13 | 社区社交，相亲类产品 |
| 14 | 娱乐经纪产品（优质品牌客户可以商榷，例如：国际或国内知名产品的品牌宣传） |

### 21.11 扶持加权5项

> 来源：12天实操班Chapter.2

满足以下条件的作品将获得平台扶持加权：

| 序号 | 扶持条件 |
|------|----------|
| 1 | 竖版移动端原生视频 |
| 2 | 画面平稳，作品高清 |
| 3 | 作品无过多杂音噪音 |
| 4 | 作品主题及内容明确，易归类 |
| 5 | 抖音官方热推的热门内容，话题，挑战等内容 |
