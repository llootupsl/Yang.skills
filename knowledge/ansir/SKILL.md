# 安先生短视频创作知识体系

> 本知识体系基于安先生（"亲爱的安先生"）91节短视频课程、内部直播课、262个案例分析、思维导图与课程总结深度蒸馏而成，覆盖从认知准备、账号定位、选题结构，到导演级视听语言、时间的语法、信息特性、销售成交与本地生活的完整创作框架。
>
> 核心原则：不要问"什么赛道能做"，要问"我能做什么"——这决定了你的起点、路径和终点。

本知识库已按主题拆分为12个独立文件，每个文件自包含、可独立阅读。请通过下方文件索引定位具体主题。

## 使用说明

### 如何通过索引定位具体主题

1. **按需求查找**：根据你想解决的问题，在上方表格的"核心内容"列中找到对应关键词，然后打开对应文件。

2. **按关键词查找**：如果你知道具体关键词（如"钩子""骨架""张晓阳"），可以打开 `curriculum.md` 查看关键词索引，它会指引你到正确的文件和章节。

3. **按学习阶段查找**：
   - **新手入门** → 先读 `cognition-positioning.md`（认知与定位）→ 再读 `content-methods.md`（内容方法论）
   - **结构精进** → `hooks.md`（钩子）→ `emotion-system.md`（骨架与情绪刺点）→ `master-thinking.md`（大师思维）
   - **视听进阶** → `audiovisual.md`（导演级视听语言）→ `info-traits.md`（信息特性）
   - **运营变现** → `content-methods.md`（漏斗模型）→ `info-traits.md`（销售成交）→ `advanced-insights.md`（起号流程）
   - **实操落地** → `practice-sop.md`（自查清单与SOP）→ `audiovisual.md`（行动日历）
   - **心态建设** → `advanced-insights.md`（创作者心态建设的十个真相）

4. **按课程查找**：如果你想查找某节课的内容，打开 `curriculum.md` 查看91节课标题清单。

5. **按案例查找**：如果你想参考具体案例，打开 `cases.md` 查看262个案例清单，或打开 `industries.md` 查看30个行业爆款分析。
