# 开篇36计之文案钩子（计1-计28）

> **模块定位**：28种文案开篇钩子，覆盖视频前3秒"说什么"，每种钩子包含文案目的、用户观看动机、开篇类型、话术模板、实战案例和变体。

---

## 钩子类型分类总览

| 分类 | 包含钩子编号 | 触发心理 |
|------|------------|---------|
| **悬念/好奇类** | 计1/2/4/6/12/13/15/18/20/22/25 | 引发好奇、拉停留 |
| **共鸣/认同类** | 计3/8/9/17/21/23/28 | 与我相关、找认同 |
| **冲突/争议类** | 计5/14/16/24/26/27 | 引发冲突、引起好奇 |
| **恐惧/焦虑类** | 计7/10/11/19 | 恐惧心理、损失厌恶 |

---

## 计1：圈定人群

| 维度 | 说明 |
|------|------|
| **文案目的** | 让目标用户觉得"这条视频就是对我说的" |
| **用户观看动机** | 与我相关 |
| **开篇类型** | 人群属性点名 |
| **话术模板** | `{人群标签} + {要讲的事}` |
| **话术举例** | "微胖女生买裤子""新手刚学化妆""我是很羡慕水瓶的""穷人的孩子""年轻人怎么不靠打工养活自己""今年想要翻身你必须做到三点""这个宝妈认真拍了89条视频""普通人如何挣到自己人生的第一桶金" |
| **人群标签库** | 男女、星座、穷富、普通人、年轻人、姐妹们、兄弟们、新手、负债的人、30岁的人 |
| **变体** | "如果你……那你一定要看这条视频"、"给所有……的人提个醒" |

## 计2：直接提问

| 维度 | 说明 |
|------|------|
| **文案目的** | 用提问直接唤起用户的参与感 |
| **用户观看动机** | 与我相关、引发好奇心、被迫回答问题 |
| **开篇类型** | 直接发问 |
| **话术模板** | `你知道吗？/你敢相信吗？/你有没有发现……/你为什么……？/是不是……？/为什么……？/你见过……` |
| **话术举例** | "你相信吗？在水下生活""你为什么一定要准备好才肯出发呢？""你敢相信吗？""你可能都想象不到""你有没有发现陈思诚""如果你在背祖笔里揽一顿黄金""你为什么……？""是不是……？""为什么……？""你见过……""给你们看个厉害的" |
| **变体** | "给你看个厉害的……"——不直接提问，用暗示引发好奇 |
