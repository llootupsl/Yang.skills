# 短视频新手起号与开篇钩子方法论 · 系统化知识库

知识库已按主题拆分为7个子文件，每个文件自包含、可独立阅读。

## 使用说明

### 推荐学习路径

1. **第一步**：阅读 `principles.md`，建立底层认知（5大原则）
2. **第二步**：按 `account-setup.md` 完成账号搭建（计1-计8.5）
3. **第三步**：用 `content-strategy.md` 规划内容策略（计9-计18）
4. **第四步**：从 `cold-start.md` 选1-2个冷启动策略执行（计19-计28）
5. **第五步**：每条视频从 `copywriting-hooks.md` 和 `visual-hooks.md` 各选1个钩子组合使用
6. **全程**：参考 `pitfall-avoidance.md` 避开常见坑（计29-计46）

### 关键使用建议

- **起号36计**：按顺序执行——先看完五大原则→完成账号搭建→规划内容策略→执行冷启动→避坑
- **开篇36计**：每条视频前3秒从文案钩子（计1-28）和画面钩子（计29-36）中各选1个组合使用
- **13种开篇方法可以混合使用**，2种以上钩子组合往往效果更佳
- **新手第一原则**：先模仿后创新，用24宫格差异化策划表在同行基础上做差异化
