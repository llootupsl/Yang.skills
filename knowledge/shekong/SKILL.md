## 一、新手起号五大原则

> **来源**：起号36计 | 提炼自课程开篇"两个灵魂拷问"与"三个致命的认知错误"，构成新手上路前必须建立的底层思维框架。

### 两个灵魂拷问（来源：起号36计）

**灵魂拷问1：什么样的内容有流量？**
> **答案**：让人看了有反应、有情绪变化的内容。具体哪些内容看了有反应？——有趣、有用、有共鸣、有猎奇、能治愈、恐惧、损失厌恶、焦虑、色欲、傲慢、美好、惊喜。

**灵魂拷问2：短视频内容类型有哪几种？你适合拍哪种内容？**
> **答案**：有些人理性擅长讲知识，有些人可能是专业性很强，需要根据自身特点选择适合的内容类型。内容类型分为：知识型、故事型、晒事件过程、观点型、段子型。

### 原则1：视频整体性思维

**核心认知**：同一个文案不同人说流量天差地别，因为视频是多轨道内容，不是单一公众号文案。

| 轨道维度 | 说明 | 关键问题 |
|---------|------|---------|
| 视频文案 | 说的内容 | 有没有信息增量？有没有情绪波动？ |
| 人物形象 | 谁在说 | 外形是否匹配赛道预期？有无记忆点？ |
| 讲话姿态 | 怎么说的 | 真诚随意 > 刻意表演；情绪高低 |
| 所处环境 | 在哪说的 | 原生场景 > 纯白背景；场景是否强化人设？ |
| 灯光效果 | 画面质感 | 光线是否让画面有专业感？ |
| 画面画质 | 拍摄质量 | 清晰度是否达标？画面稳不稳？ |
| **视频文案内容的适配度** | 人物、场景和内容的匹配度 | 人物、场景和内容是否适配？不要让讲理财的人坐大排档 |

> **人物、场景和内容的适配度要高**：不要让一个讲理财的人坐在大排档，不要让一个讲育儿的人穿着睡衣在杂物间。

### 原则2：口语化表达

**核心认知**：口语化文案适用于99%的视频，书面语只占1%。

| 对比维度 | 书面语（❌ 不要） | 口语化（✅ 要） |
|---------|-----------------|---------------|
| 句式 | 长句、从句嵌套 | 短句、一句话一个意思 |
| 用词 | 书面词汇、成语堆砌 | 日常用词、大白话 |
| 语气 | 端着、像在念稿 | 放松、像在聊天 |
| 检验标准 | 读出来别扭 | 读出来就是你平时说话的样子 |

> **金句**：你平时怎么说话，拍视频就怎么说话。不要端着。

### 原则3：内容结构均衡

**核心认知**：一个成熟账号应该有4种内容结构组成，变现差的账号往往只有观点型内容。

| 内容结构 | 占比 | 功能 | 表现 |
|---------|------|------|------|
| 说观点（引发共鸣） | ~30% | 获取流量、拉新粉丝 | 讲目标用户本来就认同的观点 |
| 讲知识（塑造专业） | ~40% | 建立信任、展示专业度 | 解决用户痛点、传授技能方法 |
| 晒事件过程（实操引流） | ~20% | 展示真实、引导私域 | 记录真实过程、展示实操细节 |
| 讲故事（立人设） | ~10% | 建立情感连接、人格魅力 | 个人经历、客户故事、成长历程 |

> **警示**：只发共鸣型文案的账号（零食类等少数品类除外），虽有流量但变现困难。必须有讲知识、晒过程的内容来建立专业信任。

### 原则4：定位先行

**核心认知**：做账号前必须明确回答5个定位问题。

```
你以什么样的身份 →（人设定位）
在什么样的场景里 →（呈现定位）
说什么样的话     →（内容定位）
去吸引什么样的人 →（用户定位）
对你产生信任     →（变现定位）
购买你的产品
```

**定位表模板**：

| 定位维度 | 填写内容 |
|---------|---------|
| 人设定位（你是谁） | 职业身份 + 个人形象 + 特殊经历 + 反差感 |
| 呈现定位（用什么形式输出） | 真人口述 / 情景剧 / Vlog记录 / 图文配音 |
| 内容定位（输出的内容让目标用户喜欢） | 讲知识 + 说观点 + 晒过程 + 讲故事 |
| 用户定位（产品卖给谁） | 人群画像：年龄、性别、痛点、消费能力 |
| 变现定位（产品是什么） | 实体产品 / 知识付费 / 咨询 / 广告 / 引流私域 |

**定位表举例（来源：起号36计）**：

| 账号名称 | 人设定位 | 呈现定位 | 用户定位 | 内容定位 | 变现定位 | 视频记忆点 | 账号整体风格调性 |
|---------|---------|---------|---------|---------|---------|-----------|---------------|
| **社恐编导小黄** | 讲干货的社恐编导 | 坐着口播 | 学短视频的人 | 1.账号拆解 2.帮粉丝做账号 3.人设故事 4.个人观点 | 卖短视频课 | 暂无 | 沉浸感比较专业一些 |
| **叶公主** | 裸辞开店的、家里有点钱请发财 | 随机给粉丝Vlog | 00后创业的年轻人 | 刮彩票 | 卖招商加盟 | 暂无 | — |

### 原则5：先模仿后创新

**核心认知**：新手不要原创，先找到一个对标账号完整模仿，掌握"网感"后再创新。

| 阶段 | 做法 | 周期 |
|------|------|------|
| 模仿期 | 找一个同行对标账号，拆解其选题、脚本结构、呈现形式，1:1模仿 | 1-3个月 |
| 差异化期 | 在同行账号上加一个改变（用24宫格差异化策划表） | 2-4个月 |
| 创新期 | 形成自己的风格记忆点，原创选题和内容 | 4个月+ |

> **素材库原则**：看了30万条视频筛选分类总结下来的收藏夹体系——开篇、观点型（男女粉分层）、晒过程、挑战体验盲盒、呈现形式、立人设故事等。

## 二、起号36计之账号搭建篇（计1-计8）

> **模块定位**：在发第一条视频之前，把账号基础打好。解决"账号叫什么、长什么样、发什么内容、用什么形式发"的问题。

---

### 计1：赛道选择与人群定位

**策略名称**：赛道选择——窄赛道优先

**核心原理**：新手起步，泛赛道竞争激烈（千万级创作者），窄赛道（细分领域）更容易拿到初始流量和精准粉丝。先做窄做深，拿到正反馈后再扩赛道。

**操作步骤**：
1. 列出你感兴趣且能持续产出的3-5个领域
2. 用"24宫格差异化策划表"在每个领域中找到细分切口
3. 评估细分赛道：竞争程度 + 变现空间 + 你能否持续产出
4. 选中1个窄赛道，All-in 至少3个月

**话术模板**：
- 不要做"美食"，要做"家庭版减脂餐"
- 不要做"育儿"，要做"0-3岁新手妈妈的育儿避坑"
- 不要做"穿搭"，要做"小个子微胖女生的通勤穿搭"

**避坑指南**：
- ❌ 选"你喜欢但没人看的"赛道——没有受众=没有流量
- ❌ 一上来就做泛娱乐——泛娱乐起号难度极高
- ❌ 同时做多个赛道——新手专注一个，精力聚焦
- ✅ 选"有人搜 + 你能持续输出 + 有变现空间"的赛道

---

### 计2：人设定位

**策略名称**：人设三角定位法

**核心原理**：用户关注你不是因为你的内容"有用"，而是因为"你这个人"值得关注。人设=职业身份 + 个人形象 + 特殊经历 + 反差感。

**操作步骤**：
1. **职业身份**：你是做什么的？（医生/律师/教师/创业者……）
2. **个人形象**：你长什么样？有什么外形记忆点？（高矮胖瘦/发型/穿衣风格）
3. **特殊经历**：你有什么与众不同的经历？（失败/逆袭/特殊选择）
4. **反差感**：你身上有什么矛盾点让人好奇？（高学历摆地摊/富二代送外卖）

**人设案例参考**：
- 4次剖腹产妈妈 → 职业身份+特殊经历
- 500万给儿子开幼儿园的爸爸 → 特殊经历
- 没见过世面的有钱人 → 反差感人设
- 小马只有一米九 → 个人形象
- 讲留学的暴躁大叔 → 职业+个人风格反差
- 不会疼的牙医 → 职业+反认知差异点
- 淫羊藿一姐 → 职业+反差
- 卑微男友/霸道女友 → 关系定位+情绪标签

**避坑指南**：
- ❌ 人设造假——被拆穿即社死
- ❌ 人设过于平淡——没有记忆点
- ❌ 人设与内容脱节——用户认知混乱
- ✅ 人设可以放大真实特质，但不能凭空捏造

---

### 计3：内容来源与5大内容类型

**策略名称**：5大内容类型 + 5个内容来源

**核心原理**：内容的本质只有5种类型（知识/故事/晒过程/观点/段子），来源只有5个方向。搞清楚你要发哪种类型、从哪取材，就不会断更。

**5大内容类型**：

| 类型 | 说明 | 时态 | 适用场景 |
|------|------|------|---------|
| 知识型 | 解决用户痛点，传授方法技能 | 现在时 | 塑专业、建信任 |
| 故事型 | 过去发生的事情 | 过去时 | 立人设、建情感 |
| 晒事件过程 | 正在发生的事情记录 | 正在进行时 | 实操引流、建真实感 |
| 观点型 | 发表看法、引发共鸣 | 现在时 | 拉流量、涨粉丝 |
| 段子型 | 演绎搞笑内容 | 任意 | 娱乐引流 |

**5个内容来源**：
1. **本人的真实故事**：创业故事、员工故事、客户故事等
2. **本人的知识储备**：痛点解决、热门事件分析、干货知识、行业内幕、避坑指南
3. **本人的个人观点**：对热点事件、行业现象的评论看法
4. **本人的事件记录**：日常具体实操的事情的记录
5. **演绎**：通过表演、情景剧等方式演绎内容

**内容判断标准（符合其中之一即可）**：
有趣 / 有用 / 有共鸣 / 有猎奇 / 能治愈 / 恐惧 / 损失厌恶 / 焦虑 / 色欲 / 傲慢 / 美好 / 惊喜

**避坑指南**：
- ❌ 内容类型单一——观点太多没人信任，知识太多没人看
- ❌ 内容没有"人性钩子"——不符合上述12个判断标准
- ✅ 4种内容类型按比例组合使用

### 计4：24宫格内容差异化策划

**策略名称**：24宫格差异化策划表——在同行账号上加一个改变就是你的新账号

**核心原理**：你不需要从零创造内容。找到你赛道里的对标账号，在24个差异化维度里选1个加上去，就是你的新账号。这是最高效的内容差异化方法。

**24个差异化维度**（来源：起号36计）：

| 序号 | 差异化维度 | 说明 | 案例 |
|------|----------|------|------|
| 1 | 怀旧复古 | 加入复古场景/年代元素 | 农村土灶做饭 |
| 2 | 行业之最 | 做行业内最**的事 | 最便宜的XX测评 |
| 3 | 成本 | 展示做某事的成本 | 做一件事花了多少钱 |
| 4 | 人群 | 针对特定人群做内容 | 给特定人群的内容 |
| 5 | 奇葩 | 展示奇葩的事物 | 最奇葩的XX |
| 6 | 荷尔蒙 | 加入帅哥美女元素 | 美女讲车 |
| 7 | 换身份 | 改变出镜人身份 | 保洁阿姨讲商业 |
| 8 | 换场景 | 改变拍摄场景 | 菜市场讲穿搭 |
| 9 | 换拍摄视角 | 改变机位和拍摄方式 | 宠物视角拍Vlog |
| 10 | 对赌对抗 | 加入PK/对赌/挑战元素 | 输了就剃光头 |
| 11 | 傍大款 | 跟大佬/名人产生关联 | 跟XX大佬合作 |
| 12 | 人物关系 | 加入出镜人物关系 | 老公教老婆做饭 |
| 13 | 暴躁态度 | 用暴躁风格表达 | 暴躁设计师吐槽甲方 |
| 14 | 验证解密 | 验证/解密某件事 | 验证XX是不是真的 |
| 15 | 以物换物 | 用产品交换陌生人的故事 | 用茶叶换陌生人的故事 |
| 16 | 跨界组合 | 两个赛道内容合并 | 律师+美食=边吃边普法 |
| 17 | 拟人化 | 把物品当人拍 | 手机的一天 |
| 18 | 拟物化 | 把人当物拍 | 把自己当扫地机器人 |
| 19 | 反向操作 | 跟同行反着来 | 同行高雅你就接地气 |
| 20 | 整蛊 | 恶搞/整蛊 | 用鸡蛋整蛊老爸 |
| 21 | 扮猪吃老虎 | 假装新手展示专业 | 假装初学者结果专业扣杀 |
| 22 | 借物喻人 | 把物件动作比喻成人的行为 | 手机内存不足=打工人被压垮 |
| 23 | 改造对比 | 前后对比 | 装修前后对比 |
| 24 | 跨界重组 | 用A行业的方式做B行业的事 | 用餐饮方式做教育 |

**使用公式**：你的行业 + 某个差异化维度 = 你的差异化内容

**实战案例**：
- 洗浴行业 + 反向操作 = 反向测评洗浴中心
- 茶叶行业 + 以物换物 = 用茶叶换陌生人的故事
- 唱歌 + 换身份/换场景/换拍摄视角 = 外卖小哥唱美声
- 美业 + 行业避坑 = 美容院不会告诉你的秘密

**避坑指南**：
- ❌ 差异化维度与行业完全不搭——硬凑没有说服力
- ❌ 一次加太多差异化——混乱（一次选1-2个即可）
- ✅ 先模仿同行内容，熟悉后再加上你的差异化维度

### 计5：搭建素材库

**策略名称**：素材库分类搭建法——不靠灵感、靠积累

**核心原理**：专业创作者的秘密不是"有才华"，而是"有素材库"。看了30万条视频筛选分类总结下来的收藏夹体系，让你在任何时候都能找到选题和内容素材。

**操作步骤**：
1. **建立收藏夹分类**（保存地方：**石盟文档** + 抖音的收藏夹）
2. **每天刷视频时做标记**：把打动你的视频收藏到对应的收藏夹
3. **每周做一次整理**：分析收藏的视频为什么好？哪些元素能复用？
4. **创作时打开素材库**：先找同类选题参考，再创作

### 计6：四种呈现形式

**策略名称**：同一类内容的4种呈现形式——选择最适合你的

**核心原理**：同一类知识/观点内容，可以用4种完全不同的形式呈现。选对你擅长的方式，比选"最好的方式"更重要。

**4种呈现形式**（来源：起号36计）：

| 形式 | 说明 | 优缺点 |
|------|------|--------|
| **图文** | 用图片+文字呈现内容 | ✅ 门槛低、制作快；❌ 表现力有限 |
| **真人口述** | 对着镜头直接讲 | ✅ 门槛最低、效率最高；❌ 对表现力有要求 |
| **视频+配乐** | 视频画面配合音乐呈现 | ✅ 氛围感强、完播率高；❌ 需要素材积累 |
| **情景剧** | 把内容演绎成短剧 | ✅ 完播率最高、代入感最强；❌ 门槛最高、拍摄剪辑量大（情景剧是最难的） |

**选择建议**：
- 新手首选：**真人口述**（最快拿到反馈，最低成本试错）
- 有表演天赋可选：**情景剧**（完播率优势明显，但投入大）
- 有素材积累可选：**视频+配乐**（氛围感碾压其他形式）
- 不想出镜可选：**图文**（最低门槛快速产出）

**避坑指南**：
- ❌ 新手一上来就做情景剧——难度太高容易放弃
- ✅ 先用真人口述拿到正反馈，再考虑升级形式

### 计7：视频记忆点（视觉锤 + 语言钉）

**策略名称**：视觉锤 + 语言钉——让你的账号有辨识度

**核心原理**：在信息过载的短视频环境里，用户需要一个快速识别你的标记。视觉锤（视觉符号）+ 语言钉（口头禅/开场白）= 账号记忆点。

**视觉锤案例**：
- 固定的穿衣风格（黑帽子红衣服）
- 固定的开场动作（立正、拿道具）
- 固定的场景背景（特定颜色的墙）
- 固定的画面构图（特定机位和角度）

**语言钉案例**：
- 固定开场白（如"哎哟~呀你就说……"）
- 固定口头禅
- 固定的结尾句式
- 固定的情绪语气

**参哥出品完整案例**（来源：起号36计）：
- **视觉锤**：立正拿100块、黑帽子红衣服200块
- **语言钉**："哎哟~呀你就说……"
- **粗暴好用**：作为视频的一个记忆点，让用户0.1秒认出你

**操作步骤**：
1. 确定1个视觉记忆点（视觉锤）：可以是衣服、动作、场景、道具
2. 确定1个语言记忆点（语言钉）：可以是开场白、口头禅、结尾语
3. 每条视频都坚持使用，形成条件反射
4. 当用户在信息流里看到你的视觉锤/听到你的语言钉时，能0.1秒认出你

**避坑指南**：
- ❌ 每条视频换一个风格——没有记忆点等于白做
- ❌ 视觉锤太普通——满大街都是（比如纯白背景）
- ✅ 视觉锤要有辨识度，语言钉要朗朗上口

### 计8：账号整体风格调性

**策略名称**：各项定位适配度检查——账号是一个整体

**核心原理**：头像、昵称、简介、背景图、主页画面排版、人物形象，所有这些元素的风格调性必须统一，符合大众对你所在赛道的常规认知。

**账号风格清单**：

| 元素 | 检查标准 |

**正向匹配**（来源：起号36计）：对吧各个元素都是匹配的——头像、昵称、简介、背景图、主页画面排版、人物形象、选题、单个画面呈现、说话的语气，所有元素都要正向匹配，符合大众常规认知。

**避坑指南**：

- ✅ 用户点进主页3秒内能判断"这个账号是做什么的"

### 计9：10种爆款选题方向

**策略名称**：10种爆款选题方向——让选题不再靠灵光一闪

**核心原理**：选题决定了视频的流量天花板。覆盖人群越广，流量越大。同一个主题有4个层次的选题（初级→中级→高级→顶级），选题层次决定了流量大小。

**选题3大原则**：
1. **流量型**：蹭热点、有争议、增长见识
2. **人设型**：秀有多厉害、讲你的成长故事
3. **变现型**：晒帮客户做的事情、讲帮客户成功的故事

**选题3大标准**（来源：起号36计）：
1. **覆盖人群是否广**——怎么让你的视频覆盖人群更广一点
2. **给用户带来什么价值**——有趣、有用、有共鸣、猎奇、治愈、长见识
3. **有没有比用户更深**——你的认知是否比用户更深一层

**10种爆款选题方向**：

| 序号 | 选题方向 | 核心原理 | 案例 |
|------|---------|---------|------|
| 1 | **解决痛点** | 用户有具体的麻烦，你给出低成本解决方案 | 为什么老实人不挣钱；腿太粗不敢穿裙子 |
| 2 | **行业避坑** | 替用户在某个领域避开坑，省时间省钱 | 加盟瑞幸10大坑；新手做抖音10大坑 |
| 3 | **反认知内容** | 颠覆大众常识，引发好奇和争议 | 内蒙古人不是最能喝的；在德国被狗咬了直接拿绿卡 |
| 4 | **丰富谈资** | 给用户提供聊天的素材，看完能拿去吹牛 | 8分钟说完中国史；古代人是怎么看牙医的 |
| 5 | **内幕揭秘** | 揭秘行业不为人知的秘密 | 医美收人高但没人带；水光针的危害；健身教练不会告诉你的事 |
| 6 | **推荐建议** | 给用户推荐好东西，省去选择成本 | 推荐10部搞钱电影；推荐10本成长书籍；推荐20个办公软件；推荐10个夜店小游戏 |
| 7 | **变得更好** | 教用户提升自己，变美变强变有钱 | 3个月练成彭于晏身材；3分钟看一本书；如何提高情商；25岁到35岁成长比成功更重要；如何做到自律 |
| 8 | **共鸣型观点** | 讲用户心里想说但没说出口的话 | 婆媳矛盾就是老公的错；婚姻就是搭伙过日子；不要去指责年轻人不结婚；婚姻是经济关系，情侣是爱情关系 |
| 9 | **不同视角看问题** | 换个角度看问题，提供新鲜感 | 不同收入男生找女朋友的要求；外企同事最喜欢的中国元素是什么；不同段位的人怎么做抖音；外围人是怎么看中国人的 |
| 10 | **个人故事** | 讲你自己的故事，建立情感连接 | 帮助员工的真实经历；贵人相助故事；弥补遗憾故事；新疆15日游记 |

**选题层次案例（以咖啡为例）**：

| 层次 | 选题 | 覆盖人群 | 流量预期 |
|------|------|---------|---------|
| 初级 | 如何挑选咖啡豆 | 咖啡资深玩家 | 低 |
| 中级 | 手冲咖啡入门指南 | 普通咖啡爱好者 | 中 |
| 高级 | 各国咖啡的优缺点 | 喝咖啡的人+对咖啡感兴趣的人 | 高 |
| 顶级 | 星巴克的咖啡豆为什么不好 | 喝咖啡 + 不喝咖啡的都来看八卦 | 爆款级 |

> **选题来源**：①你的知识储备（行业内幕/干货知识/避坑）②你的经历故事（个人/顾客/员工故事）③行业的热门话题（对标账号高赞选题/关键词搜索/知乎/公众号/小红书）④你的实操事件记录

**九宫格选题创作法**（进阶技巧）：

```
行业关键词 × 目标用户感兴趣关键词 = 爆款选题

示例组合：
- 人设 × 挣钱 → 抖音上哪种人设最挣钱
- 爆款 × 人性 → 爆款选题都要符合人性
- 变现 × 副业 → 做什么副业变现最快
```

**避坑指南**：
- ❌ 选题只看同行——不会扩圈，天花板就是同行的播放量
- ❌ 选题只做本专业——用户群体窄，流量小
- ✅ 用"选题层次"思维把专业选题做成大众都能看的选题

### 计10：九宫格选题创作法

**策略名称**：关键词交叉法——用矩阵思维创作选题

**核心原理**：将行业关键词与目标用户感兴趣的关键词进行交叉组合，系统化生成选题。告别"今天拍什么"的焦虑。

**操作步骤**：
1. 列出你的**行业关键词**（如：口播、钩子、人设、爆款选题、短视频、运营、开篇、脚本、定位、变现）
2. 列出你的**目标用户感兴趣的关键词**（如：挣钱、创业、还债、副业、短视频、创作者、成长、八卦、商业、恋爱）
3. 将两组关键词做交叉组合（如：人设×挣钱、爆款×人性）
4. 每个交叉点生成1-3个具体选题
5. 关键词可以互换位置、替换同义词，拓展更多选题

**应用案例**：
- 人设 × 挣钱 → "抖音上哪5种人设最挣钱"
- 爆款 × 人性 → "爆款选题都是要符合人性的"
- 变现 × 副业 → "做什么副业变现快"

**避坑指南**：
- ✅ 这是进阶玩家的优质选题方法，新手先用10种选题方向即可

### 计11：脚本结构——教知识型（3种子结构）

**策略名称**：教知识型脚本3种结构——让干货不枯燥

**核心原理**：教知识的视频容易变成"说教"，用户划走率高。用3种结构框架包装知识，让干货变得有吸引力。核心：获得感（信息多、效果快、听得懂）。

#### 子结构A：案例引入型

| 步骤 | 内容 | 示例 |
|------|------|------|
| 1. 说一件有意思的事 | 用一个有趣案例开场 | "他3天涨粉10万，用的方法叫跨界重组" / "武汉有一家被树挡住的烤肉店" |
| 2. 提炼出知识点 | 从这个案例中提取出方法论 | "所谓跨界重组，就是用A行业的方式做B行业的事" / "视觉锤+文字钉" |
| 3. 其他行业如何运用 | 拓展应用场景 | "这个方法亲子账号能用、律师账号也能用" / "小罐茶、红马飞扬" |

**避坑**：不要一上来就讲知识点，先用案例钩住用户。

#### 子结构B：痛点型

| 步骤 | 内容 | 示例 |
|------|------|------|
| 1. 描述用户难题 | 精准描绘用户的痛点 | "如果你开学军训不想晒黑……" |
| 2. 低成本解决方法 | 给一个简单的总方案 | "只用做好这三件事" |
| 3. 具体解决方案 | 分点讲具体做法 | "首先……第二点……最后……" |

#### 子结构C：推荐型

| 步骤 | 内容 | 示例 |
|------|------|------|
| 1. 利益诱导/引发好奇 | 用结果或好奇心吸引 | "挣钱必看的4部电影，要是看过其中一部，恐怕这辈子都不会穷" |
| 2. 推荐内容和理由 | 逐一推荐并说明理由 | "第一部……第二部……" |

**避坑指南**：
- ❌ 干讲知识不说案例——完播率极低
- ❌ 知识点太多——一次只讲1个核心知识点
- ✅ 知识型内容核心：获得感（信息多、效果快、听得懂）

### 计13：脚本结构——说观点型（2种子结构）

**策略名称**：说观点型脚本2种结构——让用户觉得"你懂我"

**核心原理**：说观点的核心是"讲目标用户本来就认同的观点"。理解他、支持他、替他说话。观点不是去教育用户，而是去共鸣用户。

| 3. 强化观点 | 用心理学效应/名人名言/数据强化 | "所以男人不专一事实上是对男人的一个大的误解。心理上有一个著名的效应叫预期效应，当你觉得男人很专一的时候，全世界男人都专一" |

#### 子结构B：正反论证型（3步）

| 步骤 | 内容 | 举例 |
|------|------|------|
| 1. 阐述观点 | 提出一个"反直觉"的观点 | "找老公不要找爱好多的，你要找爱喝酒的" |

**避坑指南**：
- ❌ 观点是"教育用户"——"你应该……" = 用户划走

### 计19：反向操作

**策略名称**：反向操作——找同行反着来就是你的新号

**核心原理**：在你的行业里找一个对标账号，分析他做的所有事情，然后反着来。他的受众里一定有不喜欢他风格的人，那些人就是你的第一批粉丝。

**操作步骤**：
1. 找到你赛道里排名靠前的对标账号（3-5个）
2. 分析他们的共性特征：说话风格、拍摄场景、内容调性、价值观立场
3. 每个维度做一个"反向"版本
4. 选择最有力的1-2个反向维度，作为你的差异化定位

**实战案例**：

| 赛道 | 对标账号特征 | 反向操作 |
|------|------------|---------|
| 摄影 | 专业术语多、设备贵 | 用手机教拍照、大白话 |
| 洗浴 | 高端体验测评 | 反向测评最便宜的洗浴中心 |
| 茶叶 | 高雅茶道礼仪 | 倒茶暗语、接地气喝茶 |
| 美食 | 精致摆盘教学 | 什么时候能吃上晚饭（教懒人菜） |

**话术模板**：
- "别人都在教你怎么……我今天告诉你为什么不……"
- "同行都在做……但我偏要做……"

**避坑指南**：
- ❌ 为反而反——反向要有逻辑支撑，不是哗众取宠
- ❌ 反向后没有受众——确认反向后的人群确实存在
- ✅ 反向操作本质是找"对标账号覆盖不到的人群"

### 计20：扮猪吃老虎

**策略名称**：扮猪吃老虎——假装新手/小白展示专业实力

**实战案例**：

| 赛道 | 方案 |
|------|------|
| 招聘 | 假装第一次去应聘，结果反问HR把HR问住 |
| 乒乓球 | 假装初学者，结果专业扣杀 |
| 短视频运营 | 假装刚学做短视频，结果拆解得头头是道 |
| 钢琴 | 假装不会弹，一出手就是专业级别 |
| 健身 | 假装新手请教教练，结果做标准动作比教练还标准 |

**避坑指南**：
- ❌ 演技太假——用户一眼识破就没有反差效果
- ✅ 追求真实感，用户半信半疑时效果最好

### 计21：以物换物

**策略名称**：以物换物——用行业产品交换陌生人的故事/物品

**核心原理**：在你的行业里找出一个产品，去跟陌生人做交换。交换过程的不可预测性+人与人的互动=天然内容。

**操作步骤**：
1. 确定你行业里有什么可以交换的产品（可以是标品也可以是非标品）
2. 设计交换规则：用什么换什么？
3. 上街/去特定场景找人交换
4. 记录交换过程+对方的故事

**实战案例**：

| 赛道 | 方案 |
|------|------|
| 白酒 | 用一瓶白酒换陌生人的故事 |
| 茶叶 | 用一盒茶叶换陌生人的一个物件 |
| 手工艺 | 用手工艺品换陌生人的一句话/故事 |
| 星图广告 | 用广告资源换达人合作 |

**话术模板**：
- "我这有XX，想跟你换XX，你愿意吗？"

**避坑指南**：
- ❌ 交换过程平淡——要找有故事的人，故事才是内容核心
- ✅ 交换只是载体，人的故事才是流量密码

### 计22：借物喻人

**策略名称**：借物喻人——把实体物件的动作比喻成人的动作

**核心原理**：在你的行业里找一个实体物件，把它的动作/特性比喻成人的行为。这种"拟人化比喻"能产生意想不到的幽默感和传播力。

**操作步骤**：
1. 在你的行业里找一个大家熟悉的实体物件
2. 分析这个物件的某个特性或动作
3. 把这个特性/动作比喻成人的某种行为/情感
4. 用视频演绎这个比喻

**实战案例**：

| 赛道 | 方案 |
|------|------|
| 手机 | 把手机的"内存不足"比喻成"快被工作压垮的打工人" |
| 情趣内衣 | 把内衣比喻成"人格的另一面" |
| 星图广告 | 把各种产品拟人化做广告创意 |

**避坑指南**：
- ❌ 比喻太牵强——用户get不到就没有共鸣
- ✅ 比喻最好有"生活洞察"，让人看完会心一笑

### 计23：跨界组合

**策略名称**：跨界组合——两个赛道内容并在一起，流量翻倍

**核心原理**：把你所在赛道的内容，和另一个完全不相关的赛道内容硬组合在一起（可以没有逻辑或行为模式上的链接关系）。故事配音、共鸣型观点配音、舞蹈都是不错的跨界基础元素。特别适合小赛道做大流量。

**操作步骤**：
1. 确定你的主赛道内容（核心内容）
2. 选一个热门赛道作为跨界元素（配音/舞蹈/美食/萌宠等）
3. 把两个赛道的内容硬组合在一起
4. 跨界元素的流量会带动主赛道的曝光

**实战案例**：

| 主赛道 | 跨界元素 | 方案 |
|--------|---------|------|
| 美食 | 配音/故事 | 边做饭边讲悬疑故事 |
| 律师 | 美食 | 边吃饭边普法 |
| 情感 | 舞蹈 | 跳一段舞然后讲情感观点 |
| 按摩 | 配音 | 用故事配音配合按摩过程 |
| 钢琴 | 美食 | 边弹琴边介绍美食 |

**避坑指南**：
- ✅ 跨界组合的核心：两个赛道的内容都在输出，不是只做一个
- ❌ 硬蹭不相关的赛道——虽然可以"没有逻辑关系"，但至少形式上要顺畅

### 计24：用XX方式做XX事（赛道叠加·有逻辑关系版）

**策略名称**：赛道叠加——两个在逻辑或行为模式上有链接关系的赛道合并

**核心原理**：与"跨界组合"不同，这个方法要求两个赛道在逻辑或行为模式上有链接关系。两个赛道内容并在一起，流量更大。适合小赛道做大流量。

**实战案例**：

| 赛道A | 赛道B | 方案 |
|-------|-------|------|
| 宠物 | 配音 | 用宠物视角配音讲人类迷惑行为 |
| 餐饮 | 唱歌 | 边炒菜边唱歌 |
| 美业 | 讲故事 | 美容院里讲客户故事 |
| 洗浴 | 测评 | 用测评的逻辑测评洗浴中心 |
| 整蛊 | 行业 | 用整蛊的方式展示行业日常 |

### 计25：一句话设定故事感

**策略名称**：一句话设定故事感——在画面上加一句话就能改头换面

**核心原理**：拿着你同行的视频，在画面上加一句话，就变成了你的视频。这一句话能彻底改变用户对画面的理解和情绪反应。加一句话非常重要。

**操作步骤**：
1. 准备你的视频素材（可以是同行的常规内容）
2. 在画面上叠加一句话（字幕/标题）
3. 这句话必须能给画面赋予新的"故事感"——让用户自动脑补一个故事
4. 注意：提到的人物不需要出镜

**实战案例**：

| 赛道 | 视频内容 | 加一句话 |
|------|---------|---------|
| 服装 | 展示穿搭 | "当你告诉相亲对象你是186体育生" |
| 生活Vlog | 做家务 | "当你知道他今晚不回来了" |
| 美妆 | 化妆过程 | "去见前男友的现女友那天" |
| 设计 | 做设计 | "甲方说'随便做'之后" |
| 唱歌 | 唱歌 | "这首歌是写给五年前的自己" |

**避坑指南**：
- ✅ 这句话必须能"改变整个画面的解读方式"
- ❌ 加一些无关痛痒的描述——没有故事感就没有效果

### 计26：加人物关系

**策略名称**：加人物关系——让视频内容产生人物之间的化学反应

**核心原理**：与"一句话设定故事感"类似，但区别在于这个人物需要出镜。加入一个真实的人物关系（夫妻/父子/闺蜜/同事等），让内容产生人物间的化学反应。

**实战案例**：

| 赛道 | 方案 |
|------|------|
| 家庭生活 | "11:00老公还没回来"——制造悬念+人物关系 |
| 相亲 | 真实相亲过程记录 |
| 舞蹈 | 挑战带老妈健身，让老妈回到18岁 |
| 美食 | 老公教老婆做饭 |
| 健身 | 父子健身PK |

**避坑指南**：
- ✅ 人物关系的化学反应 > 单人出镜的表现力
- ❌ 人物关系太生硬——如果搭档不自然，适得其反

### 计27：一饰多角

**策略名称**：一饰多角——一个人扮演多个角色

**核心原理**：一个人扮演多个角色，在同一场景里演绎对话/冲突。这是一个很经典且一直被验证有效的内容形式。

**操作步骤**：
1. 设计一个包含2个以上角色的小剧本
2. 自己扮演所有角色（可以通过服装/站位/字幕区分）
3. 用简单的剪辑手法切换角色
4. 核心是角色之间的对话冲突

**实战案例**：

| 赛道 | 方案 |
|------|------|
| 茶叶 | 茶商vs茶客——卖茶的内心戏 |
| 健身 | 教练vs学员——健身的内心挣扎 |
| 美妆 | 化妆师vs直男——审美的认知差异 |

**避坑指南**：
- ✅ 一饰多角的核心是"角色之间的冲突感"，不是简单换衣服说话
- ❌ 角色区分不清晰——用户看不懂谁是谁

### 计28：情境还原

**策略名称**：情境还原——把内容还原到真实发生的情境里

**核心原理**：把视频内容（知识、观点、事件）还原到真实发生的情境里去。不仅可以减少说教感，还能大幅增加用户的代入感。

**操作步骤**：
1. 确定你要表达的内容（知识点/观点/故事）
2. 找一个最真实的场景来还原这个内容
3. 在真实场景里，用日常聊天的说话方式表达
4. 追求极致的真实情境——说话的方式+视觉体验都要真实
5. 用户不会感觉是"演的"，才能产生代入感

**实战案例**：

| 赛道 | 方案 |
|------|------|
| 餐饮 | 后厨真实环境里讲餐饮经营之道 |
| 装修 | 施工现场边干活边讲装修避坑 |
| 医生 | 诊室里穿着白大褂讲健康科普（不是在演播室） |
| 亲子 | 家里真实场景中讲育儿（抱孩子的姿势都是真实的） |
| 唱歌 | 不是在录音棚，而是在街头/浴室/阳台真实唱歌 |

**注意点**：一定要追求极致的真实情境，比如说话的方式（日常聊天式而非念稿式）和视觉体验（真实环境而非搭建的场景）。

**避坑指南**：
- ❌ 假情境还原——用户看得出是演的，失去代入感
- ✅ 日常聊天的说话方式 > 对着镜头表演

**避坑指南**：
- ❌ 纯粹蹭热点没有行业视角——和你的赛道无关的热点不要蹭
- ❌ 点评过于主观/攻击性——借势不是拉踩

### 计36：行业避坑 / 内幕揭秘 / 懒人学习 / 暴躁态度 / 怀旧复古 / 身份反差

**策略名称**：6种高流量起号方式汇总

**核心原理**：这些方式分别利用好奇心（内幕）、恐惧心（避坑）、懒惰心（懒人学习）、情绪（暴躁/怀旧/反差）来吸引流量。

| 赛道 | 方案 |
|------|------|

| 短视频运营 | 新手做短视频的坑 |

| 医生 | 看病的坑 |

| 赛道 | 方案 |
|------|------|

## 附录D：彩蛋——如何像事业人一样看视频（来源：起号36计）

**核心方法**：用两个关键时间点分析每条打动你的视频。

| 时间节点 | 分析问题 |
|---------|---------|
| **前2秒** | 是什么吸引了我？什么引起我情绪的变化？下次我能不能用得上？ |
| **前5秒** | 是什么让我产生了看后续视频的期待？这个期待技巧我是不是用得上？ |

> **核心**：普通人刷视频是消费，事业人刷视频是学习。把每条打动你的视频都当成素材，分析其钩子和期待建立技巧，下次创作时调取使用。
