# 起号36计之避坑篇（计29-计46）

> **模块定位**：36种起号方式中的后续策略，以及新手最容易踩的坑。这些策略虽然有效，但各有陷阱需要注意。

---

## 计29：Rap式内容

**策略名称**：Rap式内容——用押韵的节奏输出行业干货

**核心原理**：把行业知识/观点用押韵的方式表达，配合节奏感。这种形式需要专门去写押韵的词。

**实战案例**：

| 赛道 | 方案 |
|------|------|
| 汽修 | 用押韵方式讲修车知识 |
| 考研 | 押韵讲考研避坑 |
| 汽车 | 押韵讲买车秘诀 |
| 宠物 | 押韵讲养宠知识 |
| 广告 | 押韵做创意广告 |

**避坑指南**：
- ❌ 强行押韵导致内容信息量降低——押韵是锦上添花，内容才是核心
- ✅ 先写好内容，再优化押韵
- ✅ Rap式适合"避坑""秘诀"类的list型内容

## 计30：借势点评

**策略名称**：借势点评——借热点事件/明星/大佬/电影输出你的行业观点

**核心原理**：借势方向包括热点事件、明星、大佬、电影等。借这些"势能"来输出你的行业观点，蹭热度的同时展示专业度。

**操作步骤**：
1. 关注当前热点：热点事件、明星动态、大佬言论、热门影视
2. 从你的行业视角分析这个热点
3. 输出有信息增量的专业观点

**实战案例**：

| 赛道 | 方案 |
|------|------|
| 美业 | 点评明星的整容/医美选择 |
| 减脂 | 分析某个明星的减肥方法是否科学 |
| 咖啡 | 分析某部电影里的咖啡文化 |
| 穿搭 | 解析某部热门剧集全季的穿搭（如《浴血黑帮》全五季穿搭详细解析） |

**避坑指南**：
- ❌ 纯粹蹭热点没有行业视角——和你的赛道无关的热点不要蹭
- ❌ 点评过于主观/攻击性——借势不是拉踩
- ✅ 借势点评的核心：热点只是引子，你的行业观点才是内容

**策略名称**：跟着博主做——复刻博主的视频内容

**核心原理**：找一个你赛道里的博主，复刻他的视频内容/挑战/方法，在这个过程中展示你的行业视角。

| 服装 | 跟着穿搭博主的方法搭一周的衣服 |

## 计33：正确做法 VS 错误做法

**策略名称**：正误对比——展示正确和错误的方法

**核心原理**：用对比的方式展示正确做法和错误做法的区别。这种形式天然带"纠错"钩子，用户会好奇"我做对了吗"。

**实战案例**：

| 赛道 | 方案 |
|------|------|
| 健身 | 错误蝴蝶机夹胸 vs 正确做法 |
| 育儿 | 父母错误的说话方式 vs 正确话术 |
| 英语 | 错误发音 vs 正确发音 |
| 育儿 | 错误拒绝孩子的方式 vs 正确的公式 |

**避坑指南**：
- ❌ 对比过于简单——"1+1=2"级别的对比没人看
- ✅ 正误对比要有"反直觉"——你以为正确的其实错了

## 计34：整蛊 / 互联网嘴替

**策略名称**：整蛊型 + 互联网嘴替型

**核心原理**：
- **整蛊型**：把别人的反应做成内容。用食物/道具整蛊身边的人，记录他们的有趣反应。
- **互联网嘴替**：替用户说出他们想说但不敢说/不会说的话。

**整蛊型实战案例**：

| 赛道 | 方案 |
|------|------|
| 生活Vlog | 用鸡蛋整蛊老爸，看他什么反应 |
| 生活Vlog | 假装有新男友/女友，看家人反应 |
| 生活Vlog | 整蛊闺蜜/兄弟 |

**互联网嘴替实战案例**：

| 赛道 | 方案 |
|------|------|
| 美食 | 替吃货说出"这家店到底好不好吃"的真心话 |
| 减脂 | 替减脂人吐槽各种奇葩减肥法 |
| 测评 | 替用户说出产品好不好用的真实感受 |

**避坑指南**：
- ❌ 整蛊要安全、不伤害感情——恶搞过头会翻车
- ✅ 互联网嘴替要"说到用户心坎里"，不是简单吐槽

## 计35：求助网友 / 改造对比 / 拟人化 / 拟物化

**策略名称**：4种创意起号方式

**核心原理**：这些方式的核心都是"换个角度看你的行业"，用不同寻常的视角让你的行业内容变得有趣。

### 求助网友型

| 赛道 | 方案 |
|------|------|
| 母婴 | 让网友帮忙选宝宝用品 |
| 生活Vlog | 让网友决定今天做什么 |
| 乐器 | 用"这个三角铁怎么用"求助引出乐器知识 |

**核心**：用求助的方式引出你的行业知识。

### 改造对比型

| 赛道 | 方案 |
|------|------|
| 装修 | 厨房改造前后对比 |
| 美妆 | 素颜vs全妆前后对比 |
| 理发 | 发型改造前后对比 |
| 汽修 | 旧车翻新前后对比 |

**核心**：改造前后的反差=天然流量。但要把拍摄和剪辑练好。

### 拟人化型

| 赛道 | 方案 |
|------|------|
| 美食 | "一颗白菜的精神状态" |
| 手机 | "三天没出门的手机精神状态" |
| 宠物 | 用宠物的视角讲人类 |

### 拟物化型

| 赛道 | 方案 |
|------|------|
| 健身 | 把自己当成扫地机器人健身 |
| 生活Vlog | "到寝室和舍友打扫卫生"——模仿扫地机器人 |
| 宠物 | "提前示范给猫看怎么打扫卫生" |

**注意**：拟物化目前做的人比较少，是比较新鲜的差异化方向。

## 计36：行业避坑 / 内幕揭秘 / 懒人学习 / 暴躁态度 / 怀旧复古 / 身份反差

**策略名称**：6种高流量起号方式汇总

**核心原理**：这些方式分别利用好奇心（内幕）、恐惧心（避坑）、懒惰心（懒人学习）、情绪（暴躁/怀旧/反差）来吸引流量。

### 行业避坑

| 赛道 | 方案 |
|------|------|
| 珠宝 | 买品牌珠宝的坑 |
| 短视频运营 | 新手做短视频的坑 |
| 美业 | 美容院的坑 |
| 医生 | 看病的坑 |

**核心**：每个赛道都有多个避坑的点，用"别踩这个坑"建立专业信任。

### 内幕揭秘

| 赛道 | 方案 |
|------|------|
| 服装 | 服装行业定价内幕 |

| 商业 | 某个商业模式背后的秘密 |
| 餐饮 | 餐饮店的食材内幕 |

**核心**：好奇心 = 高停留时长。用户天然想知道"背后发生了什么"。

### 懒人学习

|------|------|

**核心**：把你对标账号的内容，换成暴躁的风格说一遍。但要镜头运镜把人的情绪抓住。

### 怀旧复古

## 计46：行业冷知识（来源：起号36计·NO.35）

**策略名称**：行业冷知识——讲行业里的冷知识

**核心原理**：讲行业里用户不知道的冷知识，利用好奇心吸引流量。冷知识天然带"增长见识"属性。

**实战案例**：

| 赛道 | 方案 |
|------|------|
| 珠宝 | 珠宝行业的冷知识 |
| 美业 | 美业行业的冷知识 |
| 律师 | 如何合法查人 |

**核心**：都是讲行业冷知识。
