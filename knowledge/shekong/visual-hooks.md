## 计29：高情绪

| 维度 | 说明 |
|------|------|
| **核心原理** | 用极端情绪画面在第一时间传递情绪能量 |
| **适用场景** | 情绪型内容、热点评论、观点输出 |
| **操作方式** | 开头画面直接展示强烈的情绪：大哭/大笑/愤怒/崩溃/狂喜/震惊 |
| **代表案例** | "高考出分当天查分瞬间"——崩溃/狂喜的情绪爆发 |

**避坑指南**：
- ❌ 情绪造假——用户能感知假情绪
- ✅ 情绪要有真实的触发事件支撑

---

## 计30：强节奏

| 维度 | 说明 |
|------|------|
| **核心原理** | 用快速剪辑/强节奏音乐/B-Beat卡点创造视觉节奏感 |
| **适用场景** | 改造类、快剪类、信息密度高的内容 |
| **操作方式** | 开头3秒用快剪镜头+节奏感强的BGM，让用户在视觉上感到"爽" |
| **代表案例** | "老板给的LV牛仔服能改几个包送老婆？"——快剪改造过程（网友：两个老板都哄好，妥妥的人生赢家） |

---

## 计31：凑热闹

| 维度 | 说明 |
|------|------|
| **核心原理** | "围观"是人类本能。用多人场景/围观画面引发好奇心 |
| **适用场景** | 街头类、多人互动类、事件记录类 |
| **操作方式** | 开头画面展示一群人围观某件事，引发用户"发生了什么事"的好奇 |
| **话术搭配** | "这个人为什么被一群人围着……" |

---

## 计32：沉浸感

| 维度 | 说明 |
|------|------|
| **核心原理** | 用ASMR般的沉浸画面让用户"陷进去" |
| **适用场景** | 护理类、美食制作、手工制作、治愈解压类 |
| **操作方式** | 纯视觉+环境音（去除BGM/旁白），让画面自身的质感吸引用户 |
| **代表案例** | "沉浸式背部护理""少女背养成SPA""猜猜小姐姐是哪里的" |

---

## 计33：反差感

| 维度 | 说明 |
|------|------|
| **核心原理** | 画面内容和标题/预期的巨大反差=天然停留 |
| **适用场景** | 反差类内容、反转类故事 |
| **操作方式** | 开头展示一个画面，用户以为是这样，但实际是那样 |
| **代表案例** | "粗茶淡饭"标题 → 打开是豪华大餐；"封闭路段固定机位安全拍摄" → 实际是刺激画面；"欢迎到我的庄园来" |

---

## 计34：特殊视角拍摄

| 维度 | 说明 |
|------|------|
| **核心原理** | 用"一般人不会这么拍"的视角制造新鲜感 |
| **适用场景** | 所有赛道 |
| **操作方式** | 把你的同行视频换个角度拍：俯拍/仰拍/偷窥视角/GoPro视角/无人机视角 |
| **话术搭配** | "从这个角度看{X}，你会发现……""偷偷带你看……" |

---

## 计35：故事感

| 维度 | 说明 |
|------|------|
| **核心原理** | 画面+一句话=完整的微型故事，让用户自动脑补 |
| **适用场景** | 生活Vlog、情感内容、穿搭、美妆 |
| **操作方式** | 画面+一句话字幕（"当你告诉相亲对象你是186体育生"），给普通的画面赋予故事感 |
| **话术搭配** | "当你{X}……"——一句话设定情境 |

---

## 计36：复古怀旧

| 维度 | 说明 |
|------|------|
| **核心原理** | 复古画面唤起集体记忆和情感共鸣 |
| **适用场景** | 音乐、美食、三农、老物件、童年回忆 |
| **操作方式** | 用复古滤镜、4:3画幅、低饱和度色调、老歌BGM，营造"过去的时光"氛围 |

## 附录D：彩蛋——如何像事业人一样看视频（来源：起号36计）

**核心方法**：用两个关键时间点分析每条打动你的视频。

| 时间节点 | 分析问题 |
|---------|---------|
| **前2秒** | 是什么吸引了我？什么引起我情绪的变化？下次我能不能用得上？ |
| **前5秒** | 是什么让我产生了看后续视频的期待？这个期待技巧我是不是用得上？ |

> **核心**：普通人刷视频是消费，事业人刷视频是学习。把每条打动你的视频都当成素材，分析其钩子和期待建立技巧，下次创作时调取使用。

---

> **使用建议**：
> - 起号36计：建议按顺序执行——先看完五大原则→完成账号搭建（计1-8）→规划内容策略（计9-18）→执行冷启动（计19-28）→避坑（计29-46）
> - 开篇36计：每条视频前3秒从文案钩子（计1-28）和画面钩子（计29-36）中各选1个组合使用
> - 13种开篇方法可以混合使用，2种以上钩子组合往往效果更佳
> - 新手第一原则：先模仿后创新，用24宫格差异化策划表在同行基础上做差异化
