# Stage 2 钩子：盲预测注入点

## 触发条件
- 内容Agent 产出成稿后
- 发布前必须执行（tight 模式）

## 注入逻辑

### Agent引擎 → 校准系统
1. 接收 内容Agent 的成稿
2. 接收 策略Agent 的发布计划（时间/平台）
3. 触发 yang-predict 进行盲预测

### 校准系统 → Agent引擎
1. 返回预测播放量/互动率（含置信区间和置信度）
2. 置信度 → 影响发布决策：
   - < 0.3: tight 模式拦截发布
   - 0.3-0.5: 警告但不拦截
   - > 0.5: 正常通过
3. 单维得分 < 2/5 → 建议回炉修改该维度

## 输出格式
```
[Stage 2] 盲预测同步完成
  播放量预测: P (置信区间: [L, H])
  置信度: C
  建议: ...
  门禁: 通过 / 拦截
```
