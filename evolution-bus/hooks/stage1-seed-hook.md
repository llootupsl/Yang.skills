# Stage 1 钩子：选题注入点

## 触发条件
- 选题Agent 产出一组候选选题后
- 用户手动触发 "产线模式" 或 "找选题"

## 注入逻辑

### Agent引擎 → 校准系统
1. 接收 选题Agent 的选题列表（题目标题 + 内部评分）
2. 不带 Agent引擎 评分地传递给 yang-seed 进行独立评分
3. 收集 校准系统 评分结果

### 校准系统 → Agent引擎
1. 将 校准系统 rubric 评分映射回 Agent引擎 信号格式
2. 若 校准系统 评分排名与 Agent引擎 差异 > 30% → 标记「跨系统争议」
3. 返回排序修正建议 + Hook 变体推荐

## 输出格式
```
[Stage 1] 选题注入完成
  选题数: N
  校准系统 验证: K/N 通过
  争议: M 个（等待人工决策）
```
