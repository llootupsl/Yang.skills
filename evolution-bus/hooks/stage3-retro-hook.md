# Stage 3 钩子：复盘反馈注入点

## 触发条件
- 发布后 T+3d，数据Agent 收集到实际表现数据
- 用户手动触发 "复盘"

## 注入逻辑

### Agent引擎 → 校准系统
1. 接收 数据Agent 的实际表现数据
2. 触发 yang-retro 进行自动复盘

### 校准系统 → Agent引擎
1. 返回预测准确度分析
2. 返回 rubric 维度贡献率回顾
3. 若连续 3 条预测偏差 > 30% → 建议降低 Agent引擎 对该维度依赖
4. 若满足 Bump 条件 → 异步触发 Bump 建议
5. Bump 通过 → 同步新版 rubric 到 Agent引擎

## 输出格式
```
[Stage 3] 复盘反馈完成
  预测准确度: A/10
  偏差: 维度分析 <details>
  校准池: N → N+1
  下次 Bump 资格: ✓ / ✗（还需要 M 条）
```
